# 泌尿科

!!! info "使用方式"
    系統性整理泌尿科觀念（總論 → 結石 → 感染 → 腫瘤 → BPH/LUTS → 神經性膀胱 → 男性學 → 小兒 → 急症外傷 → 移植）。`〔113-2〕` = 113 年第二次國考考過此觀念。
    對應考古題（含答案、解析，章節編號相同）：[泌尿科考古題](泌尿科考古題.md)

## 一、泌尿科總論

### 1.1 下泌尿道神經支配

| 神經 | 來源 | 屬性 | 作用 |
|---|---|---|---|
| **Pelvic n.** | S2–4 | 副交感 | **逼尿肌收縮（M2/M3）** → 排尿；勃起（cavernous n.） |
| **Hypogastric n.** | T10–L2 | 交感 | 膀胱頸/攝護腺收縮（α1）、逼尿肌放鬆（β3）→ **儲尿**；**射精 emission** |
| **Pudendal n.** | S2–4（Onuf nucleus） | 體神經 | **外括約肌**、球海綿體肌（**射精 expulsion**） |

〔111-2, 112-2〕

- 逼尿肌受體：**M2（數量最多）、M3（主導收縮）** → antimuscarinic；**β3** → mirabegron 〔110-1〕
- 中樞：**pontine micturition center（Barrington）** 協調逼尿肌收縮與括約肌放鬆；大腦皮質（額葉）抑制
- 男性性功能 **"Point and Shoot"**：勃起 = 副交感（pelvic → **cavernous n.**，走攝護腺後外側 NVB → 神經保留根除術保留之）；emission = 交感；expulsion = 體神經 〔112-2, 113-2〕

### 1.2 血管解剖

- 睪丸三條動脈：**testicular a.（aorta）**、**deferential a.（vesical a.）**、**cremasteric a.（inferior epigastric a.）** 〔115-2〕
- 睪丸靜脈：**右 → IVC（斜角）；左 → 左腎靜脈（直角）** → varicocele 好發**左側**；**右側或突發 varicocele → 想後腹腔腫瘤/RCC IVC 栓塞** 〔115-2〕
- 男性尿道（由外而內）：penile → bulbar → **membranous（外括約肌）** → prostatic（**精阜 verumontanum** = TURP 遠端界線）→ 膀胱頸 〔113-2〕

### 1.3 攝護腺分區

| 區域 | 比例 | 重點 |
|---|---|---|
| **Peripheral zone** | 70% 腺體 | **攝護腺癌 70%**；後側 → **DRE 可觸及** |
| **Transition zone** | 5–10% | **BPH 起源**；癌 20% |
| Central zone | 25% | 包圍射精管；癌 10% |
| Anterior fibromuscular stroma | — | 無腺體 |

〔114-2, 115-1〕

### 1.4 血尿評估

| 情境 | 想到 |
|---|---|
| **老人無痛肉眼血尿** | **泌尿上皮癌（膀胱、上泌尿道）**、RCC → 直到證明不是 |
| 年輕女性 + 頻尿急尿排尿痛 | **膀胱炎** 〔111-1〕 |
| 腰部絞痛 + 血尿 | **結石** |
| 兒童 | **腎絲球腎炎**（IgA、PSGN）〔110-1〕 |
| 起始血尿 / 終末血尿 / 全程血尿 | 尿道 / 膀胱頸、攝護腺 / 膀胱以上 |
| **條狀血塊（ureteral cast）** | **上泌尿道出血** 〔111-2〕 |

- Hematuria workup：UA（排除 dysmorphic RBC、cast、蛋白尿 → 腎內科）、**膀胱鏡**（下泌尿道）、**CT urography**（上泌尿道）、cytology（對 high-grade/CIS 較敏感）
- **腎功能差（Cr 3.0）→ 避免碘顯影 → retrograde pyelography** 〔111-2〕
- BPH 可造成血尿（攝護腺血管增生，5-ARI 可治）

### 1.5 影像

| 檢查 | 用途 |
|---|---|
| **NCCT** | **腎絞痛首選**（敏感度 > 95%，幾乎所有結石可見；indinavir 例外）〔114-2〕 |
| 超音波 | 水腎、孕婦、兒童第一線、腎腫瘤初篩、陰囊 |
| KUB | 追蹤不透光結石；**medullary nephrocalcinosis**（MSK、dRTA、hyperPTH）〔115-2〕 |
| CT urography | 血尿、上泌尿道腫瘤 |
| MAG3 diuretic renogram | 水腎是否**真阻塞**、分腎功能 |
| DMSA | 腎皮質結疤（兒童 UTI） |
| VCUG | VUR、PUV |
| **RUG** | 尿道外傷（尿道口出血） |

## 二、泌尿道結石

### 2.1 形成機轉

- **促進劑**：Ca、**oxalate**、**uric acid**、cystine、**matrix**、低尿量、尿 pH 異常 〔111-1〕
- **抑制劑**：**citrate（最重要）**、**magnesium**、Tamm-Horsfall protein、pyrophosphate、nephrocalcin 〔111-1, 112-1〕
- **Randall's plaque**：腎乳頭間質磷酸鈣沉積 → **idiopathic calcium oxalate** 結石的起點 〔112-1〕

### 2.2 依成分

| 成分 | 比例 | 尿 pH | KUB | 結晶 | 病因 | 處置 |
|---|---|---|---|---|---|---|
| **Calcium oxalate** | 70–80% | 不受影響 | 不透光 | 信封狀/啞鈴 | 高尿鈣、**高草酸尿（Crohn's、腸繞道）**、低檸檬酸尿 | 喝水、thiazide、K citrate、**不要限鈣**（限鹽、限動物蛋白） |
| Calcium phosphate | ~10% | **鹼性** | 不透光 | 無定形 | **HyperPTH、dRTA**、topiramate | 治療病因 |
| **Uric acid** | 5–10% | **酸性 < 5.5** | **透光**（CT 可見） | 菱形 | **持續酸性尿**（代謝症候群、DM、腹瀉）；**多數血尿酸正常** | **K citrate 鹼化 → 可溶解**、allopurinol 〔113-2〕 |
| **Struvite** | 5–10% | **鹼性 > 7** | 淡 | **Coffin-lid** | Urease 菌：**Proteus（最常見）**、Klebsiella 〔115-1〕 | **完全清除（PCNL）** + 抗生素；易形成**鹿角狀** |
| **Cystine** | 1–2% | 酸性 | 毛玻璃 | **六角形** | Cystinuria（AR，COLA）；年輕、家族史 | 喝水 > 3 L、鹼化 pH > 7、tiopronin |
| 藥物性 | 少 | — | **Indinavir：CT 也看不到** | — | Indinavir、atazanavir、triamterene | 停藥 |

- 高復發風險（兒童、家族史、非鈣結石、hyperPTH、RTA、腸道疾病、雙側/孤腎）→ **24 小時尿液代謝評估**

### 2.3 臨床與診斷

- 輸尿管三處狹窄：UPJ、跨髂血管、**UVJ（最常卡）**
- 腎絞痛：腰痛放射至腹股溝/陰囊/陰唇、噁心嘔吐、血尿；**NCCT** 診斷
- 膀胱結石 → 想 **BOO（BPH）**
- **完全阻塞 > 2 週開始不可逆損傷，約 1 個月後 1/3 病人永久損傷** → 不可無限期觀察 〔112-2〕

### 2.4 治療

!!! danger "阻塞 + 感染 = 泌尿急症"
    發燒、低血壓、白血球高 + 阻塞性結石 → **緊急引流（double-J stent 或 PCN）+ 抗生素**，**不可先碎石**（會加重菌血症）；感染控制後再處理結石。〔110-1, 115-2〕

| 結石 | 首選 |
|---|---|
| < 5 mm | 多自排（~70–80%）；止痛、喝水 |
| 5–10 mm 遠端輸尿管 | **MET（tamsulosin）** |
| 輸尿管 > 10 mm | **URS** / ESWL |
| 腎 < 2 cm | **ESWL / RIRS（flexible URS）** |
| **腎 > 2 cm、鹿角狀** | **PCNL** 〔113-1〕 |
| **無法停抗凝** | **RIRS（出血最少）** 〔110-2〕 |

- **ESWL 禁忌**：**懷孕**、未矯正凝血異常、未控制 UTI、遠端阻塞、**結石附近動脈瘤**；肥胖、骨骼畸形只降低成功率/定位困難 〔111-2〕
- **孕婦結石**：超音波（± MRI）；合併感染 → **stent/PCN**；**ESWL 絕對禁忌** 〔110-1〕
- 解除阻塞後注意 **post-obstructive diuresis**

### 2.5 水腎（Hydronephrosis）

- 擴張 ≠ 阻塞 → **MAG3 diuretic renogram** 判斷
- 單側：結石、腫瘤、UPJO；雙側：**BPH/BOO、PUV**、骨盆腫瘤、懷孕
- PE：**CVA knocking tenderness**、flank mass、恥骨上膨隆
- **膀胱癌 + hydronephrosis → 想 MIBC**；腫瘤侵犯輸尿管開口 → 優先 PCN

## 三、泌尿道感染

### 3.1 分類

| | 單純性 | 複雜性 |
|---|---|---|
| 對象 | 非孕婦、無結構/功能異常的女性 | **男性、孕婦**、兒童、**導管、阻塞、結石、神經性膀胱、VUR**、DM、免疫抑制 〔112-2〕 |
| 菌 | **E. coli**（80%）、S. saprophyticus | E. coli、Klebsiella、Proteus、Pseudomonas、Enterococcus |

- 上行性感染：**糞便菌 → 會陰 → 尿道口周圍定殖 → 膀胱** 〔110-2〕

### 3.2 臨床型態

| | 膀胱炎 | 腎盂腎炎 |
|---|---|---|
| 症狀 | 頻尿、急尿、排尿痛、恥骨上痛、血尿；**無發燒** 〔110-1〕 | **發燒**、畏寒、**腰痛**、CVA knocking |
| 療程 | Nitrofurantoin 5 天、TMP-SMX 3 天、fosfomycin 單劑 | **7–14 天**（FQ 7 天、β-lactam 10–14 天）〔115-1〕 |

- **ESBL**：ertapenem（QD，不涵蓋 Pseudomonas/Acinetobacter）vs imipenem（涵蓋 Pseudomonas、seizure 風險）

### 3.3 抗生素治療失敗

| 類型 | 定義 | 主因 |
|---|---|---|
| **Unresolved bacteriuria** | 治療中未清除 | **細菌抗藥性（最常見）**、雙菌、腎功能差、乳突壞死 〔110-2〕 |
| Bacterial persistence | 同菌復發 | 泌尿道內病灶：**感染性結石**、慢性攝護腺炎、異物 |
| Reinfection | 新菌 | 會陰定殖 |

### 3.4 兒童 UTI

- **< 1 歲（尤其未割包皮）男 > 女**；之後女 > 男 〔110-2〕
- 發燒性 UTI → 腎盂腎炎 → **腎臟結疤（DMSA）** → 高血壓、CKD
- 評估：腎臟超音波；反覆或異常 → VCUG（VUR）

### 3.5 Fournier gangrene

- 會陰/生殖器**壞死性筋膜炎**；**DM**、酒精、免疫低下、尿道狹窄/外傷、肛周膿瘍
- 沿 **Colles fascia → Scarpa fascia（淺層筋膜）** 蔓延；**睪丸通常不受影響**（獨立血流）
- 多菌混合；CT 見**皮下氣體** → **緊急廣泛清創 + 廣效抗生素** 〔112-2, 115-1〕

### 3.6 攝護腺炎

- 急性細菌性：發燒、會陰痛、**攝護腺劇烈壓痛（禁 massage）**；FQ 2–4 週
- **攝護腺炎/UTI 使 PSA 上升** → 先治療，**4–6 週後再驗 PSA** 〔111-2〕

## 四、泌尿腫瘤

### 4.1 腎細胞癌（RCC）

- **危險因子**：**抽菸（最大）**、肥胖、高血壓、**長期透析的後天性囊腫腎（ACKD）**、VHL、TSC、職業（三氯乙烯） 〔113-2〕
- 分子：clear cell（75%）**3p 缺失、VHL → HIF↑ → VEGF↑**
- 臨床：多為偶然發現；典型三主徵（血尿、腰痛、腫塊）< 10%
- **Paraneoplastic** 〔112-2〕

| 症候 | 機轉 |
|---|---|
| **高血鈣** | PTHrP |
| **紅血球增多** | EPO |
| 高血壓 | Renin |
| **Stauffer syndrome** | 無肝轉移的肝功能異常 |
| 其他 | 發燒、貧血、Cushing、cachexia |

- **IVC tumor thrombus**：雙下肢水腫、**右側/突發 varicocele**、Budd-Chiari、肺栓塞、右心房腫塊；仍可手術（nephrectomy + thrombectomy） 〔114-1〕
- **診斷：顯影 CT/MRI（enhancement > 15–20 HU）即可**，多**不需術前切片** 〔114-2〕
- 治療：T1a（< 4 cm）→ **partial nephrectomy**（RENAL score 評估複雜度）；大/中央 → radical nephrectomy；小腫瘤老人 → active surveillance / ablation
- **RENAL score**：**R**adius、**E**xophytic/endophytic、**N**earness to collecting system、**A**nterior/posterior、**L**ocation to polar lines 〔115-1〕
- **轉移性 RCC**：**IMDC 6 項**（KPS < 80%、診斷到治療 < 1 年、Hb 低、Ca 高、neutrophil 高、platelet 高）〔113-1〕；第一線 **ICI（pembrolizumab/nivolumab）± VEGF-TKI**；TKI 副作用以**高血壓**、腹瀉、hand-foot syndrome 為主；mTOR inhibitor（temsirolimus、everolimus） 〔110-1〕

### 4.2 腎臟良性腫瘤與囊腫

- **Angiomyolipoma（AML）**：**巨觀脂肪（CT 負 HU、超音波高回音）**；**TSC**；> 4 cm 出血風險（Wunderlich）→ 栓塞/mTORi/部分切除 〔110-1, 114-2〕
- Oncocytoma：central stellate scar、spoke-wheel；影像難與 RCC 區分
- **Bosniak 囊腫分類** 〔115-1, 115-2〕

| 類別 | 特徵 | 惡性率 | 處置 |
|---|---|---|---|
| I | 單純、薄壁、無隔、無鈣化 | ~0% | 不追蹤 |
| II | 少量細隔、細鈣化、< 3 cm 高密度 | ~0% | 不追蹤 |
| IIF | 較多細隔、輕度增厚、較多鈣化 | ~5% | **追蹤** |
| III | **增厚不規則且顯影的壁/隔** | ~50% | 手術/監測 |
| IV | **顯影的軟組織結節** | ~90% | **手術** |

### 4.3 泌尿上皮癌（膀胱癌）

- **危險因子**：**抽菸（最重要）**、芳香胺（染料、橡膠）、cyclophosphamide（acrolein）、**馬兜鈴酸**、砷（烏腳病地區）、骨盆放療
- 病理：**urothelial carcinoma > 90%**；**SCC ← 慢性發炎（血吸蟲、長期導尿、結石）**；腺癌 ← urachus、膀胱外翻 〔110-2〕
- 表現：**無痛肉眼血尿**；**CIS 常以刺激症狀（頻尿、急尿）表現** 〔110-2, 112-1〕
- **分期關鍵 = detrusor muscle（T2）**：NMIBC（Ta、T1、CIS）怕**復發**；MIBC 怕**轉移**
- **T stage 靠 TURBT 病理**（**必須取到 detrusor muscle**）；影像輔助 〔114-1〕

#### TURBT 流程

- 術前：CBC、凝血、腎功能、**UA + culture（UTI 先治療）**、cytology、**CT urography**、停抗凝
- 風險：出血、**膀胱穿孔**、obturator jerk、TUR syndrome
- 術後：**24 h 內單次化療灌注**（MMC/gemcitabine；穿孔/大出血禁用；**BCG 不可立即灌**）
- **Re-TURBT（2–6 週）**：切除不完全、**無肌肉層**、T1、high grade

#### 治療

| 風險 | 處置 |
|---|---|
| 低風險 NMIBC | TURBT + 單次化療灌注 |
| 中風險 | + 化療灌注維持 |
| **高風險 NMIBC（T1 high grade、CIS）** | **BCG induction + maintenance** 〔112-1〕；BCG 失敗 → radical cystectomy |
| **MIBC** | **Cisplatin-based neoadjuvant chemo → radical cystectomy + PLND**；或 trimodality（保膀胱） 〔111-1〕 |
| 轉移 | **Enfortumab vedotin + pembrolizumab**（第一線）；FGFR3 → erdafitinib |

- MIBC **合併 hydronephrosis = 預後差**；腎功能差 → **ileal conduit**（不做 orthotopic neobladder） 〔111-1〕

### 4.4 上泌尿道泌尿上皮癌（UTUC）

- 台灣比例特別高（**馬兜鈴酸**、砷）；Lynch syndrome
- **High-risk → radical nephroureterectomy + bladder cuff excision** 〔110-2〕
- Low-risk（低惡性、< 2 cm、單發、非侵犯）或孤腎 → 內視鏡保腎
- 術後膀胱復發率 20–50% → 膀胱鏡追蹤

### 4.5 攝護腺癌

#### 篩檢與診斷

- **PSA 影響因素** 〔113-2〕

| PSA ↑ | PSA ↓ |
|---|---|
| **攝護腺炎/UTI**、導尿、膀胱鏡、切片、射精、急性尿滯留、BPH | **5-ARI（≥ 6 個月 → 數值 × 2）**、肥胖 |

- PSA 4–10 約 25–35% 為癌，> 10 約 > 50%
- 輔助指標

| 指標 | 公式 | 切點 |
|---|---|---|
| **%fPSA** | fPSA / tPSA | **< 10% 高風險**；> 25% 偏良性 |
| **PHI** | (p2PSA / fPSA) × √tPSA | **> 35 切片**；> 55 約半數為癌 |
| PSAD | PSA / 體積 | > 0.15–0.2 |

- **DRE 異常 → 不論 PSA 都要評估**；DRE 敏感度低（約 40–50%）、常低估體積 〔112-1, 115-1〕
- **MRI first（PI-RADS）**：1–2 + PSAD 低 → 追蹤；3 → 依 PSAD/PHI；**4–5 → targeted + systematic biopsy**；MRI 價值在高 NPV（~90%）
- Transperineal biopsy 感染風險低於 transrectal
- **未確診不可治療** 〔110-1〕

#### 分級與風險

- **Grade Group**：GG1 = 3+3、GG2 = 3+4、GG3 = 4+3、GG4 = 8、GG5 = 9–10
- 低風險（GG1、PSA < 10、T1–T2a）→ **active surveillance**；高風險（PSA > 20、GG4–5、T3）
- Active surveillance（保留治癒機會）≠ watchful waiting（餘命短，只緩和）
- 骨轉移為**成骨性（osteoblastic）**、ALP↑ 〔115-1〕

#### 治療

| 情境 | 治療 |
|---|---|
| 局限性、預期壽命 > 10 年 | **Radical prostatectomy 或 radiotherapy**（± ADT）〔113-1〕 |
| 低風險 | Active surveillance |
| 轉移性（mHSPC） | **ADT + ARPI（abiraterone、enzalutamide、apalutamide、darolutamide）± docetaxel** |
| CRPC | **持續 ADT** + 換藥 |

- **TURP 不是根除手術**；**nerve-sparing** 保留 cavernous n. 〔113-1, 113-2〕
- **ADT**：睪丸切除 = LHRH agonist = antagonist（效果相當） 〔113-1〕
    - **LHRH agonist**（leuprolide、triptorelin）：受體 downregulation；**第 1–2 週 flare**（骨痛、尿路阻塞、脊髓壓迫）→ 合併 **bicalutamide**
    - **Antagonist**（degarelix、relugolix）：無 flare、快速達 castration（T < 50 ng/dL）
    - 副作用：熱潮紅、ED、**骨鬆**、代謝症候群、心血管
- 攝護腺癌**脊椎轉移 + 急性下肢無力/尿滯留 → cord compression → 立即 dexamethasone** → MRI → 放療/手術

### 4.6 睪丸癌

- 危險因子：**隱睪症**（含對側）、家族史、Klinefelter、對側睪丸癌
- **Germ cell tumor 95%**：seminoma（最常見、放化療敏感） vs NSGCT（**choriocarcinoma 早期血行轉移**、hCG↑；yolk sac AFP↑；embryonal） 〔111-1〕
- 腫瘤標記：**AFP（seminoma 不會升高）**、β-hCG、LDH
- 淋巴轉移 → **腹主動脈旁/後腹腔淋巴結**（非腹股溝）；**radical inguinal orchiectomy（不可經陰囊）** 〔111-1〕

### 4.7 陰莖癌

- **SCC > 95%**；危險因子：**包莖/未割包皮**、**HPV 16/18**、抽菸、慢性發炎 〔112-1〕
- CIS：**erythroplasia of Queyrat（龜頭）**、Bowen disease（陰莖幹）
- 淋巴 → **腹股溝 → 骨盆**
- **Tis/Ta/T1a 低惡性 → 器官保留**（circumcision、雷射、Mohs、局部切除、topical）；大範圍才 penectomy 〔113-1〕

### 4.8 腎上腺腫瘤

#### Incidentaloma 評估

- **所有偶發腎上腺腫瘤都要功能評估** 〔115-2〕

| 檢查 | 排除 |
|---|---|
| **1 mg overnight dexamethasone suppression** | Cushing / autonomous cortisol |
| **Plasma free / urine fractionated metanephrines** | Pheochromocytoma |
| **Aldosterone/renin ratio**（高血壓或低血鉀時） | Primary aldosteronism |

- 影像：**HU < 10（無顯影）或 washout 良好 → adenoma**
- **切除適應症**：**有功能（不論大小）**、**> 4–6 cm**、影像可疑 〔114-2〕
- 腹腔鏡腎上腺切除為標準；腎上腺切片幾乎不做（須先排除 pheo）
- **Primary aldosteronism**：高血壓 + 低血鉀 → ARR 篩檢 → 確認試驗 → CT → **adrenal vein sampling** 分側 → 單側切除/雙側 spironolactone 〔115-2〕

#### 各疾病

- **Cushing**：最常見為 **ACTH 依賴（垂體 Cushing disease）→ 雙側增生**；高血壓、向心性肥胖；**雙側腎上腺切除 → 終身補充 glucocorticoid + mineralocorticoid**、Nelson syndrome；**腎上腺癌：mitotane** 〔110-1〕
- **Pheochromocytoma**：「**10% rule**」— 10% 腎上腺外（→ **90% 在腎上腺**）、雙側、惡性、兒童、MEN2（遺傳實際約 30–40%）〔112-2〕
    - 診斷：**metanephrines**；術前 **α-blocker（phenoxybenzamine）先 + 補液 → β-blocker 後**（避免 unopposed α）

## 五、良性攝護腺增生與下泌尿道症狀

### 5.1 BPH 病理

- **年齡 + 雄性素（DHT）為必要條件**；**遺傳**、雌/雄激素比例↑、生長因子、代謝症候群 〔113-1〕
- 起源 **transition zone**；增大的 TZ 壓迫**周邊區** → 形成 **surgical capsule**（術後 PZ 仍可能發生癌） 〔115-1〕
- 成分：**基質平滑肌（α1A）→ α-blocker**；**上皮（DHT）→ 5-ARI** 〔115-1〕
- **大小與症狀/阻塞程度不成正比** 〔112-1〕

### 5.2 LUTS 評估

- **IPSS**：7 題各 0–5 分 → **0–7 輕度、8–19 中度、20–35 重度**；QoL 另計 〔110-2〕
    - 儲尿症狀（**FUN**）：頻尿、急尿、夜尿
    - 排尿症狀（**WISE**）：尿流細、中斷、用力、解不乾淨
- **DRE**

| 項目 | 正常 | 異常 |
|---|---|---|
| 大小 | 20–25 g | 腫大 |
| 質地 | Rubbery | **Stony hard → 癌**；boggy → 攝護腺炎 |
| 表面 | 平滑對稱 | 結節、不對稱 → 癌 |
| 中溝 | 可觸及 | 消失 |
| 壓痛 | 無 | 劇痛 → 急性攝護腺炎（禁 massage） |

- **基本檢查**：病史、IPSS、DRE、**UA（必做）**、PSA（預期壽命 > 10 年）、uroflowmetry、PVR、voiding diary 〔111-1, 114-1〕
- **不常規**：上泌尿道影像（僅血尿、UTI、腎功能異常、結石時）、膀胱鏡（侵入性治療前選術式）；**urodynamics** 用於疑神經性膀胱、手術失敗、低壓低流 〔114-1〕
- **Terminal dribbling**（排尿末段滴狀，BOO）≠ **post-micturition dribble**（排完後才滴，尿殘留 bulbar urethra → urethral milking、PFMT）

### 5.3 夜尿（Nocturia）

- **Voiding diary 3 天** → 分型決定治療；老年夜尿最常見原因是 **nocturnal polyuria**（不是 BPH）

| 指標 | 公式 | 異常 | 意義 |
|---|---|---|---|
| 24 h 尿量 | 加總 | > 40 mL/kg | Global polyuria |
| NPi | 夜間尿量 / 24 h 尿量 | > 33%（老年） | Nocturnal polyuria |
| Ni | 夜間尿量 / 最大單次尿量 | > 1.5 | 夜間尿量 > 膀胱容量 |

- Nocturnal polyuria（CHF、水腫、OSA、晚間飲水）→ **desmopressin**（≥ 65 歲注意**低血鈉**）
- 容量下降（BOO、OAB）→ α-blocker、5-ARI、antimuscarinic、β3 agonist

### 5.4 藥物治療

| 藥物 | 機轉 | 重點 |
|---|---|---|
| **α1-blocker** | 放鬆攝護腺/膀胱頸平滑肌（**α1A**） | 數天起效；**tamsulosin、silodosin 為 α1A 選擇性**；副作用：姿勢性低血壓、頭暈、**逆行性射精**、鼻塞、**IFIS**（白內障手術） 〔110-2〕 |
| **5-ARI** | 阻斷 T → **DHT** | **6 個月**達最大效果（體積 ↓ 30%）；**只對大攝護腺（> 30–40 mL）有效**；降低尿滯留/手術；PSA 減半；性功能副作用 〔115-2〕 |
| Antimuscarinic | M2/M3 | BPH + OAB（PVR < 150–200 mL）；老人注意**認知**（trospium 不過 BBB） |
| **β3 agonist** | Mirabegron、vibegron | 老人 OAB 較安全；mirabegron 注意高血壓 |
| PDE5i（tadalafil 5 mg） | — | BPH + ED |

- **α-blocker + 5-ARI 合併**（大攝護腺、中重度症狀）→ 降低進展最多

### 5.5 手術治療

- **絕對適應症**：**反覆尿滯留、反覆 UTI、反覆肉眼血尿、膀胱結石、BPH 導致腎功能受損**、大憩室；藥物失敗/症狀嚴重為相對 〔112-2〕
- **TURP（金標準）**：尿流改善最好最持久 〔112-2〕
    - **TUR syndrome**：單極電刀用低張 glycine 灌流液大量吸收 → **稀釋性低血鈉**、體液過多 → 噁心、意識混亂、**高血壓 + 心搏過緩**、視覺障礙 → 雙極（NS）可避免
    - 併發：逆行性射精（最常見）、尿道狹窄、尿失禁（少）
- 其他：**HoLEP**（大攝護腺、可得病理）、**綠光雷射 PVP**（532 nm、**出血少、適合抗凝**、無 TUR syndrome；**無病理標本 → 術前排除癌**）、simple prostatectomy（> 80–100 mL）、**Urolift / Rezum**（保留射精）

### 5.6 尿失禁與膀胱過動

| 類型 | 機轉 | 治療 |
|---|---|---|
| **Stress** | 括約肌/骨盆底支撐不足（咳嗽漏尿） | **PFMT（第一線）** → **mid-urethral sling** |
| **Urge / OAB** | 逼尿肌過動 | 行為治療 → **antimuscarinic / β3 agonist** → botox 膀胱注射、sacral neuromodulation 〔113-2〕 |
| Overflow | 阻塞或逼尿肌無力 | 解除阻塞、CIC |
| Functional | 認知/行動障礙 | 定時如廁 |

- **Pelvic floor magnetic stimulation**：刺激 pudendal/S2–4；用於 SUI、OAB、攝護腺切除後尿失禁；禁忌：節律器、骨盆金屬、懷孕

## 六、神經性膀胱

### 6.1 病灶位置與型態

| 病灶 | 例 | 逼尿肌 | 括約肌協調 | 表現 |
|---|---|---|---|---|
| **橋腦以上** | 中風、PD、失智、腦傷 | **過動（DO）** | **協調正常（無 DSD）** | 頻尿、急尿、急迫性尿失禁（**儲尿障礙、膀胱因素**）〔112-1〕 |
| **橋腦–薦髓之間** | SCI、MS、橫斷性脊髓炎 | 過動 | **DSD** | 高壓、VUR、上泌尿道損傷 |
| **薦髓（S2–4）/周邊** | Cauda equina、MMC、**DM**、**骨盆根治手術** | **無收縮（areflexia）/ 收縮力低下（DU）** | — | 尿滯留、溢流 〔111-1, 114-1〕 |

- **Autonomic dysreflexia**：**T6 以上** SCI；膀胱脹 → 血壓驟升、心搏過緩、頭痛、平面以上潮紅冒汗 → 坐起、導尿 〔110-2〕
- **Diabetic cystopathy**：**膀胱感覺↓（最早）** → 容量↑ → 收縮力↓ → PVR↑ → 定時排尿、CIC 〔114-2〕
- 逼尿肌收縮力低下（DU）：DM、骨盆根治手術（radical hysterectomy、APR）、cauda equina、長期 BOO、老化；**結石不會** 〔114-1〕

### 6.2 治療原則

- 目標：**保護上泌尿道（低壓儲尿）> 尿控 > 生活品質**
- **Detrusor leak point pressure > 40 cmH₂O → 上泌尿道損傷高風險** 〔114-2〕
- **CIC（間歇性清潔導尿）+ antimuscarinic** 為基礎；botox；augmentation cystoplasty
- **神經性膀胱合併續發性 VUR → 先處理膀胱（CIC + antimuscarinic），不先做輸尿管手術** 〔111-2〕

## 七、男性學

### 7.1 勃起生理

- **NO（神經 nNOS、內皮 eNOS）→ guanylate cyclase → cGMP → PKG → 細胞內 Ca²⁺↓ → 海綿體平滑肌鬆弛** → 動脈流入、白膜下靜脈受壓（veno-occlusion） 〔114-2〕
- **PDE5** 分解 cGMP；**dopamine 作用於中樞**（非海綿體）
- 勃起分期：flaccid → latent → **tumescence（血流最大）** → full → **rigid（坐骨海綿體肌收縮，內壓 > 收縮壓 → 動脈血流幾乎停止）** → detumescence 〔115-1〕

### 7.2 勃起功能障礙（ED）

- 病因：**血管性最常見**（ED 是心血管疾病的前哨徵兆）、神經性、內分泌（低睪固酮）、藥物、心因性
- **PDE5 inhibitor**（sildenafil、tadalafil）：抑制 cGMP 分解，**需性刺激** 〔110-2〕
    - **絕對禁忌：nitrate**（嚴重低血壓）
    - 慎用：近期 MI/中風（6 個月內）、不穩定心絞痛、低血壓、**嚴重 AS/HOCM**、嚴重肝腎衰竭、NAION 〔110-1〕
    - 交叉抑制 PDE6 → 藍視；CYP3A4 誘導劑（rifampin）只降低藥效
- 第二線：intracavernosal injection（PGE1）、真空吸引器；第三線：**penile prosthesis**
- **Penile duplex US**（注射 PGE1 後）〔111-1〕

| 指標 | 正常 | 異常 |
|---|---|---|
| **PSV（cavernous a.）** | **> 30–35 cm/s** | < 25 → 動脈功能不全 |
| EDV | < 5 cm/s | > 5 → venous leak |
| **RI** | **> 0.9（閉鎖正常）** | < 0.75 → venous leak |

### 7.3 射精障礙與 Peyronie's disease

- **早洩**：**dapoxetine（短效 SSRI，↑ serotonin）**、局部麻醉劑、行為治療 〔112-1〕
- 逆行性射精：α-blocker、TURP、DM、RPLND
- **Peyronie's disease**：白膜微創傷後纖維斑塊 → 彎曲、勃起痛、ED；相關 **Dupuytren**、DM；急性期（疼痛、變化）→ 保守/**collagenase 注射**；穩定期（3–6 個月不變）→ 手術（plication、grafting、prosthesis） 〔113-1〕

### 7.4 男性不孕

| 類型 | 荷爾蒙 | 睪丸 | 例 |
|---|---|---|---|
| Pre-testicular | **FSH/LH↓、T↓** | 小 | Kallmann、垂體腫瘤、**外源性睪固酮** |
| Testicular（非阻塞性無精） | **FSH↑** | 小、軟 | Klinefelter、Y 染色體微缺失、隱睪、化療 |
| **Post-testicular（阻塞性無精）** | **正常** | **正常大小、副睪飽滿** | CBAVD（CFTR）、輸精管結紮、感染 |

- **阻塞性無精 → 取精**：MESA/PESA（副睪）、TESE（睪丸）、輸精管；**儲精囊不儲存精子** 〔114-1〕
- **外源性睪固酮 → 抑制 LH/FSH → 睪丸內睪固酮↓ → 精子生成↓** → **想生育者禁用**；改用 **hCG、clomiphene（SERM）、aromatase inhibitor** 〔113-2〕
- **Varicocele** 〔111-2〕
    - **最常見可手術矯正的男性不孕原因**；一般族群 15%、原發不孕 35–40%
    - **左側** 90%；bag of worms、Valsalva 加重
    - 精液：數量、活動力、型態皆異常（stress pattern）
    - 治療：**microsurgical subinguinal varicocelectomy（成功率最高、復發/水囊腫最少）**；栓塞為替代

## 八、小兒泌尿

### 8.1 先天異常

| 異常 | 重點 |
|---|---|
| **UPJO** | **產前水腎最常見原因**；MAG3 判斷阻塞；pyeloplasty |
| **PUV** | **男嬰雙側水腎 + 厚壁膀胱 + 後尿道擴張** → **VCUG**；內視鏡切開；Potter sequence |
| **Duplex ureter（Weigert-Meyer）** | **Upper pole → 開口下內側（ectopic）→ 阻塞、ureterocele**；女孩異位開口於尿道/陰道 → **持續滴尿**；**lower pole → 開口上外側 → VUR** 〔114-2〕 |
| **Hypospadias** | 尿道開口位於腹側；**不造成水腎** 〔111-2〕 |
| Cryptorchidism | 6 個月未降 → **orchiopexy（6–18 月）**；不孕、睪丸癌風險（含對側） |

- **Hypospadias 手術** 〔114-1〕
    - 時機 **6–18 個月**；**不可先割包皮**（重建材料）
    - **TIP（Snodgrass）保留 urethral plate**；嚴重 chordee 需矯正（影響成功率）
    - 再手術間隔 ≥ 6 個月
    - 合併隱睪 → 排除 **DSD**

### 8.2 膀胱輸尿管逆流（VUR）

- **原發性**：**UVJ 先天缺陷（黏膜下隧道太短）**；續發性：PUV、神經性膀胱、BBD（高膀胱壓） 〔113-1〕
- **International grading（I–V）** 〔114-1〕

| Grade | 範圍 |
|---|---|
| I | 只到輸尿管 |
| II | 到腎盂，無擴張 |
| III | 輕–中度擴張 |
| IV | 中度擴張、腎盞變鈍 |
| V | 嚴重擴張迂曲 |

- 治療：低級別多自癒 → 觀察 ± 預防性抗生素；**BBD 合併 VUR → 先治療排尿/排便功能** 〔113-1〕；手術：**ureteral reimplantation（隧道長:徑 = 5:1）**、endoscopic Deflux 注射 〔114-1〕

### 8.3 Wilms tumor（Nephroblastoma）

- 最常見兒童腎腫瘤（約占兒童癌症 5–6%）；2–5 歲**無痛腹部腫塊（不過中線）**、血尿、高血壓
- 基因：**WT1（11p13）**、WT2（11p15）；症候群：**WAGR、Denys-Drash、Beckwith-Wiedemann**；約 10% 合併先天異常
- **最常轉移至肺** 〔111-2〕
- 對比 neuroblastoma：腎上腺、**過中線**、鈣化、catecholamine↑、<2 歲

### 8.4 遺尿（Enuresis）

- 定義 **≥ 5 歲**；機轉：**夜間尿量、夜間膀胱容量、睡眠中喚醒能力**三者不匹配；遺傳相關
- 每年自癒約 15% → **< 5–6 歲不需積極治療**
- 第一線：**enuresis alarm**（長期效果佳）或 **desmopressin**（快、停藥易復發）〔115-2〕

## 九、泌尿急症與外傷

### 9.1 泌尿外傷總則

- 約 10% 外傷合併泌尿生殖傷；**血行動力不穩 → 先急救/手術，不送影像** 〔113-2〕
- **血尿程度與損傷嚴重度不一定相關**（腎蒂撕裂/UPJ 斷裂可無血尿） 〔115-1〕

### 9.2 腎臟外傷（AAST）

| Grade | 表現 |
|---|---|
| I | 挫傷、**被膜下血腫（最常見）** |
| II | 裂傷 < 1 cm，無尿漏 |
| III | 裂傷 > 1 cm，**無尿漏** |
| **IV** | **集尿系統受傷（尿漏）**、節段血管傷、活動性出血 |
| V | 腎門撕脫、粉碎腎 |

〔114-1〕

- **多數保守**（含多數 IV）；不穩定、擴大血腫、腎門撕脫 → 手術/栓塞
- 晚期併發症：**urinoma**（集尿系統傷）、**Page kidney / 腎血管性高血壓**、AV fistula

### 9.3 膀胱與尿道外傷

| | Intraperitoneal rupture | Extraperitoneal rupture |
|---|---|---|
| 機轉 | **膀胱脹時下腹鈍擊** → 頂部破裂 | **骨盆骨折** |
| 影像 | 顯影劑勾勒腸環 | 火焰狀滲漏於膀胱周圍 |
| 治療 | **手術修補** | **Foley 引流 10–14 天**（多數） |

- 診斷：**CT/逆行性膀胱攝影（retrograde cystogram）**為黃金標準 〔112-1, 115-1〕
- **尿道外傷**：**尿道口出血**、陰囊/會陰血腫、高位攝護腺 → **禁盲放 Foley → 先做 RUG** → 恥骨上膀胱造口 〔113-2, 115-1〕
    - 後尿道（membranous）← 骨盆骨折；前尿道（bulbar）← 騎跨傷（straddle）

### 9.4 急性陰囊

| | **Testicular torsion** | Torsion of appendix testis | Epididymitis |
|---|---|---|---|
| 年齡 | **青少年**（新生兒第二高峰） | 7–12 歲 | 性活躍年輕人、老人 |
| 發作 | 突發劇痛、噁心嘔吐 | 漸進、上極痛 | 漸進、合併頻尿/排尿痛、發燒 |
| Cremasteric reflex | **消失** | 存在 | 存在 |
| **Prehn sign**（抬高） | 不緩解 | — | **緩解** |
| 其他 | 睪丸高位、橫躺（bell-clapper） | **Blue dot sign** | 局部溫度高 |
| 處置 | **緊急手術探查**（勿因影像延遲） | 保守 | 抗生素 |

〔111-1, 114-1, 114-2〕

- 扭轉：**6 小時內救回率 > 90%**；影像首選 **color Doppler 超音波**（非 MRI、非 CT）；手術 detorsion + orchiopexy + **對側固定**；手法復位「open the book」
- Varicocele 為慢性鈍痛，非急性陰囊常見原因 〔114-1〕

### 9.5 急性尿滯留

- 術後尿滯留危險因子：**男性/BPH**、老年、**脊髓/硬膜外麻醉**、**肛門直腸/疝氣/骨盆手術**、大量輸液、opioids、anticholinergics 〔113-1〕
- 處置：導尿（失敗 → 恥骨上造口）；BPH 者 α-blocker 後 trial without catheter

## 十、腎臟移植

### 10.1 移植前評估

- **免疫風險**：**PRA 高/DSA**（輸血、懷孕、前次移植致敏）、**ABO 不相容**、再次移植、HLA mismatch 多 → **thymoglobulin** 誘導；低風險 → basiliximab 〔112-1〕
- **Native nephrectomy 適應症**：**腫瘤**、**反覆感染（結石、VUR）**、**有症狀或過大的 ADPKD**、藥物無法控制的高血壓、大量蛋白尿；**可控制的高血壓不需切** 〔112-1〕
- **移植後原病復發** 〔112-2〕

| 疾病 | 復發 |
|---|---|
| **FSGS** | 最常、最快；預後差 |
| aHUS、MPGN/C3G | 常見 |
| IgA nephropathy | 組織學常復發 |
| **SLE** | **可復發**（較少致移植腎失敗）；需疾病不活動期移植 |
| **Primary hyperoxaluria** | 會復發 → **肝腎合併移植**（肝是缺陷酵素來源） |
| **ADPKD、Alport** | **不復發** |

### 10.2 移植後

- **DGF（ATN）vs 急性排斥**（MAG3/DTPA 腎掃描）〔115-2〕

| | DGF / ATN | 急性排斥 |
|---|---|---|
| 灌流 | **保留** | **下降** |
| 排泄 | 差 | 差 |
| 追蹤 | 逐漸改善 | 惡化 |

- 腎掃描可偵測**尿漏**、阻塞；**確診靠切片（Banff）**
- 外科併發症：**尿漏**、輸尿管狹窄、淋巴囊腫（lymphocele）、腎動脈狹窄、血栓
