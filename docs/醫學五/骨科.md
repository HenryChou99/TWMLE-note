# 骨科

!!! info "使用方式"
    本頁依 110–115 年醫師（二）醫學（五）骨科考題整理，並整合骨科實習筆記。`〔113-2〕` = 113 年第二次考過。
    對應考古題（含答案、解析）：[骨科考古題](骨科考古題.md)

## 一、骨折總論與創傷

### 1.1 理學檢查總覽

**順序：Inspection → Palpation → ROM →（Neuro）→ Special test，兩側比較。**

| 部位 | Special test | 意義 |
|---|---|---|
| Spine | **SLRT 30–70°**、cross-SLRT、**Spurling**、shoulder abduction relief、Hoffmann、Babinski、Adam forward bend | Radiculopathy、UMN、structural scoliosis 〔110-1〕 |
| Shoulder | Neer/Hawkins、painful arc 60–120°、drop arm、Jobe（empty can）、**apprehension / relocation**、**sulcus**、**Jerk / Kim** | Impingement、cuff tear、前/下/後不穩定 〔110-1, 110-2〕 |
| Wrist/Hand | **Finkelstein**、**Phalen**、Tinel、Durkan、**Watson**、Allen、Froment | De Quervain、CTS、SL instability 〔110-2〕 |
| Hip | **FABER/Patrick**（鼠蹊痛 → hip；臀痛 → SI）、**Thomas**（屈曲攣縮）、**Trendelenburg**（患側站 → 對側骨盆下降） | 〔110-2〕 |
| Knee | **Lachman**（最敏感）、pivot shift（最特異）、drawer、**posterior sag（PCL）**、varus/valgus stress、**McMurray / Apley / Thessaly**、ballottement | ACL、PCL、MCL/LCL、半月板 〔110-2, 115-2〕 |
| Ankle | Anterior drawer、talar tilt、**Thompson**、squeeze test、toe/heel walk | ATFL/CFL、Achilles、syndesmosis、S1 / L4–5 |

### 1.2 骨折分類與固定

- **兒童骨折** 〔113-2〕：**greenstick**（張力側斷、壓力側彎）、**torus/buckle**（壓力側隆起）、plastic deformation
- **Gustilo（開放性骨折）** 〔114-2〕

| Grade | 傷口 | 軟組織 / 污染 |
|---|---|---|
| I | < 1 cm | 乾淨 |
| II | 1–10 cm | 中度 |
| IIIA | > 10 cm | 可用軟組織覆蓋；**高能量、嚴重污染（農場）、槍傷、節段性骨折一律 ≥ III** |
| IIIB | — | 骨膜剝離，需皮瓣 |
| IIIC | — | **需修補血管** |

- 開放性骨折：抗生素（cefazolin ± aminoglycoside）+ tetanus + 清創；傷口在骨折旁**不一定是開放性** 〔114-2〕
- 合併血管斷裂：先**穩定骨折**（external fixator/shunt）再修補血管 〔114-2〕
- **副木 vs 石膏**：急性期先副木容許腫脹，消腫（1–2 週）後換石膏；踝固定於中立 90°；固定後疼痛加劇 → **立即拆開**；用室溫水 〔110-1〕
- **Tension band**：把張力轉換為骨折面**壓縮力**（髕骨、鷹嘴突） 〔111-1〕
- **黏彈性（viscoelasticity）**：creep、stress relaxation、hysteresis、**速率依賴**；與純彈性不同 〔113-2〕

### 1.3 腔室症候群

- **5P**：**Pain out of proportion / 被動伸展痛（最早最敏感）**、Paresthesia、Pallor、Paralysis、Pulselessness（晚期）；**脈搏存在不能排除** 〔110-2, 112-1〕
- 診斷：腔室壓 **> 30 mmHg** 或 **ΔP = 舒張壓 − 腔室壓 ≤ 30 mmHg**；臨床典型即可直接 fasciotomy 〔110-2, 111-1, 113-2〕
- **Volkmann ischemic contracture**：前臂**深層屈肌**（FDP、FPL）缺血纖維化（supracondylar fracture 傷 brachial a.） 〔112-1〕
- **Crush syndrome / rhabdomyolysis**：**積極輸液（NS）**、監測尿量與 K⁺；**避免 LR（含 K⁺）** 〔110-2, 115-1〕

### 1.4 其他創傷併發症

- **Fat embolism syndrome**：長骨骨折/髓內釘後 24–72 h；**呼吸窘迫 + 意識改變 + 點狀出血**；snowstorm CXR、血小板↓；支持療法、**早期固定**預防 〔112-2〕
- **穿刺性肢體傷 hard signs**：搏動性出血、擴大血腫、**bruit/thrill**、無脈、遠端缺血 → 手術；噴血先**直接加壓** 〔113-1〕
- **Stress fracture**：多數保守；高風險部位：**股骨頸張力側（superolateral）**、前側脛骨、navicular、5th MT；female athlete triad 〔114-2〕

### 1.5 骨盆骨折

- 多數穩定 → 保守；不穩定 → 出血（後腹腔，**靜脈叢為主**）、**pelvic binder**、血管栓塞 〔111-1, 111-2〕
- **尿道口出血 → 禁放 Foley → 先做 RUG（逆行性尿道攝影）** 〔111-2, 114-2, 115-1〕
- 男性尿道傷 > 女性；神經根損傷預後**比**周邊神經差 〔114-2〕

## 二、脊椎

### 2.1 下背痛鑑別與 Red flags

!!! warning "站不起來不一定是 spine"
    老人跌倒後下背/臀部痛、**無法負重** → 先排除 **hip / pelvis fracture**（femoral neck、intertrochanteric、pubic rami、sacral insufficiency）。

| Red flag | 想到 |
|---|---|
| > 50 歲、癌症史、體重減輕、夜間痛 | **Metastasis**（T4 以上壓迫性骨折要想 malignancy） |
| 發燒、IVDU、免疫低下 | **Spondylodiscitis**、epidural abscess（*S. aureus*） |
| 外傷、骨鬆、steroid | **Fracture**（OVCF：T11–L2，MRI STIR 判新舊） |
| 尿滯留/失禁、saddle anesthesia | **Cauda equina syndrome**（emergency） |
| 年輕、晨僵、活動後改善 | **Inflammatory back pain**（AS、PsA） |

| 鑑別 | 傾向 hip | 傾向 spine |
|---|---|---|
| 疼痛 | **鼠蹊**、大腿前、膝 | 下背、沿 dermatome 放射至膝下 |
| 檢查 | **IR 痛/受限**、FABER 鼠蹊痛、log roll、患肢縮短外旋 | SLRT(+)、感覺/DTR 改變、midline 壓痛 |

### 2.2 頸椎外傷與脊髓損傷

- **Odontoid fracture（Anderson-D'Alonzo）** 〔112-1〕

| Type | 位置 | 特徵 |
|---|---|---|
| I | 尖端 avulsion | 少見、穩定 |
| **II** | **基部（腰）** | **最常見、不癒合率最高**（老人、位移大 → 手術） |
| III | 延伸入 C2 椎體 | 癒合佳、保守 |

- **Central cord syndrome**：最常見不完全損傷；**老人頸椎退化 + 跌倒過伸**；**上肢 > 下肢** 〔111-1, 113-2〕
- 上頸椎椎管寬 → 脊髓損傷較少；急救先 ABC 〔113-2〕
- **Spinal shock**：損傷平面以下反射/運動/感覺全消失；**bulbocavernosus reflex 回復 = 結束**（非 cremasteric）；結束後才能判定 complete/incomplete 〔115-2〕
- Neurogenic shock：低血壓 + **心搏過緩**（交感中斷）

### 2.3 胸腰椎骨折（Denis three-column）

| Column | 結構 |
|---|---|
| Anterior | ALL、椎體與椎間盤前 2/3 |
| **Middle** | 椎體與椎間盤後 1/3、PLL |
| Posterior | Pedicle、lamina、facet、**PLC** |

**≥ 2 柱受傷 = 不穩定；中柱是關鍵。**

| 骨折 | 機轉 | Column | 重點 |
|---|---|---|---|
| Compression | Flexion | 前 | 穩定 |
| **Burst** | Axial loading | 前 + 中 | **Retropulsion** 壓脊髓 → CT |
| **Chance** | 安全帶 flexion-distraction | 中 + 後 | **合併腹腔內臟傷** |
| Fracture-dislocation | 剪力、旋轉 | 三柱 | 最不穩定 |

- **TLICS**：morphology + PLC + neuro；**≤ 3 保守、≥ 5 手術**

### 2.4 頸椎退化

- **Cervical radiculopathy**：**Spurling**、**shoulder abduction relief sign**；C5 → 三角肌區；多數保守可改善 〔110-1〕
- **Cervical spondylotic myelopathy**：手笨拙、步態不穩、Hoffmann、Lhermitte、**inverted radial reflex**；壓迫節段反射可**減弱**、以下亢進；腹部反射正常（鑑別 ALS） 〔114-2〕
- **OPLL**：亞洲男性、**C4–6**；合併 DISH、AS；**無症狀者觀察**，進行性 myelopathy 才手術 〔114-1〕

### 2.5 腰椎：HIVD、退化與狹窄

**HIVD 機轉**：終板營養↓ → **proteoglycan↓、髓核失水** → 後外側 annular fissure → protrusion → extrusion → sequestration；機械壓迫 + **化學性發炎**（TNF-α、IL-1）

- 危險因子：**基因（最重要）**、30–50 歲、承重下屈曲 + 旋轉、久坐、**吸菸**
- **L4–5、L5–S1** 佔 90–95%；**後外側壓下一節 root（L4–5 → L5）**、far lateral 壓同一節（L4）
- 自然病程：**80–90% 在 6–12 週內改善**；sequestration 反而較易吸收；**protrusion 最常見**；MRI 診斷 〔111-2〕
- 手術：cauda equina（急診）、進行性神經缺損、保守 6–12 週無效

| Root | 無力 | 感覺 | 反射 |
|---|---|---|---|
| L4 | 膝伸直、**TA** | 內踝 | **Knee jerk ↓** |
| **L5** | **EHL**、heel walk、髖外展 | **足背**、第一趾蹼 | — |
| S1 | 蹠屈、toe walk、**腓骨長短肌** | **外踝**、足底外側 | **Ankle jerk ↓** |

〔110-2：EHL 為 L5，不是 S1〕

- **Degenerative disc disease**：MRI 退化在**無症狀者極常見**，與疼痛相關性差；坐姿/屈曲加重 〔112-1〕
- **Spinal stenosis**：**退化性最常見**（非先天）、L4–5 最常見；neurogenic claudication（前彎/坐下緩解） 〔112-2〕
- **Spondylolisthesis**：isthmic L5/S1 → 壓 **L5（出口根）**；Meyerding I < 25%、II 25–50%、III 50–75%、IV > 75%、V spondyloptosis 〔113-1〕
- **Pyogenic spondylodiscitis**：腰椎 > 胸椎、*S. aureus*；成人血行性先到**椎體終板旁**再侵犯椎間盤（disc space narrowing + 雙側終板破壞；TB 較保留椎間盤）；手術：保守無效、需取樣、神經缺損、不穩定 〔111-1〕
- 重量訓練：neutral spine 深蹲通常安全；真正風險是**承重下屈曲（butt wink）+ 旋轉**、疲勞、剛起床

### 2.6 脊椎變形

| | AIS | Congenital | Scheuermann | Klippel-Feil |
|---|---|---|---|---|
| 病因 | 原因不明，青春期女孩 | **形成失敗 / 分節失敗** | 終板軟骨內骨化異常 | 第 3–8 週**頸椎分節失敗** |
| 重點 | Adams test；Cobb、Risser | **背架無效**；**unilateral bar + 對側 hemivertebra 惡化最快 → 早期手術** | **≥ 3 相鄰椎體各楔形 ≥ 5°**、kyphosis > 45°、Schmorl nodes；**可合併側彎**、僵硬 | **低後髮際線、短頸、活動受限** |
| 合併 | — | **VACTERL**：心、腎、脊髓（MRI） | — | **腎臟異常**、Sprengel、聽損、心臟 |
| 考點 | 〔111-1〕 | 〔113-2, 115-2〕 | 〔115-1〕 | 〔113-1〕 |

- **AIS 治療**：Cobb < 20–25° 觀察；**25–40° 且骨未成熟 → 背架**；**> 40–50° → posterior spinal fusion** 〔111-1〕
- **Crankshaft phenomenon**：骨骼未成熟（Risser 0、初經前、< 10 歲）只做後側融合 → 前柱繼續生長而旋轉惡化 〔111-1, 113-2〕

## 三、肩與肘

### 3.1 肩關節解剖與不穩定

- **鎖骨（SC joint）是上肢與中軸骨骼唯一骨性連接**；scapulothoracic 為功能性關節；glenoid 約肱骨頭 1/3–1/4，穩定靠 labrum、GH ligaments（關節囊增厚）、rotator cuff 〔115-2〕

| 方向 | 檢查 | 病灶 |
|---|---|---|
| **Anterior**（最常見） | **Apprehension（外展 90° + 外旋）**、relocation | **Bankart**（前下 labrum）、**Hill-Sachs**（肱骨頭後上外） |
| **Posterior** | **Jerk（Jahnke）、Kim** | Reverse Bankart、reverse Hill-Sachs |
| Inferior / MDI | **Sulcus sign** | 關節囊鬆弛 |

〔110-1, 110-2〕

- **Anterior dislocation**：年輕人多、**越年輕再脫臼率越高**（< 20 歲 70–90%）→ 運動員考慮 Bankart repair；老人合併 cuff tear、GT fracture、**axillary n.** 損傷 〔115-1〕
- **Posterior dislocation**（癲癇、電擊）：**鎖在內收內轉、不能外轉**；X 光 **light bulb sign**；AP 易漏 → axillary view / CT 〔115-2〕

### 3.2 Anterior dislocation 合併 GT fracture

- 約 15–30% 合併；再脫臼率**較低**；復位前查 axillary n.、排除 occult humeral neck fracture → 輕柔復位
- GT 位移 **≥ 5 mm（運動員 ≥ 3 mm）→ ORIF**；< 5 mm → sling 3–4 週

| | Hill-Sachs | GT fracture |
|---|---|---|
| 機轉 | 撞 glenoid 前下緣，壓迫凹陷 | **Rotator cuff 拉扯** |
| 再脫臼 | ↑ | ↓ |

### 3.3 肱骨近端骨折與肌腱

- **Neer**：移位 > 1 cm 或成角 > 45° 才算一 part；**年輕人 4-part → ORIF**；老人 → reverse TSA / hemiarthroplasty 〔113-1〕
- **Biceps long head 斷裂 → Popeye sign**（多保守）；遠端 biceps 斷裂 → hook test、旋後無力，年輕人修補 〔111-1〕
- **Suprascapular nerve**：suprascapular notch（棘上 + 棘下）vs **spinoglenoid notch（只有棘下，排球扣球、ganglion + SLAP）**；診斷 EMG

### 3.4 肘

- **Radial head fracture（Mason）**：FOOSH；I 無位移 → 保守早期活動；II 位移 > 2 mm + **旋轉機械性阻擋** → ORIF；III 粉碎 → 置換；**loose body → 手術** 〔110-1〕
- **Elbow dislocation**：多為後脫臼；穩定者**短期固定（≤ 1–2 週）後早期活動**（防僵硬）；**terrible triad** = 後脫臼 + 橈骨頭 + coronoid 骨折 〔113-1〕
- **Fat pad sign**：看見 posterior fat pad / sail sign = 關節積血 → 隱匿性骨折 〔112-2〕
- **Monteggia（尺骨骨折 + 橈骨頭脫臼，PIN）** vs **Galeazzi（橈骨遠端 1/3 骨折 + DRUJ 脫臼）** 〔115-1〕

## 四、手與腕

### 4.1 腕骨與掌骨骨折

- **Scaphoid**：最常見腕骨骨折、FOOSH、**snuffbox 壓痛**；血流**遠端→近端** → 近端/腰部骨折易 **AVN、nonunion**（SNAC wrist）；X 光陰性先 thumb spica、MRI 〔110-1, 112-2〕

| 骨折 | 定義 |
|---|---|
| **Bennett** | 拇指掌骨基部**兩片**關節內骨折；主骨片被 **APL** 拉向近端背橈側 〔110-2〕 |
| **Rolando** | 拇指掌骨基部**粉碎性**（Y/T）關節內骨折 〔112-2〕 |
| Boxer's | 第 5 掌骨頸 |
| Colles / Smith | 橈骨遠端，遠端骨片背側（dinner fork）/ 掌側 |

- **DRUJ arthritis**：Darrach、hemiresection、**Sauvé-Kapandji**；**Adams procedure 用於 DRUJ 不穩定** 〔111-1〕
- **Kienböck disease**（月狀骨 AVN）：與 **ulnar negative variance** 相關 → **radial shortening**、capitate shortening、vascularized graft、partial fusion；**不可延長橈骨** 〔114-2〕

### 4.2 神經壓迫

| | CTS | Cubital tunnel | Guyon canal |
|---|---|---|---|
| 神經 | Median | Ulnar（肘） | Ulnar（腕） |
| 症狀 | 拇–無名指橈側麻、**夜間麻醒、flick sign** | 無名指尺側 + 小指麻；**FDP 小指無力** | 小指麻；**FDP 正常**、背側感覺正常 |
| 測試 | **Phalen**、Tinel、Durkan | **Elbow flexion test**、Froment | — |
| 考點 | 〔110-2 題組〕 | 〔111-2〕 | |

- **腕隧道內容物**：**9 條肌腱（FDS×4、FDP×4、FPL）+ median n.**；FCU、FCR 不在內 〔113-2〕
- 肘部尺神經壓迫點：arcade of Struthers、medial intermuscular septum、**cubital tunnel（Osborne ligament）**、FCU 兩頭間（111-2 官方答 arcade of Struthers）
- Arcade of Frohse → PIN（radial tunnel）
- **EMG vs NCV**：EMG（針）看 denervation（fibrillation、PSW，受傷後 2–3 週）、neuropathic vs myopathic MUAP；NCV 看傳導（**慢 = 脫髓鞘、振幅低 = 軸突**）

### 4.3 Trigger finger、De Quervain、Dupuytren

- **Trigger finger**：**A1 pulley** 增厚（MCP 掌側、distal palmar crease 痛）；DM、RA、甲狀腺低下；兒童 congenital trigger thumb（Notta's node）；治療 splint → **steroid 注射（第一線）** → A1 release，**A2、A4 不可切** 〔112-1〕

| Grade | 表現 |
|---|---|
| I | 痛、壓痛 |
| II | 卡住，可主動伸直 |
| III | 需被動扳直 |
| IV | 固定屈曲攣縮 |

- **De Quervain**：第一伸肌腔 **APL + EPB**；**Finkelstein** 〔110-2〕
- **Dupuytren**：**北歐裔男性**最常見（亞洲少）、DM、酒精；無名指 > 小指、**MCP** > PIP；MCP > 30° 或任何 PIP 攣縮（tabletop test）→ 手術/collagenase 〔115-2〕

### 4.4 肌腱損傷

| 測試 | 做法 | 陽性 |
|---|---|---|
| FDP | 固定 PIP，屈 DIP | 不能 → FDP 斷 |
| FDS | 其他手指壓直，屈 PIP | 不能 → FDS 斷 |
| Cascade / tenodesis | 休息姿勢、被動腕伸 | 該指變直 |

- **Flexor zone II（no man's land）**：A1 到 FDS 止點，FDS + FDP 同在狹窄腱鞘 → **沾黏、預後最差**；primary repair 7–10 天內、≥ 4-strand、早期活動

| | Mallet finger | Jersey finger |
|---|---|---|
| 結構 | Extensor terminal tendon | **FDP** 撕脫 |
| 機轉 | 伸直手指被撞成屈曲 | 屈曲手指被強迫伸直 |
| 姿勢 | **DIP 下垂** | 該指伸直 |
| 治療 | **DIP 伸直副木 6–8 週**（屈曲即重新計時） | **一定手術，7–10 天內** |
| 後遺 | **Swan-neck** | — |

| 變形 | 位置 | 姿勢 |
|---|---|---|
| **Boutonnière** | **Central slip**（zone III） | **PIP 屈、DIP 過伸** |
| **Swan-neck** | Mallet 未治療、volar plate 鬆、RA | **PIP 過伸、DIP 屈** |

- PIP 固定屈曲鑑別（PsA/RA）：boutonnière（**Elson test +**）、volar plate 攣縮（最常見）、pseudo-boutonnière、ankylosis、屈肌腱沾黏、locked trigger finger

### 4.5 Intrinsic muscles、斷指與先天異常

- **Intrinsic**：thenar、hypothenar、lumbricals、interossei、adductor pollicis；**FDP/FDS 為 extrinsic** 〔114-1〕

- **Syndactyly**：**第三指蹼最常見**、第一指蹼最少；complex = 骨性黏合 〔115-1〕

### 6.3 膝 OA：玻尿酸與 AMI

| HA 注射適合 | 不適合 |
|---|---|
| 輕–中度 OA（KL II–III） | **末期（KL IV）→ TKA** |
| NSAIDs 無效/禁忌 | 大量積液、急性發炎（先排除 gout、感染） |
| 想延後手術 | **關節/皮膚感染（絕對禁忌）** |

- 起效慢、持續久（vs steroid 快而短）；**健保**：保守治療累計 ≥ 6 個月無效、未達 TKA 標準；第一針起 35 天內不可同部位 NSAID/steroid 注射或復健
- **AMI（arthrogenic muscle inhibition）**：關節積液（20–30 mL 即可）/疼痛 → 脊髓 Ib inhibition、γ-loop dysfunction → **quadriceps 反射性抑制**（extensor lag）；治療：**先解除抑制（控制積液、冰敷後立即運動、TENS、NMES）再練肌力**

### 6.4 足踝外傷與骨折分類

- **Inversion + plantar flexion**：外側韌帶 **ATFL > CFL > PTFL**；內踝為壓迫側（垂直骨折），**三角韌帶撕脫是外翻/外旋機轉** 〔114-1〕
- **Lauge-Hansen：SER 最常見**；**Schatzker**：I 外側劈裂（年輕）、II 劈裂 + 塌陷（最常見）、III 純塌陷（老人）、IV 內側、V 雙髁、VI 幹骺分離 〔111-1〕
- **Lisfranc injury**：plantar ecchymosis、站立 X 光 1st–2nd MT base > 2 mm、fleck sign → ORIF / arthrodesis
- Ottawa ankle rules；Thompson test（Achilles）

### 6.5 前足：Hallux valgus 與 lesser toes

**Hallux valgus 成因**：遺傳、女性、**IMA↑**、DMAA↑、**1st ray hypermobility**、扁平足；窄頭鞋/高跟鞋為促發
**惡性循環**：medial capsule 拉長 → sesamoids 外移 → adductor hallucis 外拉 → **EHL/FHL bowstring** → abductor hallucis 移至足底 → pronation → transfer metatarsalgia

| 嚴重度 | HVA / IMA | 術式 |
|---|---|---|
| Mild | < 20° / < 11° | Distal chevron |
| Moderate | 20–40° / 11–16° | Scarf / chevron + soft tissue |
| Severe | > 40° / > 16° | Proximal osteotomy + modified McBride |
| 1st TMT hypermobility | — | **Lapidus** |
| 合併 1st MTP 關節炎 | — | 1st MTP arthrodesis |

- Akin（HV interphalangeus）；第二趾 plantar plate repair + Weil；適應症是**疼痛、穿鞋困難**（非外觀）
- **Beighton score**（9 分）：成人 **≥ 4/9** = generalized hypermobility；1st TMT instability → **Lapidus**

| | MTPJ | PIPJ | DIPJ | 特徵 |
|---|---|---|---|---|
| **Hammer toe** | 輕伸 | **屈** | 伸/中立 | 單趾（**2nd** 最常見）、PIP 背側 corn |
| **Claw toe** | **過伸** | **屈** | **屈** | 多趾雙側 → **查神經（CMT、DM）** |
| **Mallet toe** | 中立 | 中立 | **屈** | 趾尖 callus |

- 機轉：intrinsic 無力 → EDL 拉 MTP 過伸、FDL/FDB 拉 IP 屈曲；flexible → 肌腱轉移/tenotomy；rigid → resection/arthrodesis

### 6.6 後足：高弓足、扁平足與 PTTD

- **Cavus foot**：**約 2/3 為神經肌肉病因，最常見 CMT**；雙側 → CMT、Friedreich；**單側 → spinal cord lesion（必做 MRI）**
    - CMT 機轉：peroneus brevis 弱 < tibialis posterior → hindfoot varus；TA 弱 < peroneus longus → 1st ray plantarflexed
    - **Peek-a-boo heel**、**Coleman block test**（後足可矯正 = forefoot-driven flexible）、Meary's angle apex dorsal
    - 表現：外踝不穩、peroneal tendinopathy、**5th MT stress fracture**
    - 治療：軟組織平衡（plantar fascia release、peroneus longus → brevis、**tibialis posterior transfer**）→ 骨性（1st MT dorsiflexion osteotomy、**Dwyer**）→ **triple arthrodesis**
- **Subtalar 機轉**：pronation（跟骨 eversion、中足 **unlocked** 吸震）vs supination（跟骨 inversion、**locked** 推進）；**windlass mechanism**
- **PTTD（成人後天扁平足）**：hindfoot **valgus**、forefoot **abduction**；**single-limb heel rise 失敗（最敏感）**、**too many toes sign**；中年女性、肥胖

| Stage | 描述 | 治療 |
|---|---|---|
| I | 腱鞘炎，無變形 | Boot / cast |
| II | Flexible flatfoot | UCBL/AFO；**FDL transfer + MDCO** ± Evans |
| III | Rigid | **Triple arthrodesis** |
| IV | + ankle valgus（deltoid） | Triple + deltoid 重建 / TTC fusion |

- **足底壓力 FTI**（∫F dt，累積負荷）：HV → MTH2–3、diabetic foot 潰瘍風險、扁平足 medial midfoot↑、高弓足 lateral forefoot + heel↑；只量垂直力

### 8.1 好發位置與年齡

### 8.2 良性骨腫瘤

- **最常見良性骨腫瘤 = osteochondroma**；**multiple hereditary exostoses：AD（EXT1/2）**；惡變警訊：成年後持續長、疼痛、**cartilage cap > 2 cm** 〔111-2, 112-1〕

### 8.4 轉移與切片原則

- **最常見骨腫瘤 = 轉移**；來源**乳、攝護腺、肺、腎、甲狀腺**；最常侵犯**脊椎**；成骨 = 攝護腺；溶骨 = 腎、甲狀腺、肺、乳（多） 〔113-2〕
- **Biopsy 原則**：先 staging 再切片；**縱向切口**、**穿過單一腔室**（不走筋膜間隙）；由執行切除的團隊做；**culture what you biopsy**；病理骨折**不可先打髓內釘** 〔115-1〕

### 8.5 軟組織腫瘤

- 成人最常見軟組織肉瘤：**UPS、liposarcoma**；**synovial sarcoma**：年輕人、膝周、**t(X;18)** 〔111-1〕
- Desmoid = aggressive fibromatosis；MPNST 多源自 **NF1**

## 九、代謝性骨病與關節炎

### 9.1 代謝性骨病

- **Renal osteodystrophy（CKD-MBD）**：**高磷** + 1,25(OH)₂D↓ → 低鈣 → **次發性 HPT** → osteitis fibrosa cystica、**brown tumor**、rugger-jersey spine；相關的是 **PTH**（非甲狀腺素） 〔110-1, 114-2〕
- **Osteoporosis**：Type I（停經後、小樑骨、脊椎/橈骨遠端） vs Type II（老年、髖部）；bisphosphonate 抑制 osteoclast；**間歇性 PTH（teriparatide）刺激 osteoblast**（anabolic） 〔115-1〕
- **Paget disease**：> 50 歲、**osteoclast 內包涵體**（paramyxovirus）、ALP↑、溶骨 → 混合 → 硬化；顱骨 cotton wool、聽損、高輸出心衰、**次發性 OS** 〔115-2〕

### 9.2 關節炎手部鑑別

| | RA | PsA | OA | Gout |
|---|---|---|---|---|
| 關節 | MCP、PIP、腕，**對稱**，不侵犯 DIP | **DIP**、不對稱 | DIP、PIP、拇指 CMC | 1st MTP |
| 特徵 | 尺側偏斜、swan-neck、boutonnière | **Dactylitis**、enthesitis、**指甲病變** | Heberden / Bouchard nodes | Tophi |
| X 光 | **關節旁骨鬆**、marginal erosion、均勻狹窄 〔113-2〕 | **Pencil-in-cup**、侵蝕 + 新骨形成 | Osteophyte、非對稱狹窄 | Punched-out（rat bite） |

- **PsA**：asymmetric oligoarthritis 最常見；**CASPAR** 分類；治療 NSAIDs → MTX → TNF-i / **IL-17-i（IBD 避免）** / IL-23-i → JAK-i；**避免全身性 steroid**
- **TAE for hand OA**：栓塞異常新生血管（imipenem/cilastatin）；小型研究、**仍屬實驗性**；同概念 genicular artery embolization（knee OA）
