# 骨科

!!! info "使用方式"
    系統性整理骨科觀念（總論 → 創傷 → 運動醫學 → 脊椎 → 手 → 關節重建 → 兒童 → 腫瘤 → 代謝 → 足踝）。`〔113-2〕` = 113 年第二次國考考過此觀念。
    對應考古題（含答案、解析，章節編號相同）：[骨科考古題](骨科考古題.md)

## 一、骨科總論

### 1.1 骨骼構造與骨折癒合

- **皮質骨（cortical）**：骨幹、承重、更新慢；**海綿骨（cancellous/trabecular）**：骨端與椎體、代謝快 → 骨鬆先影響（脊椎、橈骨遠端）
- **長骨分區**：epiphysis（骨骺）→ physis（生長板）→ metaphysis（幹骺端，血流最豐富、腫瘤與骨髓炎好發）→ diaphysis（骨幹）
- **骨折癒合**

| 期別 | 時間 | 事件 |
|---|---|---|
| 發炎期 | 0–1 週 | 血腫、發炎細胞、生長因子 |
| 修復期（軟骨痂） | 2–3 週 | 軟骨痂 → 骨痂（endochondral） |
| 修復期（硬骨痂） | 4–12 週 | 編織骨（woven bone） |
| 重塑期 | 數月–數年 | 依 Wolff's law 重塑為板狀骨 |

- **Primary（direct）healing**：絕對穩定（加壓鋼板）→ 無骨痂；**Secondary（indirect）healing**：相對穩定（石膏、髓內釘）→ 骨痂形成
- 不癒合危險因子：**吸菸**、DM、NSAIDs、感染、血流差（**scaphoid 近端、股骨頸、距骨、脛骨遠端 1/3**）、固定不足
    - Hypertrophic nonunion（血流夠、不穩）→ 加強固定；atrophic nonunion（血流差）→ 骨移植

### 1.2 生物力學

- **Viscoelasticity（黏彈性）**：受力與時間/速率相關 〔113-2〕
    - **Creep**：定力下持續變形；**Stress relaxation**：定長下應力下降；**Hysteresis**
    - 臨床：伸展運動、serial casting 都利用此特性
- **Tension band**：把偏心受力的**張力轉為骨折面的壓縮力**（髕骨、鷹嘴突、大轉子） 〔111-1〕
- 植入物材料：**鈦合金**（彈性模數接近骨、骨整合佳、**耐磨差**）、**CoCr**（耐磨，關節面）、ceramic、**UHMWPE**（襯墊） 〔112-1〕

### 1.3 理學檢查

**順序：Inspection → Palpation → ROM →（Neuro）→ Special test，兩側比較。**

| 部位 | 重點檢查 | 意義 |
|---|---|---|
| 頸椎 | **Spurling**、**shoulder abduction relief**、Lhermitte、Hoffmann | 神經根 / 脊髓病變 |
| 腰椎 | **SLRT（30–70°）**、cross-SLRT、femoral stretch | L5/S1 / L2–4 神經根 |
| 肩 | Neer、Hawkins、**Jobe（empty can）**、drop arm、**apprehension**、**sulcus**、**Jerk/Kim** | Impingement、cuff、不穩定 |
| 腕/手 | **Phalen**、Tinel、Durkan、**Finkelstein**、Watson、Froment、Allen | CTS、De Quervain、SL 不穩、ulnar n.、血流 |
| 髖 | **FABER（Patrick）**、FADIR、**Thomas**、**Trendelenburg**、log roll | 髖/SI、FAI、屈曲攣縮、外展肌無力 |
| 膝 | **Lachman**、pivot shift、drawer、**posterior sag**、varus/valgus stress、**McMurray / Apley / Thessaly** | ACL、PCL、副韌帶、半月板 |
| 踝/足 | anterior drawer、talar tilt、**Thompson**、squeeze test | ATFL/CFL、Achilles、syndesmosis |

- **Trendelenburg sign**：**患側單腳站** → 對側骨盆下垂（患側 gluteus medius / superior gluteal n.） 〔110-2〕
- **Thomas test** = 髖屈曲攣縮；**Thompson test** = Achilles 斷裂 〔110-2〕

### 1.4 電學診斷

| | EMG（針極） | NCV / NCS |
|---|---|---|
| 評估 | 肌肉去神經、neuropathic vs myopathic | 傳導速度、振幅、latency |
| 判讀 | **Fibrillation、PSW**（受傷 2–3 週後才出現）；大寬多相 MUAP = 神經性；小短多相 = 肌病 | **速度慢、latency 長 = 脫髓鞘**；**振幅低 = 軸突** |
| 適用 | 深部神經（suprascapular）、radiculopathy | CTS、ulnar n.、GBS |

## 二、骨折與創傷總論

### 2.1 骨折描述與分類

- 描述：開放/閉鎖、部位、型態（橫、斜、螺旋、粉碎、節段）、位移（平移、成角、旋轉、縮短）、關節內與否
- **兒童特有骨折** 〔113-2〕

| 型態 | 特徵 |
|---|---|
| **Torus（buckle）** | 壓力側皮質隆起，無骨折線；最穩定 |
| **Greenstick** | **張力側斷裂、壓力側塑形變形** |
| Plastic deformation | 彎曲無骨折線（尺骨、腓骨） |
| Physeal fracture | Salter-Harris（見九、兒童骨科） |

- **開放性骨折（Gustilo-Anderson）** 〔114-2〕

| Grade | 傷口 | 特徵 |
|---|---|---|
| I | < 1 cm | 乾淨、低能量 |
| II | 1–10 cm | 中度軟組織傷 |
| IIIA | > 10 cm | 軟組織仍可覆蓋；**高能量、嚴重污染（農場）、槍傷、節段骨折直接歸 III** |
| IIIB | — | 骨膜剝離，需皮瓣 |
| IIIC | — | **合併需修補的血管傷** |

- 開放性骨折處置：**抗生素（≤ 1 h，cefazolin ± gentamicin）**、tetanus、清創灌洗、固定；穩定者可一期髓內釘 〔114-2〕
- 合併血管傷：先**暫時穩定骨折**（external fixator / shunt）再修補血管 〔114-2〕

### 2.2 固定原則

| | 副木（splint） | 石膏（cast） |
|---|---|---|
| 包覆 | 非環狀 | 環狀 |
| 時機 | **急性期**（容許腫脹） | **消腫後**（約 1–2 週） |
| 風險 | 固定力較差 | 腔室症候群、壓瘡 |

〔110-1〕

- 固定「骨折上下兩個關節」；踝固定於**中立 90°**（防馬蹄足）、手固定於 **intrinsic-plus（safe position：MCP 屈 70–90°、IP 伸直）**
- 石膏後疼痛加劇、麻木 → **立即剖開/拆除**檢查；浸泡用**室溫水**（熱水放熱燙傷）
- 內固定：加壓鋼板（絕對穩定）、髓內釘（相對穩定、承重分擔）、外固定（開放性、軟組織差、暫時）

### 2.3 骨折併發症

#### 腔室症候群（Compartment syndrome）

- 機轉：封閉筋膜腔內壓 > 微血管灌流壓 → 缺血；好發**小腿前腔**、前臂掌側
- **5P**：**Pain out of proportion、被動伸展痛（最早最敏感）**、Paresthesia、Pallor、Paralysis、**Pulselessness（晚期，脈搏存在不能排除）** 〔110-2, 112-1〕
- 診斷：臨床為主；壓力 **> 30 mmHg** 或 **ΔP（舒張壓 − 腔室壓）≤ 30 mmHg** 〔111-1, 113-2〕
- 治療：解除包紮 → **緊急 fasciotomy**（小腿四腔）；勿抬高過心臟
- 後遺：**Volkmann ischemic contracture**（前臂深層屈肌 FDP、FPL 纖維化；常見於 supracondylar fracture） 〔112-1〕

#### Crush syndrome / 橫紋肌溶解

- 肌肉壞死 → myoglobin、K⁺ 釋出 → **AKI、高血鉀、心律不整**
- **積極輸液（NS，目標尿量 200–300 mL/h）**；**避免 LR（含 K⁺）**；監測 K⁺、尿量 〔110-2, 115-1〕

#### 脂肪栓塞症候群（FES）

- 長骨（股骨）/骨盆骨折或**髓內釘後 24–72 h**
- **三主徵：呼吸窘迫（低血氧）+ 神經症狀（意識改變）+ 點狀出血（腋下、結膜、上胸）**；血小板↓、貧血；CXR snowstorm
- 治療：支持療法（氧氣/呼吸器）；**早期固定骨折**可預防；不是腦壓問題 〔112-2〕

#### 其他

| 併發症 | 重點 |
|---|---|
| DVT / PE | 髖膝手術、骨盆骨折高風險 → 藥物預防 |
| AVN | 股骨頸、scaphoid 近端、距骨頸、肱骨頭 |
| Malunion / nonunion | 見 1.1 |
| CRPS | 不成比例疼痛、腫脹、皮膚溫度/顏色改變、骨鬆 |
| 神經血管傷 | 肱骨幹→radial；肱骨髁上→AIN/brachial a.；膝脫臼→popliteal a.、peroneal n.；髖後脫臼→sciatic n. |

#### 壓力性骨折（Stress fracture） 〔114-2〕

- 反覆次最大負荷 > 骨重塑能力；跑者、軍人、**female athlete triad**（能量不足、月經失調、骨質低）
- 部位：脛骨、蹠骨（march fracture）、股骨頸、navicular、骨盆
- X 光早期常陰性 → **MRI / bone scan**
- 治療：**多數保守**（減量、保護性負重）；**高風險部位才手術**：**股骨頸張力側（superolateral）**、前側脛骨幹（dreaded black line）、navicular、5th MT（Jones）

### 2.4 多重創傷與骨盆骨折

- ATLS：**ABCDE**；出血性休克找五處：胸、腹、**骨盆/後腹腔**、長骨、外出血
- **Damage control orthopaedics**：不穩定病人先外固定，生理穩定後再確定性固定
- **穿刺性肢體傷**：**hard signs**（搏動性出血、擴大/搏動性血腫、**bruit/thrill**、無脈、遠端缺血）→ 直接手術；soft signs → ABI / CTA；外出血先**直接加壓**（勿盲夾） 〔113-1〕

#### 骨盆骨折

| 分類（Young-Burgess） | 機轉 | 重點 |
|---|---|---|
| **APC**（open book） | 前後擠壓 | 骨盆容積↑ → 大出血；**pelvic binder** |
| LC | 側方擠壓 | 最常見 |
| VS | 垂直剪力（墜落） | 最不穩定 |

- 多數為穩定骨折 → 保守；不穩定 → binder、外固定、**血管栓塞**（動脈）/ preperitoneal packing（**出血多來自靜脈叢**） 〔111-1〕
- 合併傷：**尿道（男 > 女，後尿道）**、膀胱、**腰薦神經叢**（神經根損傷預後差）、直腸/陰道 〔114-2〕
- **尿道口出血、陰囊血腫、高位前列腺 → 疑尿道斷裂 → 禁放 Foley → 先做 RUG（逆行性尿道攝影）** 〔111-2, 114-2, 115-1〕

## 三、上肢創傷

### 3.1 鎖骨與肩

- **鎖骨骨折**：中 1/3 最常見；多保守（sling/figure-of-8）；縮短 > 2 cm、皮膚頂起、開放、神經血管傷 → ORIF
- **肩關節脫臼**

| | Anterior（95%） | Posterior |
|---|---|---|
| 機轉 | 外展 + 外旋 | **癲癇、電擊**、直接撞擊 |
| 姿勢 | 外展外旋、肩峰下凹陷 | **內收內轉、無法外轉** |
| 病灶 | **Bankart**（前下 labrum）、**Hill-Sachs**（肱骨頭後上外） | Reverse Bankart、reverse Hill-Sachs（McLaughlin） |
| 影像 | AP + Y / axillary | **Light bulb sign**；AP 易漏 → axillary / CT |
| 合併 | **Axillary n.**、老人 cuff tear、GT fracture | — |

〔115-1, 115-2〕

- 再脫臼率：**年紀越輕越高**（< 20 歲 70–90%）→ 年輕運動員考慮手術（Bankart repair、Latarjet） 〔115-1〕
- **合併 GT fracture**：約 15–30%、再脫臼率較低；復位前查 axillary n.、排除 occult neck fracture → 輕柔復位；GT 位移 **≥ 5 mm（運動員 ≥ 3 mm）→ ORIF**

| | Hill-Sachs | GT fracture |
|---|---|---|
| 機轉 | 肱骨頭撞 glenoid 前下緣（壓迫凹陷） | Rotator cuff 拉扯 |
| 再脫臼 | ↑ | ↓ |

### 3.2 肱骨

- **肱骨近端骨折**：老人骨鬆跌倒；**Neer 分類**（頭、GT、LT、幹；位移 > 1 cm 或成角 > 45° 才算一 part）
    - 多數無位移 → sling、早期擺盪運動
    - **年輕人 3/4-part → ORIF**（保留肱骨頭）；老人 → **reverse TSA** / hemiarthroplasty 〔113-1〕
- **肱骨幹骨折**：**radial n.（spiral groove）→ wrist drop**；多保守（functional brace）；Holstein-Lewis（遠端 1/3 螺旋）

### 3.3 肘

- **Elbow dislocation**：多為**後外側**；**單純型 → 復位後短期固定（≤ 1–2 週）早期活動**（肘最怕僵硬）；不穩定才手術 〔113-1〕
    - **Terrible triad** = 後脫臼 + 橈骨頭骨折 + coronoid 骨折 → 手術
- **Radial head fracture**：FOOSH；**Mason** 〔110-1〕

| Mason | 型態 | 處置 |
|---|---|---|
| I | 無位移 | 保守、早期活動（可抽血腫 + 局麻測旋轉） |
| II | 位移 > 2 mm | **旋轉有機械性阻擋 → ORIF** |
| III | 粉碎 | 置換 / 切除 |
| IV | 合併脫臼 | 手術 |

- 關節內游離骨塊 → 手術移除 〔110-1〕
- **Fat pad sign**：側面 X 光**前 fat pad 抬高（sail sign）或看見後 fat pad** = 關節積血 → 隱匿性骨折（成人橈骨頭、兒童 supracondylar） 〔112-2〕
- 鷹嘴突骨折：位移 → tension band wiring / plate

### 3.4 前臂

| | Monteggia | Galeazzi |
|---|---|---|
| 骨折 | **尺骨近端** | **橈骨遠端 1/3** |
| 脫臼 | **橈骨頭** | **DRUJ** |
| 神經 | **PIN** | — |
| 治療 | 兒童閉鎖復位；成人 ORIF 尺骨 | **成人一定 ORIF**（fracture of necessity） |

口訣 **MUGR**：Monteggia–Ulna、Galeazzi–Radius 〔115-1〕

### 3.5 腕與手部骨折

- **橈骨遠端骨折**：最常見骨折之一（骨鬆老婦 FOOSH）

| | Colles | Smith | Barton |
|---|---|---|---|
| 機轉 | 伸展跌倒 | 屈曲跌倒 | 關節內緣骨折 + 腕骨半脫位 |
| 遠端骨片 | **背側**（dinner fork） | **掌側**（garden spade） | 背側或掌側 |

- 可接受復位：radial inclination > 15°、radial height 縮短 < 5 mm、palmar tilt 中立、關節面 step-off < 2 mm；併發：**EPL 斷裂**、CTS、CRPS、malunion
- **Scaphoid fracture**：最常見腕骨骨折；**anatomical snuffbox 壓痛**；血流**遠端 → 近端**（radial a. dorsal branch）→ **腰部/近端骨折易 AVN、nonunion**（→ SNAC wrist） 〔110-1, 112-2〕
    - X 光陰性但臨床懷疑 → thumb spica，**MRI**（或 10–14 天後重照）
    - 無位移腰部 → cast；近端、位移 > 1 mm → 螺釘
- **Lunate / perilunate dislocation**：Mayfield 分期，median n. 受壓 → 急診復位
- **Kienböck disease**（月狀骨 AVN）：與 **ulnar negative variance** 相關 → 卸載手術：**radial shortening**、capitate shortening、vascularized graft；晚期 proximal row carpectomy / fusion（**不可延長橈骨**） 〔114-2〕
- **DRUJ arthritis**：Darrach（尺骨頭切除）、hemiresection-interposition、**Sauvé-Kapandji**、尺骨頭置換；**Adams procedure 是 DRUJ 不穩定的韌帶重建** 〔111-1〕
- **拇指掌骨基部骨折** 〔110-2, 112-2〕

| | Bennett | Rolando |
|---|---|---|
| 型態 | 關節內**兩片** | 關節內**粉碎（Y/T）** |
| 變形力 | **APL** 拉主骨片往近端背橈側（+ adductor pollicis） | — |
| 治療 | CRPP / ORIF | ORIF / 外固定 |

- **Boxer's fracture**（第 5 掌骨頸）：可接受成角較大（40–70°）；注意旋轉畸形（scissoring）

## 四、下肢創傷

### 4.1 髖部骨折

| | Femoral neck（囊內） | Intertrochanteric（囊外） |
|---|---|---|
| 血流 | **Medial femoral circumflex a.** 易斷 → **AVN、nonunion** | 血流豐富，癒合佳 |
| 外觀 | 縮短 + 外旋 | 縮短外旋更明顯、大轉子瘀青 |
| 分類 | **Garden**（位移）、**Pauwels**（骨折線與水平夾角，越垂直越不穩） 〔111-1〕 | Stable / unstable |
| 治療 | **年輕：緊急復位 + 內固定**；老人無位移：螺釘；**老人位移：hemi/THA** 〔111-2〕 | DHS / cephalomedullary nail |

- Garden：I 不完全/外翻嵌插、II 完全無位移、III 部分位移、IV 完全位移
- **Shenton line 中斷** = 移位/脫臼 〔111-2〕
- 老人髖部骨折：**48 小時內手術**、早期下床；X 光陰性但無法負重 → MRI（occult fracture）
- 其他老人低能量骨折：**pubic rami**、**sacral insufficiency**（像下背痛、X 光常陰性，MRI/CT Honda sign）

### 4.2 髖關節脫臼

- **後脫臼（~90%）**：**dashboard injury**；肢體**屈曲、內收、內旋**、縮短；**sciatic n.（peroneal division）**；± 後壁骨折 〔112-1〕
- 前脫臼：屈曲、外展、外旋；femoral n./a.
- **6 小時內復位**降低 AVN；復位後 CT 查骨塊/關節內碎片

### 4.3 髖臼與骨盆影像解剖

- 髖臼 = ilium + ischium + pubis 於 **triradiate cartilage** 會合（青春期閉合） 〔111-2〕
- 前柱（ilium 前部 → 恥骨）、後柱（坐骨大切跡 → 坐骨）
- **AP 六線**：iliopectineal（前柱）、ilioischial（後柱）、teardrop、roof、anterior rim、posterior rim 〔115-2〕
- **Judet views（45°）**：**Obturator oblique → 前柱 + 後壁**；**Iliac oblique → 後柱 + 前壁**（O-A-P / I-P-A） 〔111-2〕

### 4.4 骨盆撕脫性骨折（青少年 apophysis） 〔111-2〕

| 附著點 | 肌肉 |
|---|---|
| **ASIS** | **Sartorius**、TFL |
| **AIIS** | **Rectus femoris** |
| Ischial tuberosity | Hamstrings |
| Lesser trochanter | Iliopsoas（成人 → 想**病理性骨折**） |
| Iliac crest | 腹肌 |

- 多保守；坐骨結節位移 > 2 cm 可考慮固定

### 4.5 股骨幹與膝周骨折

- **股骨幹**：高能量、出血 1–1.5 L；**髓內釘**；注意 FES、同側股骨頸骨折
- **Tibial plateau（Schatzker）** 〔111-1〕

| Type | 型態 | 族群 |
|---|---|---|
| I | 外側**純劈裂** | 年輕、骨質好 |
| II | 外側劈裂 + 塌陷 | **最常見** |

- **髕骨骨折**：伸直機制斷裂 → ORIF（tension band）；無位移、伸直機制完整 → 保守
- **伸直機制斷裂**：**髕骨肌腱（< 40 歲）→ patella alta**；**四頭肌腱（> 40 歲、DM、CKD、steroid）→ patella baja**；無法主動伸膝 → 手術修補 〔112-1〕

### 4.6 膝脫臼

- 高能量，常自行復位；多韌帶損傷（≥ 2 條）
- **Popliteal artery 損傷 20–40%**（內膜撕裂可延遲阻塞）→ **脈搏正常不能排除** → **ABI < 0.9 → CTA**、連續追蹤；**peroneal n.** 損傷 〔113-2〕

### 4.7 踝與足

- **踝扭傷**：**inversion + plantar flexion** → 外側韌帶 **ATFL > CFL > PTFL**；內踝為受壓側（垂直剪力骨折）；**三角韌帶撕脫是外翻/外旋機轉** 〔114-1〕
- **Ottawa ankle rules**：外/內踝後緣下 6 cm 壓痛、5th MT 基部、navicular 壓痛、無法負重四步 → 照 X 光
- **踝骨折**：**Lauge-Hansen（SER 最常見）**、Weber（A 低於 syndesmosis、B 平齊、C 高於 → syndesmosis 傷） 〔111-1〕
    - 雙踝/三踝、距骨位移、syndesmosis 不穩 → ORIF；**Maisonneuve**（近端腓骨 + 內側傷）
- **Achilles rupture**：「被踢一下」、**Thompson test**、palpable gap；保守（馬蹄位）或手術
- **Lisfranc injury**：**plantar ecchymosis**、**站立 X 光 1st–2nd MT base > 2 mm**、fleck sign → ORIF / primary arthrodesis
- **5th MT 基部**：zone 1 avulsion（peroneus brevis，保守）、**zone 2 Jones（分水嶺，易不癒合）**、zone 3 stress fracture
- **Calcaneus**：墜落；**10% 合併腰椎骨折**；Böhler angle↓

## 五、運動醫學

### 5.1 肩

- **GH 穩定結構**：glenoid 僅肱骨頭 1/3–1/4（golf ball on tee）→ 靠 **labrum、GH ligaments（關節囊增厚）、rotator cuff**；**鎖骨（SC joint）是上肢與軀幹唯一骨性連接**；scapulothoracic 為功能性關節 〔115-2〕
- **不穩定檢查** 〔110-1, 110-2〕

| 方向 | 檢查 |
|---|---|
| Anterior | **Apprehension（外展 90° + 外旋）**、relocation、anterior drawer |
| Posterior | **Jerk（Jahnke）**、**Kim**、posterior drawer |
| Inferior / MDI | **Sulcus sign** |

- **Rotator cuff**

| 肌肉 | 功能 | 測試 |
|---|---|---|
| Supraspinatus | 外展起始 | **Jobe（empty can）**、drop arm |
| Infraspinatus / teres minor | 外旋 | ER lag、**Hornblower（teres minor）** |
| Subscapularis | 內旋 | Lift-off、belly press |

- **Impingement**：painful arc 60–120°、Neer、Hawkins；**rotator cuff tear** 主動痛/無力、**被動 ROM 正常**；**adhesive capsulitis** 主被動皆受限（外旋最早）
- **Biceps**：**近端 long head 斷裂 → Popeye sign**（多保守）；遠端斷裂 → hook test、旋後無力 → 年輕人修補 〔111-1〕
- **SLAP lesion**：過頭運動；O'Brien test
- **Suprascapular n.**：suprascapular notch（棘上 + 棘下無力）vs **spinoglenoid notch（只有棘下，排球扣球、ganglion + SLAP）**；EMG 診斷

### 5.2 肘與腕

- **Lateral epicondylitis**：ECRB tendinosis；**Medial epicondylitis**：FCR / pronator teres
- **UCL injury**：投手（valgus stress）→ Tommy John 重建

### 5.3 膝韌帶

| | ACL | PCL | MCL | LCL |
|---|---|---|---|---|
| 功能 | 限制**前移 + 內旋** | 限制後移 | 限制 valgus | 限制 varus |
| 機轉 | 非接觸性落地/急停轉身、pop、急性血腫 | Dashboard、跌倒膝著地 | 外側撞擊（valgus） | 內側撞擊 |
| 檢查 | **Lachman（最敏感）**、pivot shift（最特異）、anterior drawer | **Posterior sag**、posterior drawer | Valgus stress（30°） | Varus stress |
| 治療 | 運動員**重建**（非 primary repair） | 多保守 | **多保守**（brace） | 合併 PLC 傷 → 手術 |

〔110-2, 115-2〕

- **ACL 雙束** 〔113-1〕：**AM bundle 屈曲時緊**（前移）；**PL bundle 伸直時緊**（旋轉）；screw-home 終末伸直時脛骨外旋
- **Segond fracture**（外側脛骨平台撕脫，anterolateral ligament）≈ **ACL tear**；reverse Segond → PCL 〔114-2〕
- **Unhappy triad**：ACL + MCL + 內側半月板（valgus 撞擊） 〔113-2〕
- 急性膝血腫：**ACL（最常見）**、髕骨脫臼、骨軟骨骨折；張力性血腫可抽吸

### 5.4 半月板與髕股關節

- **Meniscal tear**：扭轉；joint line tenderness、**McMurray、Apley、Thessaly**；**locking（無法完全伸直）= bucket-handle tear** → 早期手術 〔110-2, 112-2〕
    - 周邊 1/3（red zone）血流好 → 修補；內側 2/3（white zone）→ 部分切除
    - **合併 ACL 斷裂 → 半月板修補 + ACL 重建同時** 〔115-2〕
- **Patellar dislocation**：多為**外側**、MPFL 撕裂；危險因子：**Q 角增大**、patella alta、trochlear dysplasia、genu valgum/recurvatum、股骨前傾、hypermobility、VMO 無力 〔114-1〕
- **PFPS**：上下樓、久坐後膝前痛；patellar grind

### 5.5 運動傷害原則

- 急性軟組織傷：PRICE → **PEACE & LOVE**
- **AMI（arthrogenic muscle inhibition）**：關節積液（20–30 mL 即可）、疼痛 → 脊髓 Ib inhibition、γ-loop dysfunction → **quadriceps 反射性抑制**（extensor lag、常雙側）；治療**先解除抑制**（控制積液、冰敷後立即運動、TENS、NMES）**再練肌力**

### 6.4 腰椎退化

#### 椎間盤退化與 HIVD

**機轉**：終板營養↓ → **proteoglycan↓、髓核失水** → 負荷轉移至纖維環 → **後外側 annular fissure** → protrusion → extrusion → sequestration；壓迫 + **化學性發炎（TNF-α、IL-1）**

| 危險因子 | 內容 |
|---|---|
| **基因（最重要）** | Collagen、aggrecan 變異 |
| 年齡 | 30–50 歲（更老轉為 stenosis） |
| 機械 | **承重下屈曲 + 旋轉**、久坐、全身震動 |
| 生活 | **吸菸**、肥胖 |

- **L4–5、L5–S1** 佔 90–95%；**protrusion 最常見**；**MRI** 為最佳檢查
- 自然病程：**80–90% 在 6–12 週內改善**（sequestration 反而較易吸收）→ **保守為主** 〔111-2〕
- 手術：**cauda equina（急診）**、進行性神經缺損、保守 6–12 週無效；併發症：dural tear、神經根傷、感染、復發
- **Degenerative disc disease**：MRI 退化在**無症狀者極常見**（影像與疼痛相關性差）；屈曲/坐姿加重；手術效果較差，常需融合 〔112-1〕

#### Spinal stenosis

- **退化性最常見**：椎間盤膨出 + facet 肥厚 + 黃韌帶肥厚；**L4–5** 最常見；central / lateral recess / foramen 〔112-2〕
- **Neurogenic claudication**：站立/走路下肢痛麻，**前彎、坐下緩解**（shopping cart sign）；vs vascular claudication（站著休息即緩解、脈搏弱）
- 進行性神經缺損 → 手術減壓效果佳

#### Spondylolysis / spondylolisthesis

| | Isthmic | Degenerative |
|---|---|---|
| 族群 | 青少年運動員（過伸：體操） | 中老年女性 |
| 位置 | **L5/S1** | **L4/5** |
| 機轉 | Pars 疲勞骨折（Scottie dog collar） | Facet 退化 |
| 壓迫 | **出口根（L5）** | 走行根 L5（中央狹窄） |

- **Meyerding**：I < 25%、II 25–50%、III 50–75%、IV > 75%、V spondyloptosis 〔113-1〕

#### 下背痛鑑別

!!! warning "站不起來不一定是 spine"
    老人跌倒後下背/臀部痛、**無法負重** → 先排除 **hip / pelvis fracture**（疼痛常轉移至下背、臀、膝）。

| Red flag | 想到 |
|---|---|
| > 50 歲、癌症史、體重減輕、夜間痛 | **Metastasis** |
| 發燒、IVDU、免疫低下 | **Spondylodiscitis**、epidural abscess |
| 外傷、骨鬆、steroid | **Fracture** |
| 尿滯留、saddle anesthesia | **Cauda equina** |
| 年輕、晨僵、活動後改善 | **Inflammatory back pain**（AS） |

| | 傾向 hip | 傾向 spine |
|---|---|---|
| 疼痛 | **鼠蹊**、大腿前、膝 | 下背、放射至膝下 |
| 檢查 | **IR 痛/受限**、FABER 鼠蹊痛、log roll、縮短外旋 | SLRT(+)、dermatome、DTR 改變、midline 壓痛 |

### 6.5 脊椎感染

### 6.6 脊椎變形

#### Adolescent idiopathic scoliosis（AIS）

- 青春期女孩、右胸彎最常見（左胸彎 → MRI 找 syrinx 等）；**Adams forward bending** + scoliometer（軸向旋轉）；**Cobb angle**；骨成熟度 **Risser 0–5**、初經
- 治療 〔111-1〕

| Cobb | 骨未成熟 | 骨成熟 |
|---|---|---|
| < 20–25° | 觀察（每 4–6 月 X 光） | 不需追蹤 |
| 25–40° | **背架**（防惡化，不矯正） | 觀察 |
| **> 40–50°** | **Posterior spinal fusion** | > 50° 手術 |

- **Crankshaft phenomenon**：骨骼很未成熟（Risser 0、初經前、open triradiate cartilage）只做後側融合 → 前柱繼續生長 → 旋轉惡化 → 需加前側融合

#### 其他變形

|---|---|---|---|

## 七、手外科

### 7.1 手部解剖

- **Intrinsic muscles**：thenar、hypothenar、**lumbricals**、**interossei**、adductor pollicis；**FDS/FDP/EDC 為 extrinsic** 〔114-1〕
    - Intrinsic-plus：MCP 屈、IP 伸；**Intrinsic-minus（claw hand）**：MCP 過伸、IP 屈（ulnar n. 病變）
- **腕隧道**：**9 條肌腱（FDS×4、FDP×4、FPL）+ median n.**；FCR 有獨立隧道、FCU 止於 pisiform（不在內）、palmaris longus 在屈肌支持帶之上 〔113-2〕
- **Guyon canal**：ulnar n. + a.（pisiform 與 hamate hook 之間）
- **Flexor pulleys**：A1–A5、C1–C3；**A2、A4 最重要**（防 bowstringing）

|---|---|---|
| I | FDS 止點以遠 | 只有 FDP；jersey finger |
| **II（no man's land）** | A1 至 FDS 止點 | FDS + FDP 同在狹窄腱鞘 → **沾黏、預後最差** |
| III–V | 掌、腕隧道、前臂 | V：spaghetti wrist |

- Primary repair **7–10 天內**、**≥ 4-strand core suture**、早期保護性活動；併發：沾黏（最常見）、rerupture（約第 10 天）

| | Mallet finger | Jersey finger |
|---|---|---|
| 結構 | Extensor terminal tendon（± 撕脫骨片） | **FDP 撕脫**（無名指最常見） |
| 機轉 | 伸直手指被撞成屈曲 | 屈曲手指被強迫伸直（抓球衣） |

### 7.4 手部常見疾病

| 疾病 | 病灶 | 臨床 | 治療 |
|---|---|---|---|
| **Trigger finger** | **A1 pulley** 增厚 + 肌腱結節 | MCP 掌側痛（distal palmar crease）、卡住；無名指、拇指；DM、RA | splint → **steroid 注射（第一線）** → A1 release（**A2、A4 不可切**） 〔112-1〕 |
| **De Quervain** | 第一伸肌腔 **APL + EPB** | 橈骨莖突痛；新手媽媽 | **Finkelstein**；splint、注射、release 〔110-2〕 |
| **Dupuytren** | 掌腱膜（myofibroblast） | **北歐裔男性**、DM、酒精；無名指 > 小指；**MCP** > PIP | MCP > 30° 或任何 PIP 攣縮（**tabletop test**）→ fasciectomy / needle / collagenase 〔115-2〕 |

### 7.5 斷指再接與先天異常

- **再接適應症**：**拇指、多指、兒童**、手掌/腕/前臂、單指 zone I（FDS 止點以遠） 〔113-1〕
- **相對禁忌**：**單指 zone II**、**多段截斷**、嚴重壓砸/撕脫、溫缺血過久、全身不穩
- **斷指保存**：**生理食鹽水濕紗布包 → 密封袋 → 置於冰水**（不直接接觸冰或水）；殘端**直接加壓止血**（不用止血帶、不盲夾） 〔114-1〕
- **Syndactyly**：**第三指蹼最常見**、第一指蹼最少；simple（只有軟組織）vs complex（骨性黏合）；邊緣指（拇/食、無名/小）早期分開 〔115-1〕

## 八、關節重建

### 8.1 退化性關節炎（OA）

- 機轉：軟骨退化（proteoglycan↓）、軟骨下骨硬化、骨刺；X 光：**非對稱關節腔狹窄**、骨刺、軟骨下硬化/囊腫（KL 0–4）
- 膝 OA 治療階梯：減重、運動（股四頭肌）、NSAIDs → 注射 → 截骨（年輕、單腔室）→ **TKA**（KL IV）
- **玻尿酸（HA）注射**

| 適合 | 不適合 |
|---|---|
| 輕–中度 OA（KL II–III） | **末期 OA（KL IV）→ TKA** |
| NSAIDs 無效/禁忌、想延後手術 | 大量積液、急性發炎（先排除 gout、感染） |
| | **關節或皮膚感染（絕對禁忌）** |

- 起效慢、持續久（vs steroid 快而短）；指引不一（AAOS 不建議常規）；**健保**：保守治療累計 ≥ 6 個月無效、未達 TKA；第一針起 35 天內同部位不可再做 NSAID/steroid 注射或復健

### 8.2 骨壞死（Osteonecrosis）

- 好發：**股骨頭（最常見）**、肱骨頭、股骨髁、距骨、**scaphoid 近端、lunate**——終末血流或逆向血流處；跟骨少見 〔113-2〕
- **ONFH 危險因子**：**steroid、酒精**（最常見兩者）、SLE、鐮刀型、潛水夫病、外傷、Gaucher
- 病理始於**股骨頭前外上承重區的軟骨下骨** → 軟骨下骨折（**crescent sign**）→ 塌陷 → 關節炎 〔115-2〕
- 影像：早期 X 光正常 → **MRI 最敏感**（double-line sign）

| 分期（Ficat） | 表現 | 治療 |
|---|---|---|
| I–II | 塌陷前 | 保守（減少負重、bisphosphonate）、**core decompression ± 骨移植** |
| **III** | **Crescent sign、塌陷** | 保守無效 → 關節置換 |
| IV | 退化性關節炎 | **THA** |

### 8.3 髖關節保存手術

| LCEA | 意義 |
|---|---|
| **< 20°** | **Dysplasia** |
| 20–25° | Borderline |
| 25–40° | 正常 |
| > 40° | Over-coverage → **pincer FAI** |

- 其他：Tönnis angle > 10°、ACEA < 20°；年輕女性鼠蹊痛、C sign、labral tear
- **DDH 成人**：**年輕無 OA → PAO（periacetabular osteotomy）**；**已有 OA → THA**
- **Hip arthroscopy**：適應症 **FAI（cam、pincer）**、labral tear、loose body；**禁忌：明顯 OA、明顯 DDH（LCEA < 20°）**

### 8.4 人工關節

- **手術入路**：posterior（切開 **short external rotators**：piriformis、superior/inferior gemellus、obturator internus、quadratus femoris → **後脫臼風險**、坐骨神經）vs anterior / anterolateral（abductor 受損） 〔114-2〕
- **材質**：股骨頭 CoCr、ceramic、oxidized zirconium；**鈦合金用於柄/杯（不做關節面）**；襯墊 UHMWPE（highly cross-linked）〔112-1〕
- **骨水泥 PMMA** 〔114-1〕
    - 機制：**填充嵌合（grout），不是黏膠**
    - **液體 = monomer**（避光）、**粉末 = polymer**
    - 聚合為**放熱**反應（可達 70–80°C）
    - **Bone cement implantation syndrome**：低血氧、低血壓、心律不整、心跳停止（monomer、栓子）
- **預防性抗生素** 〔113-1〕：**cefazolin 劃刀前 60 分內**（vancomycin 120 分內）；**術後 ≤ 24 h 停**；vancomycin 只用於 MRSA 帶菌或 β-lactam 過敏

### 8.5 人工關節感染（PJI）

- 分類：早期（< 4 週）、遲發（3–24 月，術中低毒性菌）、晚期血行性
- **MSIS / ICM 診斷**：**sinus tract 通到關節** 或 **兩次培養同菌** = major；minor：ESR/CRP、關節液 WBC/PMN%、α-defensin、組織病理；**CRP 可能不升高** 〔112-2〕
- 治療：**急性 + 植入物穩定 → DAIR（debridement, antibiotics, implant retention）**；慢性 → **二階段翻修**（抗生素骨水泥 spacer）
- **Post-THA piriformis syndrome**：posterior approach、LLD/offset↑；**先排除 PJI**、sciatic n. 損傷、loosening、HO；**FAIR/Freiberg = 屈曲內收內旋 = 後脫臼姿勢**（precautions 期間避免）；超音波導引注射

## 九、兒童骨科

### 9.1 DDH

| 年齡 | 檢查 | 影像 | 治療 |
|---|---|---|---|
| < 3 個月 | **Ortolani（復位）**、**Barlow（脫出）** | **超音波（Graf，α < 60° 異常）** | **Pavlik harness**（< 6 月） |
| > 3 個月 | **外展受限（最可靠）**、**Galeazzi**、皮紋不對稱 | **X 光（> 4–6 月）**：Hilgenreiner/Perkin、**Shenton line 中斷**、acetabular index↑ | 6–18 月：closed reduction + spica |
| 會走路後 | Trendelenburg / waddling gait、腰椎前凸 | X 光 | Open reduction ± osteotomy |

- 危險因子：**女嬰、臀位、第一胎、家族史**、羊水少、斜頸、metatarsus adductus
- **Patrick（FABER）用於髖/SI 疼痛，不用於 DDH** 〔111-1, 111-2〕

### 9.2 兒童跛行與髖部疾病

| | Transient synovitis | Septic arthritis | LCPD（Perthes） | SCFE |
|---|---|---|---|---|
| 年齡 | 3–8 歲 | 任何 | **4–8 歲** | **10–16 歲** |
| 族群 | 上呼吸道感染後 | — | 男、骨齡延遲、矮小 | **肥胖男孩**、**內分泌異常** |

- 兒童主訴膝痛 → **一定要檢查髖**（obturator n. referred pain）

| V | 壓碎（**R**ammed） | 早期難診斷、**生長停滯風險最高** |

- **Supracondylar humerus fracture**

|---|---|---|

- X 光：anterior humeral line 應通過 capitellum 中 1/3、posterior fat pad sign

### 9.4 下肢變形與長短腳

- **脛骨彎曲** 〔110-2〕

| 方向 | 診斷 | 預後 |
|---|---|---|
| **Anterolateral** | **Congenital pseudarthrosis of tibia（NF1）** | 易骨折、不癒合，**預後差** |

| Anteromedial | Fibular hemimelia | 長短腳、踝不穩 |

- **長短腳（LLD）處理**（預估成年時差距）〔112-1〕

| 差距 | 處理 |

| < 2 cm | 觀察 / **鞋墊（shoe lift）** |
| 2–5 cm | 長肢 **epiphysiodesis**（需剩餘生長）/ 縮短 |
| > 5 cm | 短肢**延長術**（± 長肢 epiphysiodesis） |

- **Genu varum / valgum**：生理性（< 2 歲 varum、3–4 歲 valgum 最大）；**Blount disease**（脛骨近端內側生長板異常，肥胖早走兒）、佝僂病
- **Osgood-Schlatter**：青少年脛骨粗隆 apophysitis，自限性

| 脛骨 | Internal tibial torsion | 1–3 歲 | **Thigh-foot angle 負值** | 4 歲前自癒 |
| 股骨 | **Femoral anteversion** | **3–8 歲（最常見）** | **W-sitting**、kissing patella、**IR > 70°、ER < 20°** | 8–10 歲前自癒 |

- 治療：**觀察與衛教**（矯正鞋無效）；紅旗：單側、疼痛、8–10 歲後仍持續、張力高（CP）、長短腳；嚴重 → femoral derotational osteotomy

- **Clubfoot（CTEV）**：**CAVE**（cavus、adductus、varus、equinus）；**Ponseti casting**（依序矯正）+ Achilles tenotomy + 外展支架
- Congenital vertical talus：rocker-bottom foot

## 十、骨與軟組織腫瘤

### 10.1 診斷原則

- **年齡**：< 5 歲 → 轉移性 neuroblastoma、LCH；10–25 歲 → **osteosarcoma、Ewing**；> 40 歲 → **轉移、MM、chondrosarcoma**
- **位置**

| 位置 | 腫瘤 |
|---|---|
| **Epiphysis** | **Chondroblastoma（骨未成熟）**、**GCT（骨成熟後，延伸至軟骨下）**、clear cell chondrosarcoma 〔113-1〕 |
| **Metaphysis** | **Osteosarcoma**、osteochondroma、UBC、ABC、NOF、chondromyxoid fibroma、bone infarct 〔114-2〕 |
| Diaphysis | **Ewing**、lymphoma、adamantinoma、osteoid osteoma、fibrous dysplasia |

- **骨膜反應**：侵襲性 → **Codman triangle、sunburst、onion-skin、hair-on-end**；良性 → 實心連續
- **切片原則** 〔115-1〕
    - **先完成 staging**（影像、胸部 CT、骨掃描）再切片；由**執行最終切除的團隊**做
    - 四肢**縱向切口**、**經過單一腔室**（不走筋膜間隙、不暴露神經血管）
    - 取組織時**同時送培養**（culture what you biopsy, biopsy what you culture）
    - 疑病理性骨折**不可先打髓內釘**（污染整段骨髓腔）

### 10.2 良性骨腫瘤

| 腫瘤 | 重點 |
|---|---|
| **Osteochondroma** | **最常見良性骨腫瘤**；metaphysis、背離關節生長；**MHE：AD（EXT1/EXT2）**；惡變警訊：成年後持續長、疼痛、**cartilage cap > 2 cm** 〔111-2, 112-1〕 |
| Enchondroma | 手部短骨最常見；**Ollier（多發）**、**Maffucci（+ 血管瘤）** → 惡變為 **chondrosarcoma** 〔112-1, 113-1〕 |
| Osteoid osteoma | < 2 cm nidus；**夜間痛、NSAIDs 有效**；RFA |
| **Chondroblastoma** | 青少年**骨骺** 〔113-1〕 |
| **GCT of bone** | 20–40 歲骨骺→軟骨下；**RANK/RANKL 失衡**（denosumab）；刮除**復發 10–25%**；肺轉移約 2–5% 〔113-1, 114-1〕 |
| **UBC** | 兒童**近端肱骨**（約半數）；**fallen fragment sign** 〔113-1, 114-1〕 |
| ABC | fluid-fluid level（鑑別 telangiectatic OS） |
| NOF | 兒童常見、偶然發現、自癒 |

### 10.3 偽腫瘤

- **Brown tumor**：HPT 骨吸收，組織像 GCT → 需驗 **Ca、PTH** 才能確診 〔115-2〕
- **Gaucher disease**：glucocerebrosidase 缺乏 → 肝脾腫大、**bone infarct**、Erlenmeyer flask deformity 〔114-2, 115-2〕
- **Bone infarct**：**metaphysis**（蛇形鈣化邊緣） 〔114-2〕
- **PVNS（TGCT）**：**膝最常見**、反覆血性積液、MRI blooming 〔114-2〕

### 10.4 惡性骨腫瘤

| | Osteosarcoma | Chondrosarcoma | Ewing sarcoma |
|---|---|---|---|
| 年齡 | 青少年（老人次發性） | **> 40 歲** | 兒童、青少年 |
| 位置 | **膝周 metaphysis**（股骨遠端 > 脛骨近端 > 近端肱骨） | 骨盆、近端股骨、肩 | 骨幹、骨盆 |
| X 光 | **Codman triangle、sunburst**、成骨/溶骨混合 | **Popcorn / rings-and-arcs 鈣化**、endosteal scalloping | **Onion-skin**、溶骨；似骨髓炎（發燒、ESR↑） |
| 分子 | RB1、TP53 | IDH1/2 | **t(11;22) EWS-FLI1**、**CD99** |
| 治療 | **新輔助化療 → 廣泛切除 → 輔助化療**；**化療後壞死 ≥ 90% 預後好** | **化放療不敏感 → 廣泛切除** | 化療 + 手術 / **放療（敏感）** |

〔110-1, 110-2, 111-2, 112-2, 113-1, 114-1, 115-1〕

- **Osteosarcoma 亞型** 〔110-2〕

| 亞型 | 特徵 |
|---|---|
| Conventional | 最常見、高惡性 |
| **Parosteal** | **股骨遠端後側、stuck-on / string sign、低惡性 → 廣泛切除即可** |
| Periosteal | 骨幹表面、sunburst、中度惡性 |
| **Telangiectatic** | 易與 **ABC** 混淆 |
| **Secondary** | **Paget disease、放療後**；**預後最差** |

- 低惡性 chondrosarcoma vs enchondroma：需**臨床 + 影像 + 病理**綜合判斷 〔110-1〕
- **Primary bone lymphoma**：DLBCL、單發者預後較好、化療 ± 放療 〔112-2〕
- **Multiple myeloma**：> 50 歲、punched-out lesions、**骨掃描常陰性**（純溶骨）→ skeletal survey / MRI

### 10.5 骨轉移

- **最常見的骨腫瘤 = 轉移**；來源：**乳、攝護腺、肺、腎、甲狀腺** 〔113-2〕
- 最常侵犯**脊椎**（Batson venous plexus）> 骨盆 > 近端股骨
- **成骨性：攝護腺**（乳癌可混合）；**溶骨性：腎、甲狀腺、肺、乳癌（多數）、MM**
- 病理性骨折風險：**Mirels score**（部位、疼痛、溶骨/成骨、大小）≥ 9 → 預防性固定

### 10.6 軟組織腫瘤

- 警訊：**> 5 cm、深於筋膜、持續長大、疼痛** → MRI + 切片（勿直接切除）
- 成人最常見軟組織肉瘤：**UPS、liposarcoma**；**synovial sarcoma**：年輕人、膝周、**t(X;18) SS18-SSX** 〔111-1〕
- **Desmoid（aggressive fibromatosis）**：局部侵襲不轉移、高復發
- **NF1**：MPNST 多源自 NF1（plexiform neurofibroma 惡變）

## 十一、代謝性骨病、骨感染與關節炎

### 11.1 鈣磷代謝與腎性骨病

- **PTH**：持續高 → 骨吸收（osteoclast 經 RANKL 間接活化）、腎保鈣排磷、活化維生素 D；**間歇性給予 → 刺激 osteoblast（anabolic）**
- **Renal osteodystrophy（CKD-MBD）** 〔110-1, 114-2〕
    - **磷滯留（高磷）** + 1α-hydroxylase↓（**活性維生素 D↓**）→ 低鈣 → **次發性 HPT**（FGF-23↑）
    - 骨病：**osteitis fibrosa cystica、brown tumor**、**rugger-jersey spine**、adynamic bone disease、軟組織鈣化
    - 相關檢驗：Ca、P、維生素 D、**PTH**（不是甲狀腺素）

### 11.2 骨質疏鬆症

| | Type I（停經後） | Type II（老年性） |
|---|---|---|
| 機轉 | **雌激素缺乏** → 骨吸收↑ | 老化、成骨↓、維生素 D/鈣↓ |
| 骨 | **小樑骨** | 皮質 + 小樑 |
| 骨折 | **脊椎、橈骨遠端** | **髖部** |

- 次發性：**steroid**、甲狀腺/副甲狀腺亢進、性腺低下、CKD、RA、藥物（PPI、抗癲癇） 〔115-1〕
- 診斷：DXA **T-score ≤ −2.5** 或脆弱性骨折；FRAX
- **藥物**

| 類別 | 藥物 | 機轉 |
|---|---|---|
| 抑制吸收 | **Bisphosphonate** | **抑制 osteoclast**（farnesyl pyrophosphate synthase）；ONJ、atypical femur fracture |
| | Denosumab | **RANKL 單株抗體**；停藥反彈骨折 |
| | SERM（raloxifene） | 降脊椎骨折、VTE 風險 |
| **促合成** | **Teriparatide / abaloparatide** | **間歇性 PTH → 刺激 osteoblast** 〔115-1〕 |
| 雙重 | Romosozumab | Anti-sclerostin |

### 11.3 其他代謝性骨病

- **Paget disease** 〔115-2〕：> 50 歲；**osteoclast 內包涵體**（paramyxovirus 假說）；溶骨期 → 混合期 → 硬化期；**ALP↑**（Ca/P 正常）；顱骨 cotton wool、骨盆/脛骨彎曲、**聽力損失**、高輸出心衰、**次發性骨肉瘤**；治療 bisphosphonate
- **Rickets / osteomalacia**：類骨質礦化不良；兒童 rachitic rosary、genu varum、幹骺端杯狀擴張；成人 Looser zones
- **Osteopetrosis**：osteoclast 功能缺陷 → bone-in-bone、易骨折、骨髓衰竭

### 11.4 骨與關節感染

| | 急性骨髓炎（兒童） | Septic arthritis |
|---|---|---|
| 機轉 | 血行性 → **metaphysis**（血流慢的 sinusoid） | 血行性、直接接種、鄰近骨髓炎 |
| 菌 | *S. aureus*（鐮刀型：Salmonella） | *S. aureus*；性活躍年輕人：**N. gonorrhoeae**；新生兒 GBS |
| 影像 | X 光 10–14 天後才變化 → **MRI** | 超音波看積液 |
| 治療 | 抗生素 ± 引流 | **緊急關節抽吸 + 沖洗** + 抗生素（軟骨數小時即破壞） |

- 慢性骨髓炎：sequestrum（死骨）、involucrum（新生骨殼）、sinus tract（**Marjolin ulcer**：SCC）

### 11.5 關節炎鑑別

| | RA | PsA | OA | Gout |
|---|---|---|---|---|
| 關節 | MCP、PIP、腕，**對稱**，不侵犯 DIP | **DIP**、不對稱 | DIP、PIP、拇指 CMC、膝髖 | **1st MTP** |
| 特徵 | 尺側偏斜、swan-neck、boutonnière | **Dactylitis**、enthesitis、**指甲病變** | Heberden（DIP）/ Bouchard（PIP） | Tophi、急性紅腫熱痛 |
| X 光 | **關節旁骨鬆**、marginal erosion、**均勻狹窄** 〔113-2〕 | **Pencil-in-cup**、侵蝕 + 新骨形成 | 骨刺、非對稱狹窄、軟骨下硬化 | Punched-out（overhanging edge） |

- **PsA**：asymmetric oligoarthritis 最常見；**CASPAR** 分類（RF 陰性加分）；治療 NSAIDs → MTX → TNF-i / **IL-17-i（IBD 避免）** / IL-23-i → JAK-i；**避免全身性 steroid**
- **TAE（transcatheter arterial embolization）**：栓塞慢性滑膜炎的異常新生血管（imipenem/cilastatin）→ 減痛；hand OA 小型研究、**仍屬實驗性**；同概念 genicular artery embolization（knee OA）

## 十二、足踝重建

### 12.1 後足生物力學

| 動作 | 跟骨 | 距骨 | 中足 | 功能 |
|---|---|---|---|---|
| **Pronation** | Eversion | 蹠屈 + 內收 | TN、CC 軸平行 → **unlocked** | 觸地吸震 |
| **Supination** | Inversion | 背屈 + 外展 | 軸交叉 → **locked** | 推進 |

- **Windlass mechanism**：拇趾背屈 → plantar fascia 拉緊 → 足弓上升、後足內翻 → 鎖住
- **Plantar fasciitis**：晨起第一步痛、跟骨內側結節；拉筋、鞋墊、ESWT

### 12.2 扁平足與 PTTD

- **PTTD（成人後天扁平足）**：hindfoot **valgus**、forefoot **abduction**；**single-limb heel rise 失敗（最敏感）**、**too many toes sign**；中年女性、肥胖、DM、HTN、steroid；內踝後下 watershed

| Stage | 描述 | 治療 |
|---|---|---|
| I | 腱鞘炎，無變形 | Boot / cast、NSAIDs |
| II | Flexible flatfoot | UCBL/AFO；**FDL transfer + medial displacement calcaneal osteotomy** ± Evans |
| III | Rigid | **Triple arthrodesis** |
| IV | + ankle valgus（deltoid） | Triple + deltoid 重建 / TTC fusion |

- 支撐：鞋墊（medial heel post、sustentaculum tali 支撐）、UCBL、AFO

### 12.3 高弓足（Cavus foot）

- **約 2/3 為神經肌肉病因，最常見 CMT** → 雙側：CMT、Friedreich ataxia、CP；**單側：脊髓病灶（必做 spine MRI）**、polio、外傷
- **CMT 機轉**：peroneus brevis 弱 < tibialis posterior → **後足內翻**；TA 弱 < peroneus longus → **第一蹠骨蹠屈**（forefoot-driven）；intrinsic 弱 → claw toes
- 檢查：**peek-a-boo heel**、**Coleman block test**（後足可矯正 = flexible、forefoot-driven）、Meary's angle apex dorsal
- 併發：外踝不穩、peroneal tendinopathy、**5th MT stress fracture**、lateral forefoot 壓力集中
- 治療順序：**軟組織平衡 → 骨性矯正 → 融合**

| 情況 | 術式 |
|---|---|
| Flexible、forefoot 為主 | Plantar fascia release、**1st MT dorsiflexion osteotomy**、peroneus longus → brevis |
| Rigid hindfoot varus | **Dwyer calcaneal osteotomy** |
| Foot drop | **Tibialis posterior transfer** |
| Claw hallux | Jones procedure |
| 嚴重 rigid | **Triple arthrodesis** |

### 12.4 Hallux valgus

- **成因**：遺傳、女性、**IMA↑（metatarsus primus varus）**、DMAA↑、**1st ray hypermobility**、扁平足、韌帶鬆弛；窄頭鞋/高跟鞋為促發；續發於 RA、CP、中風
- **惡性循環**：medial capsule 拉長 → MT head 內移 → **sesamoids 相對外移** → adductor hallucis 外拉 → **EHL/FHL bowstring** → abductor hallucis 移至足底 → 拇趾 pronation → 疊第二趾、**transfer metatarsalgia**

| 嚴重度 | HVA / IMA | 術式 |
|---|---|---|
| Mild | < 20° / < 11° | **Distal chevron** |
| Moderate | 20–40° / 11–16° | **Scarf** / chevron + soft tissue |
| Severe | > 40° / > 16° | **Proximal osteotomy** + modified McBride |
| 1st TMT hypermobility | — | **Lapidus** |
| 合併 1st MTP 關節炎 | — | 1st MTP arthrodesis |

- Akin osteotomy（HV interphalangeus）；第二趾 plantar plate repair + Weil osteotomy
- 手術適應症是**疼痛、穿鞋困難**（非外觀）；術前**站立 X 光**；併發：復發、**hallux varus**、transfer metatarsalgia、AVN
- **Beighton score（9 分）**：成人 **≥ 4/9** = generalized hypermobility；1st TMT instability：dorsal translation > 8–10 mm、2nd MTH 下 callus → **Lapidus**

### 12.5 Lesser toe deformities

| | MTPJ | PIPJ | DIPJ | 特徵 |
|---|---|---|---|---|
| **Hammer toe** | 輕伸 | **屈** | 伸/中立 | 單趾（**第二趾**最常見）、PIP 背側 corn；常合併 HV |
| **Claw toe** | **過伸** | **屈** | **屈** | 多趾、雙側、metatarsalgia → **查神經（CMT、DM）** |
| **Mallet toe** | 中立 | 中立 | **屈** | 趾尖 callus |

- 機轉：**intrinsic 無力** → EDL 拉 MTP 過伸、FDL/FDB 拉 IP 屈曲
- 治療：保守（寬頭鞋、toe crest、Budin splint、metatarsal pad）→ flexible：**FDL → extensor transfer** / FDL tenotomy → rigid：**PIP/DIP resection arthroplasty / arthrodesis** ± Weil osteotomy

### 12.6 足底壓力分析

| 指標 | 公式 | 意義 |
|---|---|---|
| Peak pressure | max F / A（kPa） | 瞬間最大 |
| **FTI** | ∫F dt（N·s） | **累積負荷**（衝量） |
| PTI | ∫P dt（kPa·s） | 單位面積累積 |
| Relative FTI | 區域 / 全足（%） | 負荷轉移，消除體重/步速差異 |

- 應用：HV（負荷轉到 MTH2–3）、**糖尿病足潰瘍風險**、扁平足（medial midfoot↑）、高弓足（lateral forefoot + heel↑）；限制：只量垂直力，無 shear
