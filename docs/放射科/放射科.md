# 放射科

!!! info "使用方式"
    放射科（影像醫學）在國考沒有獨立一卷，而是分散在各卷的影像題：醫學（三）、（四）第 74–75 題，醫學（五）、（六）第 72–74 題。每次約 10 題，多數附圖。
    本頁依系統整理（總論 → 神經 → 頭頸 → 胸 → 肝膽胰 → 消化道 → 泌尿 → 婦產 → 骨骼肌肉 → 小兒 → 外傷/介入），重點放在**「看到什麼徵象 → 想到什麼診斷」**。`〔113-2〕` = 113 年第二次考過此觀念。
    對應考古題（含答案、解析，章節編號相同；原圖請點題號連到考選部原卷）：[放射科考古題](放射科考古題.md)

## 〇、總論

### 0.1 檢查工具比較

| 工具 | 原理/特性 | 優勢 | 限制 |
|---|---|---|---|
| X 光 | 衰減：空氣（黑）< 脂肪 < 軟組織 < 骨/金屬（白） | 便宜、快；骨折、氣腹、氣胸、腸阻塞 | 軟組織對比差；有輻射 |
| 超音波 | 回音；**後方聲影**（結石、鈣化、氣體）、**後方增強**（液體） | 無輻射、即時、可攜；**膽、婦產、兒童、血管** | 操作者依賴；氣體與骨頭擋住 |
| CT | HU：水 0、脂肪 −100、血液 40–80、骨 +1000 | 快；**急診首選**（出血、外傷、急腹症） | 輻射；碘顯影劑 |
| MRI | T1 亮：**脂肪、亞急性血（methemoglobin）、gadolinium、黑色素、蛋白質**；T2 亮：**水** | 軟組織最佳；**腦、脊髓、骨髓、韌帶、骨盆** | 慢、貴；金屬/節律器禁忌 |
| 核醫 | 功能顯像（骨掃描、MAG3/DTPA、PET） | 功能、全身 | 解析度低 |
| DSA | 血管攝影 | 血管金標準 + **同時介入治療** | 侵入性 |

- **檢查選擇原則**：無輻射、最直接回答臨床問題的優先 〔112-1, 115-2〕
    - 兒童、孕婦 → 超音波/MRI
    - 不孕 → 經陰道超音波、HSG，**不用 CT** 〔112-1〕
    - 隱睪 → 超音波 〔115-2〕
    - 急性胰臟炎**不靠鋇劑**，評估嚴重度用顯影 CT 〔112-2〕
    - 固體食物**漸進性吞嚥困難** → 鋇劑食道攝影/內視鏡 〔113-1〕

### 0.2 顯影劑與輻射

- **碘顯影劑**：過敏樣反應、**顯影劑腎病變**（高危：eGFR < 30、脫水、DM）→ 水化；**metformin** 在腎功能差者暫停
- **Gadolinium**：嚴重腎衰竭 → **NSF**（腎因性全身纖維化）
- **鋇劑**：**疑似穿孔禁用**（改水溶性）；高滲透壓水溶性顯影劑**吸入 → 肺水腫**（新生兒 TEF 禁用）〔110-1〕
- 輻射：ALARA；**CT > 透視 > X 光**；超音波與 MRI 無游離輻射

## 一、神經放射

### 1.1 急性中風

| 時間 | CT | MRI |
|---|---|---|
| 超急性（< 6 h） | **常正常** 〔113-1〕；**hyperdense MCA sign** 〔112-2〕、insular ribbon、lentiform 模糊 | **DWI 數分鐘即變亮**（ADC↓） |
| 急性–亞急性 | 低密度、mass effect；**約 2 週 gyral enhancement**（2-2-2） | DWI 亮約 **10–14 天** 後 pseudonormalize 〔113-1〕 |
| 出血性轉化 | 可見 | **GRE/SWI 更敏感** 〔113-1〕 |

- 急性中風做 non-contrast CT 是為了**排除出血與 mimics（SDH、腫瘤）**；**CT 正常且在時窗內仍可打 tPA** 〔112-2〕
- CT 上**低密度範圍 > 1/3 MCA 區域**是 tPA 禁忌
- **反覆 TIA**：緊急評估血管（頸部聽診、頸動脈超音波、CTA/MRA、ECG）；**EEG 不需要** 〔114-1〕
- **頸動脈狹窄**：好發分叉處/ICA 起始；有症狀 ≥ 50–70% → CEA/CAS；**無症狀重度狹窄仍可考慮 CEA** 〔110-1〕

### 1.2 顱內出血

| | 形狀 | 來源 | 重點 |
|---|---|---|---|
| **EDH** | **雙凸（lens）**、**不跨骨縫** | 中腦膜動脈（顳骨骨折） | lucid interval |
| **SDH** | **新月形**、跨骨縫、不跨中線 | 橋靜脈（老人、酗酒、抗凝） | **亞急性（1–3 週）等密度易漏看** 〔114-1〕 |
| **SAH** | 腦溝、腦池 | **非外傷 85% 為動脈瘤** | CTA 找原因 〔111-1, 115-2〕 |
| ICH | 實質內 | 高血壓：基底核、視丘、橋腦、小腦 | 老人腦葉出血 → amyloid angiopathy |

- **出血在 CT 的密度變化**：急性高密度 → 亞急性等密度 → 慢性低密度
- **MRI 血液訊號口訣「It Be, Iddy Biddy BaBy, Doodoo」**：

| 時期 | T1 | T2 |
|---|---|---|
| 超急性 | 等 | 亮 |
| 急性 | 等 | **暗** |
| 早亞急性 | **亮** | 暗 |
| 晚亞急性 | **亮** | 亮 |
| 慢性 | 暗 | 暗（hemosiderin） |

- 自發性頭痛 + SAH + ICH → **動脈瘤/AVM，做 CTA**（不是外傷型態）〔115-2〕

### 1.3 腦動脈瘤與血管病變

- **囊狀動脈瘤**：**AComA > PComA > MCA 分叉**；巨大型（> 2.5 cm）可鈣化 〔114-2〕
    - **PComA 動脈瘤 → 瞳孔散大的 CN III 麻痺** 〔113-1〕
    - 診斷：CTA → **DSA（金標準）**；**首次血管攝影陰性約 15–20% → 1–2 週後重做** 〔114-2〕
    - 治療：**coiling 或 clipping** 〔112-1, 114-2〕
    - 併發症：再出血（< 24 h）、**水腦**、**vasospasm（4–14 天）**、低血鈉 〔111-1〕

| 疾病 | 影像關鍵 | 臨床 |
|---|---|---|
| **靜脈竇栓塞** | 平掃 **dense sinus / cord sign**；打藥 **empty delta sign** 〔110-2〕；非動脈分布的出血性梗塞 | 年輕女性、口服避孕藥、產後、脫水 |
| **頸動脈剝離** | **T1 fat-sat 新月形壁內血腫**、管腔狹窄；string sign 〔115-2〕 | **年輕人中風**、外傷、頸痛 + Horner |
| **FMD** | **string of beads** 〔113-1〕 | 年輕女性；**腎 > 頸**；ICA 中遠段（非分叉） |
| **直接型 CCF** | **上眼靜脈擴張**、海綿竇膨大；常合併顱底骨折 〔112-2〕 | 搏動性突眼、眼眶雜音 → **血管內栓塞**（非放射治療） |

### 1.4 腦腫瘤

- 第一步：判斷**腦實質內（intra-axial）或腦實質外（extra-axial）**

| 腫瘤 | 影像關鍵 |
|---|---|
| **腦膜瘤** | 腦實質外、寬基底貼硬膜、**均勻強烈顯影**、**dural tail**、CSF cleft、**骨增生/侵犯**；**包圍血管會使其狹窄** 〔114-2〕 |
| **腦下垂體大腺瘤** | 鞍內 → 鞍上，**snowman / figure-8**（鞍隔膜束腰）〔114-1〕；壓迫視交叉 → **雙顳側偏盲** 〔115-1〕；包住 ICA 通常不狹窄 |
| **Oligodendroglioma** | 額葉皮質、**鈣化（最常鈣化的膠質瘤）**、癲癇 〔112-1〕 |
| GBM | 不規則環狀顯影、中央壞死、跨胼胝體（butterfly） |
| **轉移** | **灰白質交界**、多發、**水腫明顯**；**成人後顱窩腦實質腫瘤最常見** 〔113-2〕 |

- 單發轉移可能與原發腦瘤無法區分；易出血的轉移：melanoma、RCC、choriocarcinoma、甲狀腺、肺

### 1.5 其他腦部疾病

| 疾病 | 影像 | 臨床 |
|---|---|---|
| **顱內低壓** | **SEEPS**：Subdural fluid、Enhancing pachymeninges（瀰漫平滑）、Engorged sinuses、Pituitary 充血、Sagging brain 〔110-1〕 | **姿勢性頭痛**；epidural blood patch |
| **缺氧缺血性腦病變** | 瀰漫水腫、**灰白質分界消失**、**reversal sign**、white cerebellum；基底核、分水嶺 〔114-2〕 | 心跳停止、心衰竭後昏迷 |
| **血管性失智** | 多發梗塞、白質高訊號、lacunes 〔111-2〕 | 階梯式退化 |
| Alzheimer / FTD | 海馬迴、內側顳葉 / 額顳葉（knife-blade）萎縮 | — |
| **TSC** | **室管膜下鈣化結節**、皮質 tubers、SEGA（Monro 孔 → 水腦）〔110-2〕 | 癲癇、智障、顏面血管纖維瘤 |

### 1.6 脊髓

- **脊髓梗塞**：**前脊髓動脈（ASA）最常見** → 前 2/3 症候群（運動、痛溫覺、括約肌；**保留本體/振動覺**）；T2 **owl's eye**；DWI 受限；主動脈手術後（Adamkiewicz T9–L2）〔114-1〕
- 脊髓血供：**一條 ASA + 一對 PSA**

## 二、頭頸部與眼眶

- **鼻咽癌（NPC）**：Rosenmüller 窩 〔112-1, 113-2, 115-1〕
    - 阻塞耳咽管 → **成人單側中耳/乳突積液**（耳悶、耳鳴）→ 必須排除 NPC
    - 往顱底/海綿竇侵犯 → **CN VI 最常**、III、IV、V → 複視、眼瞼下垂
    - MRI 評估顱底與咽後淋巴結
- **鼻竇炎**：Waters view 黏膜增厚、混濁、氣液面；**CT 為標準**（OMC）〔110-2〕
- **眼眶爆裂性骨折**：**眶底與內側壁**最常見；Waters view 可見 **teardrop sign**；**CT 冠狀切面**最佳；下直肌卡住 → 上視受限、眼球凹陷 〔110-2〕
- **甲狀腺眼病**：雙側；**肌腹腫大、肌腱保留**；**IR > MR > SR > LR**；**眶內脂肪也增生**；眶尖擠壓 → 視神經病變 〔111-2〕
    - 鑑別 orbital pseudotumor：單側、會痛、連肌腱一起侵犯
- **頸部腫塊**

| 疾病 | 位置/特徵 |
|---|---|
| **第二型腮裂囊腫** | **SCM 前內緣、頸動脈外側、頜下腺後方**；薄壁單房 〔111-1〕 |
| 甲狀舌管囊腫 | 中線、舌骨附近，隨吞嚥/伸舌移動 |
| Cystic hygroma | 嬰兒後頸三角、多房；Turner |
| 囊性/壞死淋巴結 | 成人要排除 HPV 口咽癌、甲狀腺乳突癌轉移 |

- **唾液腺**：**多形性腺瘤**最常見（耳下腺）；超音波**邊界清楚、分葉狀低回音、後方增強** 〔112-1〕；Warthin：老年男性吸菸、雙側；惡性：邊界不規則、顏面神經麻痺

## 三、胸腔與心血管

### 3.1 肺部

- **肺結節良性鈣化**：**中央型**、瀰漫實心、同心層狀、**爆米花（hamartoma）**；**含脂肪 → hamartoma** 〔113-2〕
    - 持續存在的 GGN 或 part-solid 結節 → 腺癌光譜（AIS/MIA）
- **肺結核**

| 活動性 | 陳舊/癒合 |
|---|---|
| **新出現/變大**、**開洞**、邊界不清實質化、**tree-in-bud**、肋膜積液 | **鈣化**（Ghon、Ranke complex）、纖維化、體積縮小 〔114-1〕 |

- **COPD**：過度充氣、橫膈變平、血管稀疏；**HRCT 是支氣管擴張的標準**（**signet ring sign**、tram-track）〔112-1〕
- **肺轉移**：**多發、圓形、邊緣平滑**、下肺周邊；常**不合併**淋巴結腫大 〔111-2〕
    - 骨轉移：**成骨性 = 攝護腺**（乳癌混合）；溶骨性 = RCC、甲狀腺、肺、骨髓瘤
- **氣胸**：張力性氣胸 = **持續累積的大量氣體** → **縱隔偏移、橫膈下壓或反轉**，屬臨床診斷，應立即減壓 〔114-2〕；仰臥 **deep sulcus sign**；吐氣相影像可讓小氣胸較明顯

### 3.2 縱膈

| 分區 | 常見腫瘤 |
|---|---|
| **前縱膈（4T）** | **T**hymoma、**T**eratoma（**脂肪 + 鈣化 + 液體**，年輕人）〔115-2〕、**T**hyroid、**T**errible lymphoma |
| 中縱膈 | 淋巴結、支氣管/前腸囊腫 |
| 後縱膈 | **神經源性腫瘤** |

### 3.3 心臟與大血管

- **冠狀動脈 CTA**：**LAD 走前室間溝**、LCx 走左房室溝、RCA 走右房室溝 〔115-2〕
- **PDA**：降主動脈近端（左鎖骨下動脈遠側）↔ 左肺動脈 〔111-2〕；主動脈縮窄：figure-3 sign、rib notching
- **主動脈瘤**：**CTA 是胸主動脈瘤的主要診斷工具**；壁**常鈣化**；經胸超音波看不到弓部與降主動脈；AAA 篩檢用腹部超音波 〔114-2〕
- **急性主動脈症候群**

| | 影像 | 治療 |
|---|---|---|
| 剝離 | **intimal flap**、真假腔 | A 型手術；B 型內科/TEVAR |
| **壁內血腫（IMH）** | 平掃**新月形高密度**壁增厚、**沒有 flap** 〔110-1〕 | 侵犯升主動脈 = **Stanford A** → 比照 A 型 |
| Penetrating ulcer | 動脈硬化斑塊潰瘍 | — |

- Stanford A = 侵犯升主動脈；DeBakey I（升 + 降）、II（只有升）、III（只有降）
- **DVT**：CT venography 充盈缺損；**首選加壓超音波**；抗凝為主；危險為**肺栓塞**；**May-Thurner**（左髂靜脈）〔111-2〕
- 影像判讀：先確認**切面**（axial/coronal/sagittal）與**有無顯影劑**，再辨認結構 〔110-2〕

## 四、肝膽胰

### 4.1 肝臟

- **門脈系統** = SMV + 脾靜脈（+ IMV）；**肝靜脈 → IVC，屬體循環** 〔115-1〕
- **Couinaud 分段**：肝靜脈縱向分隔，門脈橫向分隔
    - **鐮狀韌帶**分開左外節（II/III）與左內節（IV）〔111-1〕
    - 中肝靜脈分隔左右肝

| 病灶 | 動脈期 | 門脈/延遲期 | 其他 |
|---|---|---|---|
| **血管瘤** | **周邊不連續結節狀顯影** | **向心性填滿** 〔111-1, 113-1〕 | T2 **極亮（light bulb）**；超音波均勻高回音 |
| **HCC** | 顯影（arterial hyperenhancement） | **wash-out** + capsule | **門靜脈腫瘤栓塞**（浸潤型最常合併）〔110-1, 113-2〕 |
| FNH | 均勻強烈顯影 | 等密度；**中央疤痕延遲顯影** | 年輕女性 |
| 肝膿瘍 | 環狀顯影 | **cluster sign**、double target | 產氣 → *Klebsiella*（DM） |

- **肝硬化**：表面結節、**尾葉/左外葉肥大、右葉萎縮**、脾腫大、腹水、側枝循環 〔111-1〕
- **HCC 破裂**：腹腔積血 + 顯影劑外滲 → **緊急 TAE** 〔110-2〕
- **Budd-Chiari**：**肝靜脈/肝上段 IVC 阻塞**；**尾葉肥大**（直接回流 IVC）；nutmeg 斑駁顯影 〔113-1〕
- 門靜脈血栓：硬化肝的 bland thrombus vs **HCC 腫瘤栓塞**（會顯影、有動脈血流、使門脈膨大）〔110-1〕

### 4.2 膽道

| 疾病 | 影像關鍵 |
|---|---|
| **膽結石** | 超音波**高回音 + clean shadow + 隨姿勢移動** 〔111-1〕；WES sign；**X 光只有 10–15% 可見**（多面體層狀鈣化）〔112-2〕 |
| 急性膽囊炎 | 壁增厚、周圍積液、**sonographic Murphy**；HIDA 膽囊不顯影 |
| **腺肌症** | 壁增厚 + **Rokitansky-Aschoff sinuses** → **comet-tail artifact** 〔110-2〕；MRCP pearl necklace |
| **氣膽** | **中央（肝門）**線狀高回音 + dirty shadow 〔112-2〕（sphincterotomy、膽腸吻合、gallstone ileus） |
| 門脈氣體 | **周邊**分布（腸缺血、NEC）——預後差 |
| 瓷器膽囊 | 壁鈣化 → 膽囊癌風險 |

### 4.3 胰臟

- **急性胰臟炎**：靠臨床 + 酵素診斷；**顯影 CT 評估壞死與併發症**（**> 72 h** 做最準）；超音波找膽結石 〔112-2〕
    - **晚期併發症（> 4 週）**：**假性囊腫（最常見）**、walled-off necrosis、膿瘍、胰管中斷、脾靜脈血栓、**假性動脈瘤（脾動脈 > GDA > 肝動脈）** 〔112-1, 115-2〕
    - **膽結石是病因，不是併發症** 〔115-2〕
- **慢性胰臟炎**：**L1–L2 高度橫向斑駁鈣化**（腹部正中央鈣化）〔113-1〕；**X 光只有約 30% 可見，CT 最敏感** 〔111-2〕；主胰管 chain of lakes、萎縮

## 五、消化道與急腹症

### 5.1 食道與胃十二指腸

- **鋇劑食道正常壓迹**：**主動脈弓（左）→ 左主支氣管（左前）→ 左心房（前）** 〔112-1〕
- **食道裂孔疝氣**：**滑動型（type I）約 95%**、GEJ 上移、GERD；食道旁型易絞窄 → 手術 〔110-1〕
- **Achalasia**：擴張 + **bird's beak** + 蠕動消失、胃泡消失 〔111-1〕；確診用 manometry；老人要排除 pseudoachalasia（賁門癌）
- 十二指腸球部慢性潰瘍 → **cloverleaf deformity** 〔111-2〕

### 5.2 氣腹

- **直立胸部 X 光**或 **left lateral decubitus**（肝臟外側）最敏感，CT 最佳 〔110-2〕
- 仰臥徵象：**Rigler（double wall）**、**football**、**倒 V（外側臍韌帶）**、falciform ligament sign 〔111-2〕
- 陷阱：**Chilaiditi sign**（結腸位於肝臟與橫膈之間，可見皺摺）

### 5.3 扭轉、套疊與阻塞

| 疾病 | 族群 | 影像 |
|---|---|---|
| **乙狀結腸扭轉（最常見）** | 老人、療養院、便秘 | X 光 **coffee bean**、鋇劑 **bird's beak**、CT **whirl sign** 〔110-2, 114-1, 114-2〕；無腹膜炎 → 內視鏡減壓 |
| 盲腸扭轉 | 較年輕 | 擴張的盲腸位於左上腹 |
| **腸套疊** | 6 月–3 歲（特發）；**> 5 歲找 lead point** | 超音波 **target / doughnut**、pseudokidney 〔114-2〕；CT sausage |
| **中腸旋轉不良 + 扭轉** | 新生兒膽汁性嘔吐 | UGI：**DJ junction 不在左側**、**corkscrew**；超音波 SMA/SMV 顛倒、whirlpool 〔115-1〕 |
| 小腸阻塞 | 沾黏（最常見）、疝氣 | 擴張小腸 > 3 cm、氣液面；**transition point** |

- **SMV 血栓**：門脈期 SMV 內充盈缺損 + 腸壁增厚、腸繫膜水腫 〔113-2〕
- **闌尾炎**：**壓不扁、> 6 mm**、target、糞石；兒童/孕婦用超音波，成人用 CT 〔113-2〕

### 5.4 後腹腔

- 後腹腔腫塊：淋巴瘤（包住血管不壓迫）、肉瘤（脂肪肉瘤、UPS、平滑肌肉瘤）、**睪丸生殖細胞瘤轉移**（主動脈旁淋巴結）；**GBM 極少顱外轉移** 〔111-1〕

| 疾病 | 影像關鍵 |
|---|---|
| **Angiomyolipoma** | **巨觀脂肪（負 HU）** 〔110-1〕；TSC；> 4 cm 易出血 → 栓塞 |
| RCC | 強烈不均勻顯影（clear cell）；很少含脂肪；靜脈侵犯 |

| **髓質鈣化** | 腎錐體成簇鈣化：**MSK**、**dRTA**、副甲狀腺亢進 〔115-2〕；MSK 為 paintbrush |
| **Fournier's gangrene** | 會陰/陰囊**軟組織氣體** 〔112-2〕；DM → 緊急清創 |

- **膀胱破裂**：**逆行膀胱攝影/CT cystography 是診斷標準** 〔112-1〕

| | 腹膜內 | 腹膜外（較常見） |
|---|---|---|
| 機轉 | 膀胱脹滿時下腹受撞，**頂部**破裂 | **骨盆骨折** |
| 顯影劑 | 勾勒出**腸管**、流入結腸旁溝 | 膀胱周圍**火焰狀**（molar tooth） |
| 治療 | **手術** | 導尿管 |

- **尿道損傷**（尿道口出血）→ 先做逆行尿道攝影（RUG），**禁放 Foley**

## 七、婦產科影像

- 不孕：**TVUS → HSG**（輸卵管通暢）；MRI 問題導向；**不用 CT** 〔112-1〕
- **HSG**：正常 = 顯影劑從繖部**自由溢入腹腔**；**遠端膨大無溢出 = 輸卵管積水**（PID 後；IVF 前處理）〔114-2, 115-1〕

| 附件腫塊 | 影像關鍵 |
|---|---|
| **子宮內膜異位瘤** | **T1 高、T2 shading**；**T1 fat-sat 仍亮** 〔110-1〕；超音波 ground-glass |
| **成熟畸胎瘤（dermoid）** | **脂肪**（CT 負 HU、**fat-sat 變暗**）、**鈣化/牙齒**、Rokitansky nodule、dot-dash 〔114-2, 115-1〕；X 光見牙齒 〔111-2〕；併發**扭轉** |
| 囊腺瘤 | 大、薄壁、單房或少分隔、無實質結節 〔110-2〕 |
| 卵巢癌 | 厚分隔、**壁結節/實質成分且會顯影**、腹水、腹膜種植 |
| **TOA** | 年輕、發燒；**多房厚壁、壁顯影**、周圍發炎 〔112-2〕 |
| **Krukenberg** | 消化道原發（**胃 > 大腸**），**雙側實質**卵巢腫塊 〔113-1〕 |

- **子宮肌瘤**：X 光骨盆中線**爆米花狀粗鈣化**（退化）〔113-2, 115-1〕；超音波邊界清楚低回音 + 聲影
- **育齡女性急性腹痛 + 腹腔積血** → 子宮外孕破裂、黃體破裂；**sentinel clot sign**；**子宮內膜異位不會造成急性大量出血** 〔114-1〕

## 八、肌肉骨骼

### 8.1 骨折與外傷

- **隱匿性骨折**：骨折線邊緣骨吸收後，約 **7–10 天**較明顯 → 追蹤 X 光或 MRI 〔113-2〕
- **肘部脂肪墊**：前脂肪墊上抬（**sail sign**）或**看得到後脂肪墊** = 關節積液 → 當隱匿性骨折處理（成人橈骨頭、兒童髁上）〔112-2, 113-2〕
- 骨釘周圍透亮帶 = **鬆脫或感染** 〔113-2〕

| 損傷 | 影像徵象 | 合併傷 |
|---|---|---|
| **肩後脫臼** | **light bulb**、**trough line（reverse Hill-Sachs）**、rim sign；axial CT 最清楚 | 無法外轉；癲癇、電擊 〔115-2〕 |
| 肩前脫臼（最常見） | Hill-Sachs、Bankart | 腋神經 |
| **髖後脫臼** | 股骨頭向後上 + **髖臼後壁骨折** | **dashboard**；坐骨神經、AVN 〔112-1〕 |
| **Segond fracture** | 外側脛骨平台撕脫 | **ACL** 〔110-1, 114-2〕 |
| Reverse Segond | 內側 | PCL |
| ACL 斷裂 MRI | **pivot-shift 骨挫傷**（股骨外髁 + 脛骨外側平台後方）、脛骨前移 | Unhappy triad：ACL + MCL + **內側**半月板 |
| Chance fracture | 腰椎水平劈裂（安全帶） | **十二指腸**、胰臟 |

### 8.2 骨腫瘤

- 判讀順序：**年齡 → 位置（骨骺/幹骺端/骨幹）→ 邊界（移行帶）→ 基質 → 骨膜反應**

| 腫瘤 | 年齡/位置 | 影像關鍵 |
|---|---|---|
| **Osteosarcoma** | 青少年；**膝周 > 肱骨近端**幹骺端 | **骨樣基質**、**Codman triangle**、**sunburst** 〔113-1, 114-1〕 |
| Ewing | 兒童；骨幹 | **onion skin**、大軟組織腫塊 |
| Chondrosarcoma | > 40 歲 | 環弧狀（ring-and-arc）軟骨鈣化 |
| **Fibrous dysplasia** | 青年 | **毛玻璃**、**shepherd's crook**（股骨近端）〔110-1〕；McCune-Albright |
| Chondroblastoma | 青少年；**骨骺** | — |
| GCT | 20–40 歲；骨骺延伸至軟骨下 | 偏心溶骨、無硬化邊 |
| 轉移/骨髓瘤 | > 40 歲 | 骨髓瘤 punched-out，**骨掃描常陰性** |

- 侵襲性骨膜反應：Codman、sunburst、onion skin；良性：實心、平滑

### 8.3 關節炎、骨壞死與軟組織

| 關節炎 | X 光 |
|---|---|
| **RA** | **對稱 MCP/PIP/腕**、**關節周圍骨質疏鬆**、**邊緣侵蝕**、均勻變窄、尺側偏移 〔113-2〕 |
| OA | **DIP/PIP**、第一 CMC、骨刺、軟骨下硬化 |
| Gout | **overhanging edge 打洞樣侵蝕**、關節腔保留、tophi |

| 骨壞死 | 重點 |
|---|---|
| **股骨頭 AVN** | 酒精、類固醇；MRI 最敏感：**T1 蜿蜒低訊號帶**、T2 **double line**；晚期 **crescent sign** → 塌陷 〔115-1〕 |
| **Kienböck（月狀骨）** | 硬化、塌陷；**negative ulnar variance**、類固醇 〔115-1〕 |
| **SONK** | 老年女性、**股骨內髁**；軟骨下低訊號線 + 骨髓水腫（insufficiency fracture）〔115-2〕 |
| **OCD** | **青少年**；**股骨內髁外側面**、距骨頂、肱骨小頭；游離體 〔113-2〕 |

- **PVNS**：膝；含鐵血黃素 → **T2/GRE blooming**；反覆血性積液
- **鈣化性肌腱炎**：**棘上肌**；X 光不定形鈣化、超音波高回音 + 聲影；40–60 歲女性 〔115-2〕
- **足底筋膜炎**：筋膜**增厚 > 4 mm**、低回音（與對側比較）〔112-2〕
- **異位性骨化（HO）**：神經損傷/髖置換後；**髖 > 膝 > 肘**；**周邊成熟（zonal）**——與骨肉瘤相反；最早用骨掃描與 ALP 偵測 〔111-1〕
- **OPLL**：亞洲男性、**C3–C6**、椎體後緣條狀骨化 → myelopathy 〔111-2〕；DISH 為前縱韌帶連續 ≥ 4 節
- **壞死性筋膜炎**：深筋膜增厚、沿筋膜積液、**軟組織氣體**；**筋膜不顯影 = 壞死**（顯影代表仍有血流）；**不可因影像延誤清創** 〔113-2〕

## 十、外傷與介入放射

- **FAST**：找腹腔積血；**血行動力不穩 → 先急救，不可為了詳細影像延誤**
- **肝/脾鈍傷**：撕裂傷最常見、被膜下/實質血腫、**contrast blush = 活動性出血**；穩定者保守治療 ± **TAE**；門靜脈栓塞罕見 〔113-1〕
- 骨盆骨折出血（多為靜脈叢）：骨盆帶 → 腹腔無積血但仍不穩 → **血管攝影栓塞**或骨盆填塞
- **TACE**：HCC 由**肝動脈**供血（正常肝實質約 75% 來自門靜脈）；**肝外供血最常見 = 右下膈動脈** 〔115-1〕
- 介入放射應用：TAE（外傷、HCC 破裂、產後出血、咳血支氣管動脈）、動脈瘤 coiling、PCN/PTCD 引流、IVC filter、精索靜脈栓塞
