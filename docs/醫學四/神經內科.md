# 神經內科

!!! info "使用方式"
    依 110–115 年醫師（二）醫學（四）神經科考題整理（腦血管 → 癲癇 → 頭痛 → 睡眠 → 失智 → 動作障礙 → 脊髓 → 周邊神經 → 肌肉 → 脫髓鞘 → 感染 → 腫瘤）。`〔113-2〕` = 113 年第二次考過。
    虛線底線的名詞可點擊跳到定義（電腦上停留可看簡短提示）。
    對應考古題（含答案、解析，章節編號相同）：[神經內科考古題](神經內科考古題.md)

## 一、腦血管疾病

### 1.1 急性缺血性中風處置

| 項目 | 重點 |
|---|---|
| 影像 | 非顯影 CT 先**排除出血**（早期梗塞常正常，仍可溶栓）〔112-2〕；**DWI** 數分鐘即陽性〔111-1〕；出血性轉化 MRI（GRE/SWI）較 CT 敏感；DWI 異常約持續 2 週；1–2 週後可顯影加強〔113-1〕 |
| IV tPA | 發病 **≤ 4.5 h**；0.9 mg/kg（10% bolus、其餘 60 分鐘）〔115-1〕；治療前 BP **< 185/110**〔115-1〕；禁忌：ICH、**主動脈剝離**、48 h 內 NOAC（PT/aPTT 正常不能代表無 NOAC 作用）〔112-1〕 |
| 取栓（EVT） | 大血管阻塞（LVO）、救 **penumbra**；符合者**先 IV tPA 再橋接取栓**；灌流影像篩選可延至 24 h；不適用 lacunar〔114-1〕 |
| 血壓 | 未溶栓：**permissive**（> 220/120 才降）；185/110 只是溶栓門檻〔115-2〕 |
| 抗血栓 | 急性期**不常規抗凝**〔113-2〕；輕度中風/高危 TIA：**aspirin + clopidogrel** 短期 DAPT〔113-2, 115-2〕；動脈剝離：抗凝 ≈ 抗血小板〔113-2, 115-2〕 |
| **Malignant MCA**{ #malignant-mca } | 大片 MCA 梗塞 2–5 天水腫高峰、意識惡化 → **≤ 60 歲 48 h 內去顱減壓**〔111-2〕 |
| 降腦壓 | [ICP↑](#cushing "Cushing triad：高血壓、心搏過緩、呼吸不規則")：床頭 30°、高滲透壓、短暫過度換氣、減壓；**類固醇無效**（細胞毒性水腫）〔114-2〕 |

- 缺血串聯：ATP↓ → 去極化 → **glutamate excitotoxicity** → **細胞內 Ca²⁺↑** → 自由基、發炎、凋亡〔113-1〕
- 中風後併發症：吸入性肺炎、UTI、褥瘡、攣縮；**中風後憂鬱 SSRI 有效**〔110-2〕

### 1.2 中風定位

| 症候群 | 血管 / 位置 | 表現 |
|---|---|---|
| MCA | 心因性栓塞（AF）常見 | 對側偏癱（臉、上肢）、失語（左）/忽略（右）、凝視偏向病灶〔111-1〕 |
| **Lacunar**{ #lacunar } | 穿通動脈（lipohyalinosis） | pure motor、pure sensory、**ataxic hemiparesis**、dysarthria–clumsy hand；**無皮質徵候**〔111-2〕；刻板反覆 TIA（capsular warning）〔115-2〕 |
| AChA | ICA 分支 | **hemiplegia + hemihypesthesia + hemianopia**；少皮質徵候〔114-2〕 |
| Top of basilar | 基底動脈頂端 | 中腦、視丘、枕葉、內側顳葉（**少影響橋腦**）〔114-2〕 |
| **Wallenberg**{ #wallenberg } | VA / PICA → 外側延腦 | **同側臉 + 對側身體痛溫覺**、同側 Horner、同側 ataxia、**聲啞/吞嚥困難（nucleus ambiguus）**、眩暈〔110-2, 113-2〕 |
| **INO**{ #ino } | MLF | **不能內收那一側 = 病灶側**；對側眼外展眼震；convergence 正常〔111-1〕 |
| Amaurosis fugax | **同側 ICA**（眼動脈） | 單眼短暫黑矇〔115-1〕 |

### 1.3 腦出血與蜘蛛膜下腔出血

| | 重點 |
|---|---|
| 高血壓 ICH | **putamen** > thalamus > pons > cerebellum〔114-1〕；亞急性 T1 高訊號（methemoglobin）〔112-2〕；**CTA spot sign** = 血腫擴大、預後差〔112-1〕 |
| **CAA**{ #caa } | 老人**葉性出血** + SWI 皮質微出血/superficial siderosis〔115-1〕；葉性出血非高血壓好發〔112-1〕 |
| 抗凝相關 ICH | **Xa 抑制劑 → andexanet / 4F-PCC**；dabigatran → idarucizumab；warfarin → PCC + Vit K〔113-1〕 |
| SAH | 輕症（Hunt-Hess 1）最易誤診〔112-1〕；CTA 診斷、**coiling 或 clipping**、**nimodipine**〔112-1, 115-1〕；PComm 瘤 → 瞳孔放大 CN III 麻痺〔113-1〕；自發性 SAH + 實質出血 → CTA 排除血管病變〔115-2〕 |
| 未破裂動脈瘤 | ISUIA < 7 mm：前循環 ~0%、**後循環（含 PComm）~2.5%/5 年**；危險因子 **ADPKD**、家族史〔115-2〕 |
| SDH | **橋靜脈**撕裂〔112-1〕 |

### 1.4 中風預防與特殊病因

- 顱內動脈狹窄：**抗血小板（短期 DAPT）+ 積極危險因子控制**，不用抗凝〔112-2〕；症狀性顱外 ICA ≥ 70% → CEA/CAS
- 心因性：AF（CHA₂DS₂-VASc）、機械瓣 → 抗凝；**感染性心內膜炎 → 不抗凝**；NBTE（癌症）→ heparin〔111-2〕
- 癌症 + D-dimer 極高 + 多血管區 DWI → **Trousseau** 多發栓塞（鑑別[多發轉移](#tumor "灰白質交界、顯影")）〔113-2〕

| | 重點 |
|---|---|
| **CVT**{ #cvt } | 危險因子：OCP、懷孕、APS、易栓症、**高**同半胱胺酸、感染〔113-1〕；上矢狀竇/橫竇最常〔110-2〕；**empty delta sign**〔110-2〕；**合併出血仍抗凝**〔110-1, 113-2〕 |
| Moyamoya | 雙側 ICA 遠端狹窄 + 基底側枝（puff of smoke）〔112-2〕 |
| PRES | 高血壓、免疫抑制劑、子癲前症 → 頂枕葉血管性水腫；頭痛、視覺異常、癲癇；**臨床與影像皆可逆**〔112-1〕 |

## 二、癲癇

### 2.1 診斷與分類

- 癲癇 vs 昏厥：前驅盜汗、噁心、眼前發黑、姿勢/Valsalva、迅速恢復 → **昏厥**〔110-2〕；**convulsive syncope** 可有短暫抽動，不等於癲癇〔111-1〕
- 癲癇為臨床診斷：MRI/EEG 正常不能排除，EEG 偶發棘波不能單獨確診〔111-1〕
- 約 **60–70%** 單藥可控制；老人最常見病因為**腦血管病**〔113-1〕
- 誘發因子：停藥、睡眠剝奪、感染、代謝異常；**單純熱痙攣病史不是**〔112-2〕
- 額葉癲癇：睡眠中**短暫、刻板、叢發** hypermotor、發作後立即清醒〔114-2〕

| 症候群 | 特徵 | EEG | 用藥 |
|---|---|---|---|
| Childhood absence | 學齡、每天數十～上百次 10 秒恍神 | **3 Hz spike-wave** | ethosuximide、**VPA**、LTG〔112-1〕 |
| **JME**{ #jme } | 青春期、**晨起肌躍**（掉東西）± GTC ± absence；遺傳性全面癲癇（非難治）〔110-2〕 | **4–6 Hz polyspike-wave** | **VPA**；肝病/育齡 → **LEV**〔113-1〕；避免 PHT、CBZ〔111-1〕 |

### 2.2 抗癲癇藥物

| 情境 | 選擇 / 注意 |
|---|---|
| 起始原則 | 單一藥物、**start low, go slow**、依臨床反應調整〔114-1〕 |
| 肝硬化、老人 | **Levetiracetam**（腎排除、少交互作用）〔113-2〕 |
| 育齡女性 | **LTG、LEV** 最安全〔114-2〕；**VPA → NTD、IQ↓，避免**〔115-2〕；topiramate 唇顎裂；懷孕 LTG/LEV 清除率↑ → 監測濃度 |
| 基因 | **HLA-B\*1502**（亞洲人）→ CBZ/PHT 致 SJS/TEN〔111-2〕 |
| 交互作用 | PHT、CBZ（酵素誘導）→ 口服避孕藥失效〔111-2〕 |

### 2.3 重積癲癇

- **Status**{ #status }：痙攣 **≥ 5 分鐘**，或兩次發作間意識未恢復〔115-1〕
- 現場：**側躺**、保護頭部、不塞東西〔112-1〕
- 流程：**lorazepam IV**（5 分鐘後可重複）→ fosphenytoin / VPA / LEV → 難治：插管 + propofol / midazolam / phenobarbital〔115-1〕
- 兒童 CSE 死亡率約 3–5%（非 50%）；發燒者需 LP、成人需影像〔110-1〕

## 三、頭痛與顱內壓

### 3.1 原發性頭痛

| | 偏頭痛 | 緊縮型 | 叢發性 | Paroxysmal hemicrania |
|---|---|---|---|---|
| 時間 | **4–72 h** | 30 分–7 天 | 15–180 分 | **2–30 分、> 5 次/天** |
| 特徵 | 單側、搏動、中重度、活動加重；噁心/嘔吐 或 **畏光且怕吵**〔115-1〕 | 雙側緊箍 | 眼眶、自主神經症狀、男性、躁動 | 同側流淚流鼻水、女性 |
| 急性 | NSAIDs、**triptan**（心血管禁忌）、**ergotamine**（5-HT1B/1D + α）〔110-2〕、止吐劑 | 止痛藥 | 100% O₂、SC sumatriptan | — |
| 預防 | propranolol、flunarizine、**topiramate**、VPA、amitriptyline、**CGRP 單抗（erenumab）**、botox（慢性）〔111-1, 113-2, 114-1〕 | **amitriptyline**〔111-2〕 | verapamil | **Indomethacin（絕對有效）**〔114-2〕 |

- 預防用藥：每月 ≥ 4 次發作；依共病選藥（高血壓、躁鬱）；**carbamazepine 不是偏頭痛預防藥**〔111-1, 114-1〕
- 偏頭痛機轉：三叉神經血管系統、**CGRP**、5-HT〔112-2〕
- **MOH**{ #moh }：頭痛 ≥ 15 天/月 + 止痛藥過度使用 > 3 個月 → 停藥 + 預防用藥〔112-1〕
- 三叉神經痛：V2/V3、電擊樣、扳機點；**SCA 壓迫**最常見；**carbamazepine**；無效 → MVD〔113-1〕

### 3.2 次發性頭痛與顱內壓

- **自發性顱內低壓**：**姿勢性頭痛**（站起加重）、MRI **瀰漫性硬腦膜增強**、腦下垂；CSF 漏 → 硬膜外血液貼片〔110-1〕
- ICP↑：晨起頭痛、噴射性嘔吐、papilledema、CN VI 麻痺；**Cushing triad**{ #cushing } **= 高血壓 + 心搏過緩 + 呼吸不規則** → 腦疝前兆；LP 前先做影像〔110-1, 112-2〕

## 四、睡眠障礙

| 疾病 | 重點 |
|---|---|
| OSA | 肥胖、頸短、扁桃腺肥大、**下顎後縮**、肢端肥大〔112-1〕；NREM 與 REM 都會發生（REM 較重）〔110-1〕；**CPAP** |
| 中樞型 SA | 腦幹病灶、心衰竭、鴉片類〔110-1〕 |
| **Narcolepsy type 1**{ #narcolepsy } | 白日嗜睡 + **猝倒（情緒誘發、意識清楚）**+ 睡眠癱瘓 + 入睡幻覺；**hypocretin（orexin）缺乏**〔115-1〕 |
| DSPS | 青少年；**早晨照光**、傍晚 melatonin、chronotherapy；晚上照光錯誤〔113-1〕 |
| **RBD**{ #rbd } | 後半夜 **REM**、夢境實演、老年男性；**PSG：REM 無失張力**確診；**SSRI/SNRI 加重**；clonazepam、melatonin；**α-synucleinopathy 前驅**（PD、[DLB](#dlb "波動、視幻覺、RBD")、MSA）〔111-2, 115-2〕 |
| 夢遊/夜驚 | **NREM N3**、前 1/3 夜、隔天失憶、**無夢境實演**；多不需藥物〔112-2〕 |
| **RLS**{ #rls } | 想動的衝動、休息出現、**活動緩解**、傍晚加重；懷孕、**缺鐵**、CKD、合併 PLMS〔110-2, 113-2〕；補鐵（ferritin < 75）、α2δ ligand、dopamine agonist |
| Hypnic jerks | 生理性；睡眠不足、壓力、咖啡因、睡前劇烈運動加重〔114-1〕 |

## 五、失智症與高級皮質功能

### 5.1 阿茲海默症與 MCI

- **MCI**：客觀測驗異常（MoCA < 26）+ **日常功能保留**；失智症 = 影響獨立生活〔112-1〕
- 病理：細胞外 **Aβ 斑塊** + 細胞內 **tau 神經纖維糾結**；APP 經 **β-secretase → γ-secretase** 兩步裁切〔114-2〕
- 生物標記：CSF **Aβ42↓、p-tau↑**；MRI 海馬迴萎縮；amyloid PET(+)；FDG-PET **顳頂葉**低代謝〔110-1, 111-1〕
- 遺傳：早發型 **APP、PSEN1、PSEN2 = 體染色體顯性**{ #ad-genetics }；晚發型 APOE ε4〔114-1〕；**Down syndrome**：APP 在 21 號染色體 → 40 歲後 AD 病理〔112-2, 114-2〕
- 藥物：AChEI（donepezil、rivastigmine、galantamine）；**memantine = NMDA 拮抗劑**（中重度）〔113-1〕

### 5.2 其他失智症

| 類型 | 重點 |
|---|---|
| **DLB**{ #dlb } | 認知**波動**、**視幻覺**、[RBD](#rbd "REM 睡眠行為障礙")、parkinsonism；抗精神病藥極敏感；**避免 dopamine agonist**（加重幻覺）〔110-1〕 |
| 血管性 | 皮質下型：處理速度慢、注意力/執行功能差、步態異常、情緒低落；記憶相對保留；MRI 深部白質病灶〔111-2, 115-2〕 |
| CADASIL | **NOTCH3**（AD）、先兆偏頭痛、年輕中風、失智；白質病灶累及**前顳極、外囊**〔111-2〕 |
| **NPH**{ #nph } | **步態（最早、最明顯）**+ 失智 + 尿失禁；腦室不成比例擴大〔110-1〕；**CSF tap test**〔110-2〕；shunt 後**步態最易改善**、術前腦壓正常、效果隨時間遞減〔115-1〕 |
| Pseudodementia | **憂鬱症**造成的可逆性認知障礙〔115-2〕 |

- 譫妄 vs 失智：急性、波動、注意力差；**震顫不能排除譫妄**；急診先驗血糖〔112-2〕

### 5.3 普里昂病

- Prion = 錯誤摺疊蛋白（**非病毒、無核酸**）；散發型最多（~85%）〔112-2〕；潛伏期長；一般滅菌不足〔112-1〕
- **sCJD**{ #cjd }：快速進展失智 + **驚嚇肌躍** + ataxia/視覺；DWI **皮質緞帶、尾核/殼核高訊號**；EEG PSWC；CSF RT-QuIC/14-3-3〔113-1〕
- **vCJD**：年輕人、精神症狀先發、pulvinar sign〔112-1〕

### 5.4 失語、失用、暫時性全面失憶

- **複誦保留 = transcortical**（分水嶺）；只有複誦壞 = conduction〔111-2〕
- **Ideomotor apraxia**：能口述步驟，但無法比劃/模仿；左頂葉〔115-1〕
- **TGA**：順行性失憶 + 部分逆行性、反覆問同樣問題、< 24 h 恢復；誘因：情緒、用力、Valsalva；**偏頭痛為危險因子**、不增加中風〔114-1〕

## 六、動作障礙

### 6.1 巴金森氏病

- 典型：單側起始、靜止性 pill-rolling 顫抖（動作時減輕、動腦加重）、**小寫症**、手擺動減少、面具臉〔111-2〕
- **早期**出現凍僵步態、跌倒、自主神經衰竭、垂直凝視麻痺 → 想 atypical parkinsonism〔111-1〕
- 非動作症狀：嗅覺喪失、便秘、[RBD](#rbd "REM 睡眠行為障礙")、憂鬱、姿勢性低血壓、失智〔113-2〕
- **Rigidity**：與速度無關（lead-pipe/cogwheel）vs **spasticity**：速度依賴、clasp-knife〔114-2〕

| 治療 | 重點 |
|---|---|
| Levodopa | 最有效；**最低有效劑量**（高劑量 → wearing-off、dyskinesia）〔112-2〕 |
| Dopamine agonist | 年輕患者；**D3 → 衝動控制障礙**（賭博、購物）〔110-2, 112-2〕 |
| MAO-B 抑制劑、anticholinergic | 輕症/年輕顫抖型；**AChEI 只用於 PD 失智**〔115-1〕 |
| DBS | **STN / GPi**，藥效波動者〔112-2〕 |

### 6.2 非典型巴金森症候群

| | 病理 | 特徵 | 影像 |
|---|---|---|---|
| **MSA** | **α-synuclein**（glial inclusion） | 早期**自主神經衰竭**（姿勢性低血壓、ED）+ parkinsonism/ataxia〔112-1〕 | **hot cross bun** |
| **PSP** | tau（4R） | **垂直（向下）凝視麻痺**、頸後仰、**早期向後跌倒**〔114-2〕 | hummingbird sign |
| CBD | tau（4R） | 不對稱、alien limb、失用 | 不對稱頂葉萎縮 |
| DLB | α-synuclein | 見 [DLB](#dlb "波動、視幻覺、RBD") | — |

- Synucleinopathy：PD、DLB、**MSA**；tauopathy：AD、PSP、CBD〔115-2〕
- 後天性 parkinsonism：藥物、[NPH](#nph "步態 + 失智 + 尿失禁")、缺氧、腦炎、中風；**CO 中毒 → 雙側蒼白球**〔111-1, 113-2〕

### 6.3 顫抖、舞蹈症與遺傳性疾病

| 疾病 | 重點 |
|---|---|
| **Essential tremor** | 雙側對稱**姿勢/動作性**（非靜止性）、家族史、喝酒改善；排除甲亢、藥物（lithium、VPA）；propranolol、primidone、BZD；難治 → MRgFUS/DBS〔115-2〕 |
| **Huntington** | AD、**HTT CAG**、anticipation；精神症狀（憂鬱、**自殺**）→ 舞蹈症 → 皮質下失智；尾核萎縮〔112-2, 114-1〕 |
| SCA | AD、進行性 ataxia、構音障礙、**慢速眼跳**、反射亢進；台灣以 SCA3 最多〔114-1〕 |

### 8.3 運動神經元疾病

- **ALS**{ #als } = **UMN + LMN**：萎縮 + 反射亢進、舌顫、球麻痺〔112-1, 114-2〕
