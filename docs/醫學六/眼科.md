# 眼科

!!! info "使用方式"
    系統性整理眼科觀念（基礎 → 屈光/水晶體 → 眼表角膜 → 青光眼 → 葡萄膜炎 → 視網膜 → 神經眼科 → 小兒/斜視弱視 → 眼瞼淚器眼窩 → 外傷急症）。`〔113-2〕` = 113 年第二次國考考過此觀念。
    虛線底線的名詞可點擊跳到定義。
    對應考古題（含答案、解析，章節編號相同）：[眼科考古題](眼科考古題.md)

## 一、眼科基礎

### 1.1 角膜

| 層次（前 → 後） | 重點 |
|---|---|
| 上皮 | 幹細胞在**輪部（limbus）**；可再生 |
| **Bowman layer** | **前基質的無細胞層**（非上皮基底膜）；**受損不再生 → 疤痕** 〔110-1, 115-1〕 |
| 基質 | 佔 90% 厚度；膠原纖維由 **proteoglycan** 維持等距 → 透明 |
| Descemet membrane | **內皮細胞的基底膜**；Wilson 銅沉積（KF ring） |
| 內皮 | **幾乎不分裂**（靠擴大移行代償）；**pump + barrier** 維持基質約 78% 含水；過少 → 不可逆水腫 → DMEK/DSAEK 〔110-1, 112-2〕 |

- 屈光力：**角膜約 +43 D（全眼的 2/3）**、水晶體約 +20 D 〔115-1, 115-2〕
- 角膜**無血管、無淋巴** → **免疫特權（immune privilege）**，移植排斥率低 〔113-1〕
- 眼表感覺：**V1（nasociliary → long ciliary nerves）** 〔114-1〕

### 1.2 房水循環

- **睫狀體無色素上皮**分泌（carbonic anhydrase、Na⁺/K⁺-ATPase）→ 後房 → 瞳孔 → 前房 → 排出 〔112-1〕
    - **Conventional（~90%）**：trabecular meshwork → **Schlemm canal → 上鞏膜靜脈（靜脈系統，非淋巴）**；睫狀肌收縮（pilocarpine）拉開小樑網 → 排出↑
    - **Uveoscleral**：prostaglandin analogue 增加此途徑
- 房水：蛋白質低、**維生素 C 高**

### 1.3 隅角評估

- **Gonioscopy 結構（前 → 後）**：**Schwalbe line → trabecular meshwork → scleral spur → ciliary body band**；閉角時後方結構被虹膜遮住（看不到 ciliary body band）〔112-1〕
- **Van Herick**：周邊前房深度 / 角膜厚度 **≤ 1/4 → 窄角 → gonioscopy** 〔115-1〕

### 1.4 視力評估

- 近視者遠距裸視必下降；**輕度遠視可靠調節維持良好遠視力** → 裸視好≠沒有遠視 〔111-2〕
- **Retinoscopy = 客觀驗光**（非檢查視網膜）〔113-1〕
- **RAPD（Marcus Gunn pupil）**：swinging flashlight → 病側光照時雙瞳擴大 → 視神經或廣泛視網膜病變（不見於白內障、屈光不正）

## 二、屈光與水晶體

### 2.1 屈光不正

| | 定義 | 矯正 |
|---|---|---|
| 近視 | 焦點在視網膜前；**軸性為主（眼軸 +1 mm ≈ −3 D）** 〔113-1〕 | 凹透鏡 |
| 遠視 | 焦點在視網膜後；兒童易引起調節性內斜視 | 凸透鏡 |
| **散光** | **角膜曲度不均**（不同經線屈光力不同）〔114-1〕 | 柱鏡；**不規則散光 → 硬式隱形眼鏡** 〔112-1〕 |
| 老花 | 水晶體彈性↓、調節力↓（非屈光不正）〔111-1〕 | 近用凸透鏡 |

- **斜視不是屈光不正** 〔111-1〕
- **假性近視** = 睫狀肌調節痙攣 → **睫狀肌麻痺劑（atropine、cyclopentolate，散瞳劑）**，**不是縮瞳劑**；**睫狀肌麻痺驗光後仍近視 = 真性近視** 〔112-1, 113-1〕
- **兒童近視控制**：**低濃度 atropine**、角膜塑型片（ortho-K）、**戶外活動**、近視控制鏡片

### 2.2 白內障

- **症狀**：漸進無痛模糊、**眩光**、**單眼複視**、對比敏感度↓、核性 → **近視化（second sight）**；**乾眼不是白內障症狀** 〔110-1〕
- **全身相關原因** 〔112-2〕

| 原因 | 型態 |
|---|---|
| **年齡** | 核性、皮質、後囊下 |
| **DM** | Snowflake、早發老年性 |
| **類固醇** | **Posterior subcapsular** 〔112-2〕 |
| **Myotonic dystrophy** | Christmas tree |
| **Atopic dermatitis** | Anterior subcapsular（shield） |
| Wilson | Sunflower |
| 先天 | TORCH（rubella）、galactosemia、Down |
| 其他 | 外傷、放射線、葡萄膜炎、低血鈣 |

- **Graves disease 不是**白內障常見原因 〔112-2〕
- **無水晶體眼（aphakia）→ 約 +10～+12 D 高度遠視** → 需植入 IOL 〔113-2〕

### 2.3 先天性白內障

- **Leukocoria 鑑別之一**（必排除 retinoblastoma）〔111-2〕
- **單側緻密 > 雙側**：單側最易產生**遮蔽性弱視** → **6 週內手術**；雙側 < 10 週；雙眼輕微可觀察
- 術後：**aphakic glaucoma**、後囊混濁、需屈光矯正 + 遮蓋

### 2.4 水晶體移位與類固醇副作用

- **Ectopia lentis** 〔113-1, 114-1〕

| 疾病 | 方向 |
|---|---|
| **Marfan**（FBN1） | **上顳側（superotemporal）** |
| **Homocystinuria** | **下鼻側（inferonasal）**、易全脫位 |
| Weill-Marchesani | 小球形水晶體 |

- **類固醇眼部副作用**：**後囊下白內障、眼壓上升（steroid-induced glaucoma）、CSCR**、感染（HSV、黴菌）、傷口癒合延遲；視神經炎反而是類固醇的治療對象 〔112-2〕

## 三、眼表與角膜疾病

### 3.1 結膜炎

| 類型 | 分泌物 | 結膜反應 | 重點 |
|---|---|---|---|
| **病毒（adenovirus）** | **水性** | **濾泡（follicles）**、耳前淋巴結 | **EKC**、高度傳染 〔111-1, 111-2〕 |
| 細菌 | 黏液膿性 | 乳突 | |
| **淋病** | **超急性大量膿性** | — | 可角膜穿孔 → **全身 ceftriaxone** 〔111-2〕 |
| **披衣菌** | **黏液膿性** | 濾泡 | 成人包涵體結膜炎；新生兒最常見 |
| 急性過敏 | 水性、劇癢 | **乳突（papillae）**、結膜水腫 | |
| 慢性過敏/乾眼 | **黏液** | | 〔111-2〕 |
| **VKC** | 黏稠 | **上瞼巨大鵝卵石乳突、Horner-Trantas dots（輪部嗜酸性球）**、shield ulcer | **年輕男孩、溫暖季節** 〔110-2〕 |
| Trachoma | — | 上瞼濾泡、Herbert pits、Arlt line | 全球可預防盲主因 |

- **新生兒結膜炎（< 1 個月）**：化學性（< 24 h）、**淋病（2–5 天）**、**披衣菌（5–14 天，最常見）**、HSV 〔111-1〕

### 3.2 感染性角膜炎

- **細菌**：上皮缺損 + 基質浸潤 + 水腫；**隱形眼鏡 → Pseudomonas**；**外傷（植物）→ 黴菌**；隱形眼鏡 + 水 → **Acanthamoeba**（不成比例疼痛、環狀浸潤） 〔110-2〕
- 處置：**中央大潰瘍刮片培養 + 染色** → **經驗性強效抗生素（fortified / fluoroquinolone）**；**菌種未明前禁用類固醇** 〔110-1〕
- 預後：基質感染**癒合後多留疤**（nebula → macula → leukoma）；嚴重 → 溶解、穿孔 〔110-1, 110-2〕

#### Herpes

| | HSV | HZO（VZV） |
|---|---|---|
| 潛伏 | **三叉神經節**、**反覆復發** 〔113-2〕 | 三叉神經節（V1） |
| 角膜 | **樹枝狀潰瘍（dendrite + terminal bulbs）**、地圖狀、基質炎、內皮炎；角膜感覺↓ | Pseudodendrite、基質炎、神經營養性角膜炎 |
| 其他 | **Trabeculitis → 高眼壓**、葡萄膜炎、ARN | **Hutchinson sign（鼻尖水泡）→ 眼部侵犯高風險**；葡萄膜炎、ARN、視神經炎、腦神經麻痺 〔112-2〕 |
| 治療 | 上皮型：**抗病毒、禁類固醇**；基質型：抗病毒 + 類固醇 | **全身抗病毒（72 h 內）** |

### 3.3 其他角膜疾病

- **Keratoconus**：青春期起進行性**角膜變薄前凸 → 不規則散光**；**揉眼（atopy、VKC）**、**Down**、Marfan、EDS；Munson sign、Vogt striae、Fleischer ring；**RGP、corneal cross-linking（阻止進展）**、角膜移植 〔114-2〕
- **Pterygium**：**鼻側**三角形纖維血管組織侵入角膜；**UV**；切除 + **結膜自體移植 / MMC** 降低復發 〔114-2〕
- **Limbal stem cell deficiency**：**化學灼傷（鹼最嚴重）**、**SJS/TEN**、眼部類天疱瘡、**長期隱形眼鏡**、aniridia → 結膜化、新生血管 → 輪部幹細胞移植；Sjögren 主要致乾眼 〔112-1〕

### 3.4 全身疾病與藥物的角膜表現

| 表現 | 原因 |
|---|---|
| **Vortex keratopathy（渦狀）** | **Amiodarone**、**chloroquine/HCQ**、indomethacin、tamoxifen、**Fabry** 〔113-1〕 |
| 內皮/水晶體前囊色素 | Chlorpromazine |
| **Kayser-Fleischer ring** | **Wilson：Descemet 銅沉積**（非脂質）〔114-1〕 |
| **Arcus** | 老年；**< 40 歲 → 查高血脂** |
| **中央基質膽固醇結晶 + 早發 arcus** | **Schnyder dystrophy → 血膽固醇↑** 〔112-2〕 |
| Band keratopathy | 高血鈣、慢性葡萄膜炎（JIA） |
| **夜盲、Bitot spots、角膜軟化** | **維生素 A 缺乏** 〔114-1〕 |

### 3.5 乾眼症

| 淚膜層 | 來源 | 檢查 |
|---|---|---|
| **脂質層**（外） | **Meibomian gland** | **TBUT < 10 秒 → 蒸發型（MGD 最常見）** 〔115-2〕 |
| **水層** | **淚腺 + Krause、Wolfring 副淚腺** | **Schirmer**（**局麻後 = 基礎分泌**；< 5–10 mm/5 min）、tear meniscus（正常 0.2–0.4 mm） |
| **黏液層**（內） | **杯狀細胞** | — |

〔114-1, 115-2〕

- 螢光染色：看上皮缺損；**lissamine green / rose bengal**：看結膜損傷
- 治療：人工淚液 → 熱敷、眼瞼清潔（MGD）→ cyclosporine / lifitegrast → 淚點栓塞

## 四、青光眼

### 4.1 分類總覽

| | POAG | NTG | PACG | 續發性 |
|---|---|---|---|---|
| 眼壓 | > 21 | **≤ 21** | 高（急性可 > 50） | 依原因 |
| 隅角 | 開 | 開 | **閉** | 開/閉 |
| 族群 | **非裔最高**、白人最常見類型 | **東亞（日本）** | **亞洲人、女性** | — |
| 特徵 | 無症狀、周邊視野先缺 | **Disc hemorrhage**、夜間低血壓、偏頭痛 | 遠視、短眼軸、淺前房 | — |

〔115-1, 115-2〕

- 青光眼視神經病變：**C/D ratio↑**、rim notching（ISNT rule 破壞）、RNFL 變薄、**arcuate scotoma、nasal step**
- 檢查：眼壓、**CCT**、gonioscopy、視神經/OCT、視野

### 4.2 開角型青光眼與高眼壓症

- **POAG 危險因子**：**眼壓**、年齡、**家族史**、非裔、**薄角膜**、高度近視、DM、**兩眼眼壓差 ≥ 4 mmHg** 〔115-2〕
- **Ocular hypertension**（> 21 mmHg、無視神經病變）轉化風險（OHTS）：**高眼壓、薄 CCT、大 C/D、年長** 〔114-1〕
- **CCT**：厚角膜 → 眼壓**高估**；薄角膜 → 低估且結構脆弱
- **NTG**：亞洲人常見、**disc hemorrhage**、注意**夜間低血壓（降血壓藥）**；角膜偏**薄**（非厚） 〔115-1〕
- **Steroid responder**：局部 > 眼周注射 > **口服/吸入/皮膚也可以**；小樑網細胞外基質堆積；效價越高越明顯；POAG 病人較易 〔114-1〕

### 4.3 閉角型青光眼

- **危險因子**：**遠視、短眼軸、淺前房、水晶體增厚（年長）、女性、亞洲人** 〔115-2〕
- 誘發：暗處、散瞳、抗膽鹼藥、**topiramate（雙側、睫狀體前旋）**
- **急性發作（AACG）**：劇烈眼痛、頭痛、**噁心嘔吐**、虹視、視力模糊；**角膜水腫、中度散大固定瞳孔**、淺前房、眼壓 > 40–50

!!! danger "AACG 急診處置"
    **降眼壓**：topical β-blocker + α2 agonist + CAI、**IV mannitol / 口服 acetazolamide** → **pilocarpine**（角膜清後才有效）+ **局部類固醇** → 角膜清澈後 **laser peripheral iridotomy（LPI，雙眼）**。
    **Laser trabeculoplasty 用於開角**，不是急性閉角的處置。〔110-2〕

### 4.4 續發性青光眼

| 類型 | 機轉 | 隅角 |
|---|---|---|
| **Phacomorphic** | **膨大白內障推擠虹膜** | **閉** 〔111-1〕 |
| **Phacolytic** | 過熟白內障蛋白漏出 → 巨噬細胞阻塞小樑網 | 開 |
| **Neovascular（NVG）** | 視網膜缺血 → **VEGF** → 虹膜/隅角新生血管 → 纖維血管膜 | 閉 |
| Steroid-induced | 小樑網外基質堆積 | 開 |
| Uveitic / Posner-Schlossman | 小樑炎（CMV、HSV） | 開 |
| Pigment dispersion / PXF | 色素/剝脫物阻塞 | 開 |
| Traumatic | Hyphema、angle recession | 開 |

- **NVG 三大原因：PDR、ischemic CRVO、ocular ischemic syndrome**（CRAO 較少）→ **anti-VEGF + PRP** + 降壓/引流管 〔114-2〕

### 4.5 降眼壓藥物

| 藥物 | 機轉 | 副作用 / 禁忌 |
|---|---|---|
| **Prostaglandin analogue**（latanoprost） | ↑ **uveoscleral outflow** | **第一線**；虹膜變深、睫毛增長、眼周脂肪萎縮、CME、葡萄膜炎 |
| **β-blocker**（timolol） | ↓ 房水生成 | **氣喘、COPD、心搏過緩、心衰禁用** 〔114-2〕 |
| α2 agonist（brimonidine） | ↓ 生成 + ↑ outflow | 過敏性結膜炎；**< 2 歲禁用（CNS 抑制、呼吸暫停）** |
| **CAI**（局部 dorzolamide；口服 acetazolamide） | ↓ 生成 | 口服：**paresthesia、低血鉀**、代謝性酸中毒、腎結石、**sulfa 過敏**；局部效果較弱 〔113-2〕 |
| Pilocarpine | ↑ trabecular outflow | 閉角；瞳孔小、近視化、頭痛 |
| Mannitol | 高滲透壓 | 急性 |

### 4.6 先天性青光眼

- **三主徵：溢淚、畏光、眼瞼痙攣** 〔111-1〕
- **角膜水腫**、**Haab striae**（Descemet 破裂）、**buphthalmos（眼球變大）**、近視化、C/D 增大
- 治療以**手術**為主（goniotomy、trabeculotomy）
- 鑑別：**先天性鼻淚管阻塞**（有分泌物、無畏光、角膜正常）

## 五、葡萄膜炎

### 5.1 分類與表現

- 前（虹膜炎）：紅眼、疼痛、畏光、**ciliary flush**、前房 cells/flare、KP、**hypopyon**、後沾黏
- 中間（pars planitis）：飛蚊、snowballs
- 後/全：視力下降、玻璃體混濁、視網膜血管炎、脈絡膜炎
- **肉芽腫型**（mutton-fat KP、虹膜結節）：**sarcoidosis**、TB、梅毒、**VKH**、交感性眼炎 〔114-1〕
- **非肉芽腫型**：**HLA-B27**、Behçet、JIA

### 5.2 重要病因

| 疾病 | 重點 |
|---|---|
| **HLA-B27 AAU**（AS、ReA、IBD、PsA） | **年輕男性**；**急性前葡萄膜炎、非肉芽腫**、**單側、兩眼交替復發**、纖維素滲出、hypopyon 〔111-1, 112-1〕 |
| **Behçet** | 反覆口腔潰瘍 + 生殖器潰瘍、皮膚、**pathergy**；眼：**閉塞性視網膜血管炎**（動靜脈皆可）、**移動性 hypopyon**、雙側；**HLA-B51 相關但非診斷必要**（臨床診斷）；類固醇、azathioprine、**anti-TNF** 〔112-2〕 |
| **VKH** | **亞洲人**；攻擊**黑色素細胞**；**前驅期（頭痛、腦膜炎、CSF pleocytosis、耳鳴聽損）→ 急性雙側葡萄膜炎 + 滲出性視網膜剝離 → 恢復期（sunset glow fundus、vitiligo、poliosis、alopecia）**；全身高劑量類固醇 〔110-2〕 |
| Sarcoidosis | 肉芽腫型、雙側；CXR（肺門淋巴結）、ACE、lysozyme 〔115-1〕 |
| **JIA**（oligoarticular、ANA+） | **無症狀**慢性前葡萄膜炎 → 定期篩檢；band keratopathy、白內障、青光眼 |
| Posner-Schlossman | 單側反覆、**高眼壓 + 輕微發炎**；CMV → **前房穿刺 PCR** 〔115-1〕 |
| **CMV retinitis** | **HIV CD4 < 50**；pizza-pie / brushfire；ganciclovir 〔111-2〕 |
| **ARN** | HSV/VZV；周邊壞死 → RRD |
| Toxoplasmosis | 舊疤旁 headlight in fog |

- **兒童 hypopyon** → 先想 **masquerade：retinoblastoma、白血病**、感染；HLA-B27 AAU 好發年輕成人 〔110-1〕

### 5.3 實驗室檢查

- **CXR**：sarcoidosis、TB；**HLA-B27**：AAU、AS 〔115-1〕
- **梅毒**：**nontreponemal（RPR、VDRL）追蹤療效 → 治療後效價下降**；**treponemal（FTA-ABS、TPPA）終身陽性** 〔115-1〕
- **Aqueous tap PCR**：HSV、VZV、CMV、toxoplasma
- HIV 不是疱疹病毒（retrovirus）；疱疹病毒：HSV、VZV、**EBV、CMV** 〔111-2〕

## 六、視網膜與玻璃體

### 6.1 年齡相關黃斑部退化（AMD）

- **已開發國家不可逆視力喪失最常見原因**；> 50 歲（非只 70 歲以上）〔113-2〕
- 危險因子：**年齡、抽菸（最重要可改變）**、家族史（CFH）、白人

| | 乾性（85–90%） | 濕性（10–15%） |
|---|---|---|
| 病灶 | **Drusen**、RPE 萎縮、**geographic atrophy** | **CNV**、出血、滲出、**disciform scar** |
| 視力 | 緩慢 | **快速、嚴重視損（佔多數重度視損）** |
| 治療 | **AREDS2**（lutein、zeaxanthin、Zn、Cu、vit C/E）、GA：complement inhibitor | **Anti-VEGF**（ranibizumab、aflibercept、faricimab）〔111-2, 113-1〕 |

- 症狀：**中心視力模糊、metamorphopsia（Amsler grid）、central scotoma**；**周邊視野保留** 〔114-2〕
- **PDT（verteporfin）**：PCV、CSCR

### 6.2 糖尿病視網膜病變（DR）

- **危險因子**：**病程（最重要）**、HbA1c、**高血壓**、**腎病變**、血脂、**懷孕（會惡化）**、血糖快速下降（early worsening）、白內障手術；**肝病無關** 〔114-1, 115-2〕

| 分期 | 表現 | 處置 |
|---|---|---|
| Mild NPDR | 只有微血管瘤 | 每年追蹤 |
| Moderate NPDR | 出血、硬性滲出、棉絮斑 | 3–6 個月 |
| **Severe NPDR** | **4-2-1 rule**：4 象限出血、2 象限靜脈串珠、1 象限 IRMA | 考慮 PRP |
| **PDR** | **新生血管（NVD/NVE）**、玻璃體/視網膜前出血 〔112-1〕 | **PRP** 或 anti-VEGF 〔114-2〕 |
| **DME**（任何期） | 黃斑水腫（OCT） | **Anti-VEGF 第一線** |

- 晚期：玻璃體出血、**TRD**、**NVG** → vitrectomy

### 6.3 視網膜剝離

| 類型 | 機轉 | 原因 | 治療 |
|---|---|---|---|
| **Rhegmatogenous** | 裂孔 → 液化玻璃體進入視網膜下 | **PVD**、**高度近視**、**lattice**、鈍傷、白內障術後 〔114-1〕 | **Scleral buckle、PPV、pneumatic retinopexy**；**不用 PDT** 〔113-1〕 |
| **Tractional** | 纖維血管膜牽拉 | **PDR、ROP**、穿透傷、sickle cell；**急性 PVD 不是** 〔111-2〕 | PPV |
| **Exudative** | 無裂孔、視網膜下滲液 | **VKH**、腫瘤、惡性高血壓、Coats、CSCR | 治療原因 |

- **RRD 表現**：**飛蚊、閃光（photopsia）、窗簾樣視野缺損**；**眼壓偏低**（約低 5 mmHg）、**輕微 iritis**、**tobacco dust（Shafer sign）**、廣泛 → **RAPD**；黃斑侵犯 → 視力驟降、**micropsia**（非 macropsia） 〔110-2, 113-2〕
- **CRVO 不會造成 RRD** 〔114-1〕
- 急性飛蚊/閃光 → **散瞳周邊檢查**；裂孔 → **雷射圍堵** 〔115-2〕

### 6.4 高度近視病變

- 病理性近視（> −6 D 或眼軸 > 26.5 mm）{ #pathologic-myopia } 〔110-1〕

| 後極部 | 周邊 |
|---|---|
| **Posterior staphyloma** | **Lattice degeneration** |
| **Lacquer cracks** | 視網膜裂孔 → **RRD** |
| **Myopic CNV → Fuchs spot** | |
| Chorioretinal atrophy | |
| **Myopic traction maculopathy**（foveoschisis、黃斑裂孔） | |

- **Angioid streaks 不是**高度近視病變（Bruch 膜破裂：**PXE**、Paget、sickle cell、EDS）〔110-1〕
- **Myopic CNV**（約 10%）→ **anti-VEGF**（注射次數較 AMD 少）；年輕者預後較好；**近視雷射只改角膜，不降低 CNV 風險**；葉黃素無證據 〔111-1, 115-1〕
- **OCT 看後極部**（黃斑裂孔、foveoschisis、CNV、staphyloma）；**lattice 在周邊 → 散瞳間接眼底鏡** 〔112-2〕
- 同時增加：POAG、早發核性白內障

### 6.5 血管阻塞與其他

- **CRAO**：突發無痛單眼全盲、**cherry-red spot**、RAPD → 中風等級急症（找栓子來源）
- **CRVO**：**blood and thunder**；缺血型 → **NVG（100-day glaucoma）**；黃斑水腫 → anti-VEGF
- **CSCR**：年輕男性、A 型性格、**類固醇** → 漿液性黃斑剝離
- **Shaken baby syndrome**：**< 3 歲、雙側多層多量視網膜出血** + 硬腦膜下出血、無明顯外傷 → **通報** 〔112-2〕
- **ROP**：早產、低體重、氧氣 → 周邊無血管區 → 新生血管 → **TRD**；ICROP3 分區分期；治療雷射/anti-VEGF

### 6.6 眼內腫瘤

- **眼內最常見惡性腫瘤 = 轉移**（脈絡膜，血流豐富）：**女性乳癌、男性肺癌** 〔112-1〕
- 成人原發：**uveal melanoma**（肝轉移）
- **Retinoblastoma**{ #retinoblastoma }：
    - **RB1（13q14）**；雙側/多發 → 生殖細胞突變（遺傳）、**pinealoblastoma（trilateral）**、**骨肉瘤**等第二腫瘤
    - **Leukocoria（最常見）**、斜視、假性前房蓄膿
    - 檢查：麻醉下**間接眼底鏡**、**超音波（鈣化）**、**MRI**（視神經、松果體）；**OCT 非必要** 〔113-2〕
    - 鑑別 leukocoria：**先天性白內障**、Coats、ROP、PHPV、toxocariasis、RD

## 七、神經眼科

### 7.1 視神經疾病

| | 典型視神經炎 | NAION | Papilledema |
|---|---|---|---|
| 族群 | **年輕女性** | > 50 歲、血管危險因子、**小杯盤（disc at risk）** | 任何（IIH：肥胖年輕女性） |
| 視力 | 亞急性下降 | 晨起突發無痛 | **早期正常**、短暫模糊 |
| 疼痛 | **眼球轉動痛** | 無痛 | 頭痛 |
| 側別 | 單側 | 單側 | **雙側** |
| 視盤 | **2/3 正常（retrobulbar）** | 節段性水腫 | 雙側水腫 |
| 視野 | central scotoma | **altitudinal** | 盲點擴大 |
| 其他 | **RAPD、色覺↓**、**VEP latency 延長**；**MS 第一表現** | GCA 須排除（AAION） | ICP↑ |

〔115-2〕

- **Optic neuritis 治療（ONTT）**：**IV methylprednisolone** 加速恢復（不改最終視力）；**口服 prednisone 單用增加復發**；MRI 決定 MS 風險
- 非典型（雙側、嚴重、無痛、不恢復）→ **NMOSD（AQP4）、MOGAD**
- **視盤水腫鑑別**：papilledema、視神經炎（papillitis）、NAION、**惡性高血壓**、糖尿病乳頭病變、**CRVO**、浸潤；**青光眼 → 杯盤凹陷（不是水腫）** 〔111-2〕

### 7.2 視路與視野

| 病灶 | 視野 |
|---|---|
| 視神經 | 單眼缺損 + RAPD |
| **視交叉** | **Bitemporal hemianopia**（垂體腺瘤、顱咽管瘤） |
| 視束 | **不一致**對側同側偏盲 + RAPD |
| 顳葉（**Meyer loop**） | 對側**上**象限盲（pie in the sky） |
| 頂葉 | 對側**下**象限盲 |
| **枕葉** | **高度一致**對側同側偏盲、**macular sparing**（PCA） 〔115-1〕 |

- 影像：**鈣化、骨折 → CT**；軟組織、視神經、發炎、出血 → MRI 〔115-1〕

### 7.3 眼球運動神經

- **LR6 SO4**，其餘 CN III（MR、SR、IR、IO、提上瞼肌、瞳孔括約肌） 〔110-2〕
- **CN III palsy**：眼位**下外**、上瞼下垂

!!! danger "瞳孔受累的 CN III palsy"
    **瞳孔散大 → 壓迫性**（**PCOM aneurysm、uncal herniation**；瞳孔纖維位於神經外周）→ **緊急 CTA/MRA**。
    **瞳孔正常 → microvascular（DM、HTN）**，數月內恢復。〔114-2〕

- **CN IV palsy**：**患眼上斜（hypertropia）**、內收時加重、**頭傾向對側**；Bielschowsky 傾頭測試（傾向患側加重）〔114-1〕
- **CN VI palsy**：內斜、外展受限；ICP↑（假定位徵象）、**鼻咽癌**侵犯

### 7.4 多腦神經症候群

| 症候群 | 腦神經 |
|---|---|
| **Superior orbital fissure** | **III、IV、V1、VI** |
| **Orbital apex** | **SOF + II（視力受損）** |
| Cavernous sinus | III、IV、V1、V2、VI + 交感 |
| **Miller Fisher** | **Ophthalmoplegia + ataxia + areflexia**（anti-GQ1b） |
| **Horner** | **只有交感**：ptosis、miosis、anhidrosis（不屬多腦神經） |

〔113-1〕

- **鼻咽癌（台灣）**：經顱底侵犯海綿竇 → **CN VI（最常）**、III、IV、V；成人新發腦神經麻痺 → 查鼻咽 〔113-2〕

### 7.5 上瞼下垂與瞳孔不等

| 原因 | 瞳孔 | 特徵 |
|---|---|---|
| **CN III（壓迫）** | **大** | 致命 → 急診影像 〔114-2〕 |
| CN III（microvascular） | 正常 | DM、HTN |
| **Horner** | **小** | 輕度下垂（Müller muscle）、無汗 |
| **Myasthenia gravis** | **正常** | **易疲勞、波動、可單側**；**ice pack test**、Cogan lid twitch 〔110-1〕 |
| Aponeurotic（老年） | 正常 | 提肌功能好、雙眼皮線高 |
| **Marcus Gunn jaw-winking** | 正常 | 先天，咀嚼時上瞼抬起 |

- **Ocular MG**：任何形式的複視 + 下垂、**不影響瞳孔**、不會突眼；AChR Ab（ocular 陽性約 50%）、SFEMG；合併 **thymoma**、自體免疫甲狀腺病 〔110-1, 112-1〕
- 突眼 + 複視：TED、眼窩血腫/腫瘤/蜂窩組織炎、CCF、orbital apex（MG 不會）〔112-1〕

## 八、小兒眼科、斜視與弱視

### 8.1 弱視

- 定義：**視覺發育關鍵期（< 7–8 歲）**的異常視覺刺激 → **最佳矯正視力仍差、眼球結構正常**；可**雙側**；成人後天視力差（白內障）不是弱視 〔111-2〕

| 類型 | 原因 |
|---|---|
| **Strabismic** | **恆定單側**斜視（內斜、外斜皆可；**間歇交替性風險低**）〔112-2〕 |
| **Anisometropic** | 兩眼屈光差（遠視差尤其） |
| Isoametropic | 雙眼高度屈光不正 |
| **Deprivation（最嚴重）** | **單眼先天性白內障**、完全性下垂、**眼瞼血管瘤**、角膜混濁 〔113-2〕 |

- **治療順序**：**矯正屈光 / 去除遮蔽** → **遮蓋好眼** 或 **atropine penalization**；**斜視手術不能治弱視**（改善眼位）〔110-2, 111-1〕
- **學齡前篩檢**視力與立體感；越早治療效果越好 〔111-2〕

### 8.2 斜視

- **Refractive accommodative esotropia**：2–3 歲、**中高度遠視** → 過度調節帶動內聚 → **睫狀肌麻痺驗光後完全遠視矯正眼鏡** 〔110-1, 113-1〕；高 AC/A → 雙焦
- Infantile ET：< 6 個月、大角度 → 早期手術
- Intermittent XT：最常見外斜，疲倦/強光時出現
- **假性內斜視**：寬鼻樑、**內眥贅皮**、窄瞳距、**negative angle kappa** → Hirschberg 反光置中、cover test 無移動；**ROP 黃斑顳側拉移 → positive kappa → 假性外斜視** 〔114-2〕
- **Congenital SO palsy**：常見兒童垂直斜視；患眼 **hypertropia**；需與 TED、MG 鑑別 〔114-1〕
- 檢查：Hirschberg、cover/uncover、alternate cover、prism

### 8.3 先天性鼻淚管阻塞（CNLDO）

- **Hasner valve**（鼻淚管遠端，開口於**下鼻道**）未開通 〔113-2〕
- 溢淚 + 黏液膿性分泌物、按壓淚囊有分泌物
- **約 90% 一歲前自癒** → **Crigler massage** + 局部抗生素 → **6–12 個月以上 probing**；不需立即手術 〔112-1〕
- 鑑別：**先天性青光眼**（畏光、角膜水腫、眼球大）

### 8.4 先天性眼瞼異常

- **Congenital ptosis**：**提上瞼肌發育不良（纖維化）** → 依 **levator function**：良 → levator resection；**差（< 4 mm）→ frontalis sling**；術後 **lagophthalmos** → 暴露性角膜炎；遮住瞳孔 → **弱視**（遮好眼治療）；**不同於一般雙眼皮手術** 〔114-2〕
- **BPES（FOXL2，AD）**：**blepharophimosis、ptosis（提肌差）、telecanthus、epicanthus inversus**；下眼瞼**外翻**（非內翻）；type I 卵巢早衰 〔110-1〕

## 九、眼瞼、淚器與眼窩

### 9.1 甲狀腺眼病變（TED）

- **成人單/雙側突眼最常見原因**；**女 > 男**；**抽菸**最重要可改變危險因子 〔110-2, 113-2〕
- 機轉：**TSHR / IGF-1R 自體抗體** → 眼窩纖維母細胞活化 → **眼外肌肥大 + 眼窩脂肪增生**（兩者皆有）〔111-2〕
- **嚴重度與甲狀腺功能不平行**（甲亢、甲低、正常皆可） 〔110-2〕

| 徵象 | 定義 |
|---|---|
| **Lid retraction（Dalrymple）** | **最常見、最具特徵** 〔110-1〕；Müller 肌交感過度 + 提肌纖維化/沾黏 |
| **Lid lag（von Graefe）** | **往下看時上瞼跟不上**（≠ lid retraction 的定義）〔111-2〕 |
| Proptosis | 突眼 → 暴露性角膜炎 |
| Restrictive myopathy | **IR > MR > SR > LR（"I'M SLOw"）** → **上轉受限、複視** 〔112-2, 115-2〕 |
| Compressive optic neuropathy | 眼窩尖端擁擠 → 視力/色覺↓、RAPD |

- **CT：肌腹肥大、肌腱不受影響（tendon sparing）**（vs orbital myositis：肌腱也腫）〔112-2〕
- 合併下垂 → 懷疑**合併 MG** 〔113-2〕
- 治療原則 〔113-2, 115-2〕
    - **甲狀腺功能維持正常**（**甲低也會惡化**）
    - **RAI 會惡化活動期 TED → 合併口服類固醇**
    - 輕度：潤滑、**硒**、戒菸
    - 中重度活動期：**IV methylprednisolone**、**teprotumumab**、眼窩放療
    - **威脅視力（壓迫性視神經病變、嚴重暴露性角膜病變）→ 高劑量 IV 類固醇 / 緊急眼窩減壓**
    - 穩定期（≥ 6 個月）重建順序：**眼窩減壓 → 斜視 → 眼瞼**

### 9.2 眼窩與淚腺腫瘤

| 族群 | 良性 | 惡性 |
|---|---|---|
| **兒童** | **Infantile capillary hemangioma**（增大後**自行消退**；propranolol）、dermoid cyst | **Rhabdomyosarcoma**（快速突眼） |
| **成人** | **Cavernous venous malformation（海綿狀血管瘤）**（緩慢增大、**不會消退** → 有症狀切除） | **Lymphoma**、轉移 |

〔111-1〕

- **淚腺腫塊**（顳上方 → 眼球被推向**前下內**）〔113-1〕
    - 最常見為**發炎**
    - 上皮性：**pleomorphic adenoma**（最常見良性；**整塊切除、不可先切片**——破囊易復發惡變）
    - **Adenoid cystic carcinoma**（最常見上皮惡性；**侵犯神經 → 疼痛**）

### 9.3 眼窩感染

| | Preseptal cellulitis | Orbital（postseptal）cellulitis |
|---|---|---|
| 來源 | 皮膚外傷、**蚊蟲叮咬**、麥粒腫、上呼吸道 | **篩竇炎（最常見）** |
| 表現 | 眼瞼紅腫 | **突眼、眼球運動受限且痛、視力↓、RAPD** |
| 處置 | 口服抗生素 | **CT、IV 抗生素** ± 引流 |
| 併發症 | 可擴散成 orbital、甚至**腦膜炎**（兒童，H. influenzae 時代）〔115-1〕 | 骨膜下膿瘍、**海綿竇栓塞**、腦膜炎、腦膿瘍 |

- 常見菌：*S. aureus*、*Streptococcus*

### 9.4 眼瞼疾病

- **Benign essential blepharospasm**：中年女性、**雙側**不自主閉眼（基底核）、**壓力、強光**誘發、常合併乾眼 → **botulinum toxin**；肉毒副作用：**下垂、閉眼不全、下眼瞼外翻**、複視（**不會改善內翻**）〔111-1〕
    - vs **hemifacial spasm**：單側、CN VII 血管壓迫
- **Nocturnal lagophthalmos → 暴露性角膜病變**（**晨起下方結膜/角膜發炎**）：TED、**Bell palsy**、肉毒後遺症、眼瞼術後；**眼瞼痙攣是過度閉眼（不是原因）** 〔115-1〕
- 眼瞼腫瘤：**BCC 最常見**（下瞼、內眥）；sebaceous gland carcinoma（偽裝成反覆 chalazion）

### 9.5 淚液排流

- 淚點 → 淚小管 → 總淚小管（valve of Rosenmüller）→ 淚囊 → 鼻淚管 → **Hasner valve → 下鼻道**
- **Jones test → 淚液排流功能**；**Schirmer → 分泌功能** 〔110-2〕
- 成人鼻淚管阻塞 → 淚囊炎 → **DCR**

## 十、眼外傷與急症

### 10.1 化學灼傷

- **鹼 > 酸**（鹼穿透、皂化；酸凝固蛋白形成屏障）
- **立即大量沖洗**（至 pH 7，**不等檢查**）→ 評估輪部缺血 → 類固醇、抗生素、維生素 C、doxycycline → 晚期 **LSCD**

### 10.2 眼窩爆裂性骨折（Blow-out fracture）

- 機轉：大於眼窩口的鈍物（**網球 > 小彈珠**）→ 眼窩內壓↑ → **最薄處破裂：眼窩底（infraorbital groove）、內壁（lamina papyracea）**（**非外壁、非上壁**）〔114-1, 110-2, 113-1〕
- 表現：**上看受限、垂直複視（IR 嵌頓）**、**眶下神經麻木**、**眼球凹陷**、皮下氣腫（勿擤鼻涕）
- 影像：**CT 冠狀切面**為首選；Waters view 可見 **teardrop sign** 〔110-2〕
- **手術時機**

| 情況 | 時機 |
|---|---|
| **兒童 trapdoor（white-eyed）+ oculocardiac reflex（噁心、嘔吐、心搏過緩）** | **緊急** |
| 複視持續 > 2 週、眼球凹陷 > 2 mm、骨折 > 50% 眼窩底 | 1–2 週內 |
| 複視逐漸改善 | **觀察** 〔114-1〕 |

### 10.3 眼球鈍傷

- **Hyphema**：紅血球阻塞小樑網 → **眼壓↑**；**再出血（3–5 天）**；sickle cell 易高眼壓/角膜血染（避免 CAI）→ 床頭抬高、散瞳劑、局部類固醇 〔111-2〕
- **Retrobulbar hemorrhage → orbital compartment syndrome**（突眼、緊繃、眼壓↑、視力↓、RAPD）→ **緊急 lateral canthotomy + cantholysis**；**隔前出血不會**造成 〔111-2〕
- **Open globe（ruptured globe）**：**360° 結膜下出血**、深前房、低眼壓、**瞳孔變形（淚滴狀）**、Seidel test；**視力不一定很差** → **金屬眼罩保護、勿加壓、勿點藥** → 緊急修補 + 預防眼內炎 〔111-2〕
- 其他：commotio retinae（Berlin edema）、choroidal rupture、traumatic iritis、angle recession（遲發青光眼）、RRD

### 10.4 其他急症

- **UV keratitis（電焊、雪盲）**：暴露 6–12 h 後劇痛、畏光、點狀角膜上皮病變 → **cycloplegic + 抗生素藥膏 + 人工淚液**；**禁止開立局部麻醉劑回家**（延遲癒合）〔113-1〕
- **隱形眼鏡相關紅眼** → 停戴、涵蓋 **Pseudomonas（fluoroquinolone）**，嚴重者刮片 〔113-1〕
- **甲醇中毒** → formic acid → **無痛**視神經病變、視盤水腫、失明 〔113-1〕
- **急性紅眼危險徵象**：視力下降、劇痛、畏光、角膜混濁、瞳孔異常、眼壓↑ → 轉眼科（AACG、角膜炎、葡萄膜炎、眼內炎）
