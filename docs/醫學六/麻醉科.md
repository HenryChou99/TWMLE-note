# 麻醉科

!!! info "使用方式"
    系統性整理麻醉科觀念（術前評估與呼吸道 → 監測 → 藥理 → 區域麻醉 → 特殊族群 → 術後與疼痛 → 重症）。`〔113-2〕` = 113 年第二次國考考過此觀念。
    對應考古題（含答案、解析，章節編號相同）：[麻醉科考古題](麻醉科考古題.md)

## 一、術前評估與呼吸道處置

### 1.1 呼吸道評估

#### Modified Mallampati（坐姿、張口伸舌、不發聲）

| Class | 可見結構 |
|---|---|
| I | 軟顎、咽門、懸雍垂、扁桃柱 |
| II | 軟顎、咽門、懸雍垂 |
| **III** | **軟顎 + 懸雍垂基部** 〔115-1〕 |
| **IV** | **只見硬顎** 〔110-1〕 |

#### 困難預測

| 情境 | 預測因子 |
|---|---|
| **困難插管** | **Mallampati III–IV** 〔111-1〕、張口 < 3 指、**thyromental < 6 cm**、頸部活動受限、短頸、大舌、門牙突出、上唇咬合測試差 |
| **LEMON** | **L**ook externally、**E**valuate **3-3-2**（張口 3 指、**下巴到舌骨 3 指**、舌骨到甲狀軟骨 2 指）、**M**allampati、**O**bstruction/Obesity、**N**eck mobility 〔115-1〕 |
| **困難面罩通氣** | **OBESE / BONES**：肥胖、**鬍鬚** 〔112-2〕、無牙、打鼾/OSA、> 55 歲；頸部放療 |
| 困難 SGA | 張口受限、咽部病灶、肥胖 |
| 困難環甲膜切開 | 肥胖、放療、腫瘤、無法摸到解剖標記 |

### 1.2 呼吸道輔具

| 工具 | 重點 |
|---|---|
| **口咽呼吸道** | **無意識**病人（清醒者誘發嘔吐、喉痙攣） 〔111-2〕 |
| **鼻咽呼吸道** | **清醒/半清醒可耐受**；禁忌：**顱底骨折**、凝血異常；併發鼻出血 〔111-2〕 |
| **Venturi mask** | **固定 FiO₂ 給氧**，**不能正壓通氣** 〔110-2〕 |
| LMA（SGA） | 可正壓通氣；不防吸入；困難呼吸道救援 |
| **FOB（flexible bronchoscope）** | 經口/鼻、清醒/麻醉皆可；**頸部不需移動 → 不穩定頸椎、預期困難插管的清醒插管首選** 〔113-1〕 |
| Video laryngoscope | 不需對齊三軸、困難插管 |

- **面罩通氣困難時改善**：**head tilt-chin lift、jaw thrust、口/鼻咽呼吸道、雙人雙手扣面罩**；**用力往下壓面罩反而加重阻塞** 〔111-2〕

### 1.3 清醒插管

- 適應症：預期困難插管/面罩通氣、不穩定頸椎、full stomach 合併困難呼吸道 〔113-2〕
- 表面麻醉/神經阻斷 〔114-1〕

| 神經 | 範圍 |
|---|---|
| **Glossopharyngeal** | 舌後 1/3、咽、**gag reflex** |
| **Superior laryngeal（internal branch）** | 會厭、聲帶以上喉部 |
| **Transtracheal / translaryngeal** | 聲帶以下氣管 |
| ~~Recurrent laryngeal~~ | **支配聲帶運動 → 不阻斷**（聲帶麻痺、阻塞） |

### 1.4 插管確認與困難呼吸道

- **確認 ETT 位置**：**持續 EtCO₂ 波形（最可靠）**、直視通過聲門、FOB、聽診（兩側胸部有、上腹無）、胸部起伏、**前頸部**超音波 〔111-1〕
- **非預期困難呼吸道**：必須備妥 **difficult airway algorithm**（DAS / ASA）〔113-2〕
    - 插管失敗 → 面罩通氣 → **SGA** → **CICV（無法插管且無法以非侵入方式通氣）→ front-of-neck access**
    - **Surgical cricothyrotomy**：平躺、甲狀軟骨與環狀軟骨間；**暫時性**通道；**< 10–12 歲（尤 < 6 歲）禁用 → needle cricothyrotomy** 〔112-1〕
- **吸入性肺炎最常發生於誘導期**（失去保護反射、插管前）〔113-2〕
- **拔管期併發症**：**喉痙攣**、上呼吸道阻塞 → **negative-pressure pulmonary edema**、支氣管痙攣、吸入、**杓狀軟骨脫位**、喉水腫；**neurogenic pulmonary edema 屬腦傷/SAH，非拔管** 〔115-2〕

### 1.5 快速順序插管（RSI）

- 適應症：**full stomach**（急診、腸阻塞、懷孕、GERD、DM 胃輕癱、外傷）
- 步驟：**preoxygenation（3 分鐘或 8 次深呼吸）** → 誘導劑 + **快速 NMBD（succinylcholine 1–1.5 mg/kg 或 rocuronium 1.2 mg/kg）** → **不做正壓面罩通氣** → 直接喉鏡插管（± cricoid pressure）；**FOB 不適合**（費時）〔114-2〕

#### RSI 誘導劑選擇

| 情境 | 首選 | 避免 |
|---|---|---|
| **低血壓/休克** | **Ketamine、etomidate** | **Propofol**（血管擴張、心肌抑制） 〔112-1〕 |
| **氣喘/支氣管痙攣** | **Ketamine**（支氣管擴張） 〔112-1, 112-2〕 | — |
| **頭部外傷 + 高血壓 + 疑腦疝** | Etomidate、propofol（血壓允許）、± lidocaine | **Ketamine 慎用**（交感興奮、傳統認為 ICP↑） 〔111-2〕 |

#### Succinylcholine 禁忌

- **燒傷（> 24–48 h）、SCI、去神經/中風、長期臥床、擠壓傷、肌肉失養症 → 接頭外 AChR 上調 → 致命高血鉀** → 改 rocuronium 〔114-2〕
- 惡性高熱病史/家族史、pseudocholinesterase 缺乏

### 1.6 術前風險評估

- **ASA physical status** I–VI（E = 急診）
- **Severe AS**（AVA < 1.0 cm²、mean gradient ≥ 40 mmHg、Vmax ≥ 4 m/s）→ 擇期非心臟手術前先評估處理 〔114-2〕
- **ARISCAT**（術後肺部併發症）7 項：**年齡、術前 SpO₂、1 個月內呼吸道感染、術前貧血（Hb ≤ 10）、上腹/胸腔切口、手術 > 2 h、緊急手術**；**不含 BMI** 〔115-1〕
- 禁食：清液 2 h、母乳 4 h、配方奶/輕食 6 h、油膩 8 h

## 二、麻醉監測

### 2.1 呼吸監測

#### Capnography（EtCO₂）

- 正常 **PaCO₂ − EtCO₂ ≈ 2–5 mmHg**；**死腔↑（低 CO、PE、COPD）→ 差距加大、不固定** → EtCO₂ 不能完全反映 PaCO₂ 〔112-2, 115-2〕
- **固定通氣下 EtCO₂ 反映肺血流（心輸出量）** 〔115-1〕

| EtCO₂ 變化 | 原因 |
|---|---|
| **驟降至 0** | **食道插管**（數個波後消失）〔113-2〕、迴路脫落、完全阻塞、**心跳停止** |
| **突然下降** | **ETT 彎折/部分阻塞、迴路漏氣、PE、空氣栓塞、嚴重低血壓** 〔110-1〕 |
| **上升** | **發燒**、**惡性高熱（最早徵象）** 〔114-2〕、通氣不足、CO₂ 吸收劑耗盡、腹腔鏡 CO₂、鬆止血帶、給 NaHCO₃ |
| CPR | **< 10 mmHg → 胸壓品質差；驟升 → ROSC** 〔114-2〕 |

- **插管過深（右主支氣管）**：EtCO₂ 不靈敏 → 聽診、氣道壓↑、SpO₂ 下降（**高 FiO₂ 下延遲**）〔113-1, 114-2〕

#### Pulse oximetry（SpO₂）

- 原理：**660 nm（deoxyHb 吸收多）/ 940 nm（oxyHb 吸收多）比值**，取**搏動（動脈）成分** 〔114-1〕
- 與 PaO₂ 呈 **S 形**（非線性）；**不反映通氣**（給氧時）；**晚期**缺氧指標 〔113-1〕
- 波形：心律、灌流（振幅低 → 灌流差）
- 誤差：**CO 中毒 → 假性正常**（需 co-oximetry）、**MetHb → 趨向 85%**、低灌流、移動、指甲油、methylene blue 〔115-2〕

#### 肺部影像

- **CXR 對肺水腫不敏感**（需肺水增加約 30%）；**肺超音波**（B-lines、pneumothorax、consolidation、積液）較早 〔115-2〕

### 2.2 循環監測

#### 動脈導管

- **Allen test 預測價值差**，不能預防缺血 〔111-1, 115-1〕
- **越遠端動脈：收縮壓越高、脈壓越大**（波反射、distal amplification）；**足背 > 股 > 肱 > 鎖骨下**；平均壓幾乎不變 〔112-1, 115-1〕

#### 前負荷與輸液反應

| 指標 | 評價 |
|---|---|
| **CVP、PCWP（靜態）** | **預測輸液反應差**（受順應性、胸內壓、瓣膜影響）〔111-1, 111-2, 115-1〕 |
| **PPV / SVV（動態）** | **> 12–13% → 有反應**；限制：**需機械通氣**、竇性心律、潮氣量 ≥ 8 mL/kg、閉胸 〔115-2〕 |
| **Passive leg raising** | 自發呼吸可用；**骨盆/下肢骨折、ICP↑ 不適用** 〔115-2〕 |

#### 肺動脈導管與 SvO₂

- PAC **未改善臨床結果**；最常見問題 = **數值誤判** 〔111-1, 111-2〕
- **SvO₂ 取自肺動脈**（ScvO₂ 取自上腔靜脈）〔112-2〕；**正常 65–75%** 〔111-2〕
- SvO₂↓ = 氧輸送↓（低 CO、貧血、低 SaO₂）或耗氧↑

#### TEE / FoCUS

- TEE：心室收縮/舒張功能、**局部室壁運動異常（最早期缺血）**、容積、瓣膜、CO、空氣栓塞、主動脈剝離；**無法評估冠狀動脈狹窄** 〔111-2〕
- **Simplified Bernoulli：ΔP = 4v²**（3.5 m/s → ~49 mmHg）〔111-1〕
- **FoCUS 基本視圖**：**PLAX、PSAX、A4C、subcostal 4C、IVC**（不含 apical long-axis）〔115-2〕

#### 術中 ECG

- 術中缺血多為 **ST depression（subendocardial）**、**難以定位** 〔115-1〕
- **V5 最敏感（~75%）**；II + V5 ~80%；**II + V4 + V5 ~96%**

### 2.3 麻醉深度與 EEG

- 腦血氧（NIRS）監測**灌流**，非麻醉深度 〔110-2〕
- **BIS**

| BIS | 狀態 |
|---|---|
| 100 | 清醒 |
| 60–80 | 鎮靜 |
| **40–60** | **全身麻醉（recall 機率低）** 〔113-2〕 |
| < 40 | 深麻醉 |
| ~< 20 | **Burst suppression**（不是 40） 〔113-2〕 |
| 0 | 等電位 |

- BIS 反映**意識/催眠程度**，不代表鎮痛、體動；可降低高風險（TIVA、肌鬆）病人的 awareness；**過深（低 BIS）與術後譫妄、死亡率相關** 〔110-2, 113-2〕
- **Ketamine、N₂O → 高頻 EEG → BIS 不可靠（偏高）**；propofol/volatile → **低頻高振幅**、frontal alpha 〔114-1〕
- 等電位 = 腦死；植物人 EEG 為彌漫慢波（**不像正常睡眠**） 〔114-1〕

### 2.4 體溫

- **麻醉低體溫三期** 〔111-1, 112-1〕
    1. **第 1 小時：重分布（核心 → 周邊，降 0.5–1.5°C）**——最主要
    2. 2–3 h：線性下降（散熱 > 產熱）
    3. 平台期
- 預防第 1 期：**麻醉前預先體表加溫（prewarming）**；術中體表加溫、輸液加溫；呼吸道加溫保濕對**嬰兒**較有效
- 機轉：全身麻醉**降低血管收縮/寒顫閾值**（老人閾值更低）；**神經軸麻醉同樣造成低體溫**（阻斷區血管擴張、中樞閾值下降）→ **也需監測** 〔110-1, 111-1, 112-1〕
- **> 30 分鐘全身麻醉常規監測體溫，核心體溫維持 ≥ 36°C**
- 低體溫後果：**傷口感染↑、出血↑、心肌缺血、藥物作用延長、寒顫（耗氧↑ 50–100%）** 〔110-1〕

### 2.5 腎功能

- **術中尿量與術後 AKI 相關性差** 〔110-2, 111-2〕
- **Creatinine 與 GFR 呈非線性（雙曲線）**、延遲 → **GFR 直接測量**較敏感特異
- **新 biomarker**：**NGAL（2–6 h 內上升）**、KIM-1、**IL-18**、TIMP-2·IGFBP7 〔110-2〕
- 腎保護：**維持血行動力（MAP、容積、CO）與組織灌流**、避免腎毒性 〔111-2〕
- 腎前性：NSAID（入球收縮）、ACEI/ARB（出球擴張）、血管收縮劑、低血壓 〔115-1〕

## 三、麻醉藥理

### 3.1 吸入性麻醉劑

- **Meyer-Overton**：**油氣分配係數（脂溶性）↑ → MAC↓（效力↑）** 〔113-2〕
- **血氣分配係數↓ → 誘導/甦醒快**：desflurane < N₂O < sevoflurane < isoflurane

| | Sevoflurane | Desflurane | Isoflurane |
|---|---|---|---|
| 鹵素 | **純氟** | **純氟** | 含氯 |
| 氣道 | **不刺激 → 吸入誘導首選（兒童）** | **刺激（咳嗽、喉痙攣）** | 刺激 |
| 速度 | 快 | **最快** | 慢 |
| 乾燥吸收劑 | **Compound A**（低流量，腎毒性於動物） | **CO** | CO |
| 其他 | — | 需加熱蒸發器、交感興奮 | 冠狀動脈竊血（理論） |

〔110-2〕

- 共同：**血管舒張、劑量依賴性呼吸/心肌抑制**、增強 NMBD、**子宮鬆弛**、腦血管擴張（> 1 MAC）、**惡性高熱誘因**
- **MAC 影響因素** 〔113-2〕

| MAC ↓ | MAC ↑ |
|---|---|
| **老年（每 10 年 −6%）**、低體溫、**懷孕**、急性酒精、opioid、benzodiazepine、**α2 agonist** 〔115-2〕、低血鈉 | **嬰兒（6 月最高）**、高體溫、慢性酒精、甲亢、急性安非他命/古柯鹼、高血鈉 |

### 3.2 靜脈麻醉劑

| 藥物 | 機轉 | 心血管 | 呼吸 | 重點 |
|---|---|---|---|---|
| **Propofol** | GABA-A | **↓↓ 血壓** | 抑制 | 止吐、PRIS、注射痛、**脂肪乳劑易長菌** 〔111-2〕；休克避免 |
| **Thiopental** | GABA-A | ↓ | 抑制 | **↓ CMRO₂、CBF、ICP** 〔112-1〕；紫質症禁用 |
| **Ketamine** | **NMDA 拮抗** | **↑ 血壓、心率** | **最少抑制**、支氣管擴張 〔112-1〕 | 解離麻醉、鎮痛、幻覺、分泌物↑、IOP↑；**BIS 不可靠** |
| **Etomidate** | GABA-A | **最穩定** | 輕 | **抑制 11β-hydroxylase（腎上腺）** 〔112-1〕、PONV、肌陣攣 |
| **Midazolam** | GABA-A | 輕 ↓ | 抑制（+ opioid → apnea）〔111-2, 112-1〕 | 遺忘；**flumazenil** 拮抗 |
| **Dexmedetomidine** | **α2 agonist** | 心搏過緩、低血壓 | **幾乎不抑制** | 可喚醒鎮靜、**opioid-sparing**、**↓ MAC**、減少譫妄 〔115-2〕 |

- **Barbiturate 作用於 GABA-A**（抑制 RAS），**不是 NMDA** 〔111-2〕

### 3.3 鎮靜深度（ASA continuum）

| 層級 | 反應 | 呼吸道 | 自發呼吸 |
|---|---|---|---|
| Minimal（anxiolysis） | 對口語正常反應 | 不受影響 | 不受影響 |
| Moderate（conscious） | 對口語/輕觸有目的反應 | 不需介入 | 足夠 |
| **Deep** | **反覆或疼痛刺激才有反應** | **可能需介入** | **可能不足** 〔115-2〕 |
| General | 對疼痛無反應 | 常需介入 | 常不足 |

### 3.4 鴉片類藥物

- **μ receptor（Gi/o）→ 開 K⁺ 通道（過極化）、關 Ca²⁺ 通道**（↓ 神經傳導物釋放）、↓ cAMP 〔112-1〕
- 內源性：endorphins、enkephalins、dynorphins
- 副作用：呼吸抑制、鎮靜、噁心、便秘、尿滯留、搔癢、**快速大劑量 → 胸壁僵硬** 〔112-2〕
- **長期使用 → tolerance、opioid-induced hyperalgesia（非 hypoalgesia）** 〔112-2〕
- **大劑量 opioid 抑制手術壓力反應（catecholamine）** 〔112-2〕

| 藥物 | 重點 |
|---|---|
| **Morphine** | **M6G（活性）、M3G 腎排除 → 腎衰竭累積**；肝衰竭亦累積；histamine 釋放 |
| **Fentanyl** | 高脂溶性、低分子量 → **經皮貼片** 〔112-1〕 |
| **Remifentanil** | **非特異性 esterase（血液、組織）** → context-sensitive half-time 3–4 分、**不受肝腎影響、不累積**；**與 pseudocholinesterase 無關** 〔110-1〕；停藥需銜接止痛 |
| **Meperidine** | **Normeperidine → 癲癇**（腎衰累積）；+ MAOI → serotonin syndrome；**不用於長期/癌症疼痛** 〔112-2〕；可治寒顫 |

- **Naloxone（μ 拮抗）**：拮抗呼吸抑制；**作用短於多數 opioid → 再抑制**；過快 → 疼痛、高血壓、肺水腫 〔111-2〕

### 3.5 神經肌肉阻斷劑（NMBD）

- **只有肌肉鬆弛**，無鎮靜、鎮痛、遺忘 〔115-1〕

#### 去極化：Succinylcholine

- 作用快（30–60 s）、短（5–10 min）；**plasma pseudocholinesterase** 代謝
- 副作用 〔114-2〕

| 副作用 | 重點 |
|---|---|
| **高血鉀** | 正常 ↑ 0.5 mEq/L；**燒傷、SCI、去神經、肌病變 → 致命** |
| **心搏過緩** | **兒童**、重複給藥 |
| 肌束顫動、肌痛 | 先給小劑量非去極化 NMBD（precurarization）可減少 |
| **ICP、IOP、胃內壓↑** | 〔114-2〕 |
| **惡性高熱** | RYR1；**dantrolene** |
| 作用延長 | Pseudocholinesterase 缺乏（dibucaine number） |
| Phase II block | 大劑量 |

#### 非去極化

| 藥物 | 代謝 | 重點 |
|---|---|---|
| **Rocuronium** | 肝膽 | **RSI（1.2 mg/kg）**；sugammadex 可逆轉 |
| Vecuronium | 肝膽 | — |
| **Cisatracurium** | **Hofmann elimination（不依賴肝腎）** | **肝腎衰竭首選** 〔113-1〕 |
| Atracurium | Hofmann + ester hydrolysis | Histamine、laudanosine |
| Pancuronium | 腎 | 心搏過速、長效 |

#### 監測與逆轉

- **TOF**：fade 見於非去極化；**拔管目標 TOF ratio ≥ 0.9**（< 0.9 = 殘留阻斷 → 咽部功能差、缺氧、吸入）；0.7 臨床可抬頭但仍不足 〔113-1, 114-2〕
- **Neostigmine（AChE inhibitor）**：增加 ACh；**有 ceiling effect → 需已有部分恢復（TOF count ≥ 2–4）才給**；合併 **glycopyrrolate/atropine** 〔113-1〕
- **Sugammadex**：**γ-cyclodextrin 包覆 steroidal NMBD（rocuronium > vecuronium）**；深度阻斷亦可、**CICV 緊急逆轉（16 mg/kg）**；**對 cisatracurium、mivacurium 無效** 〔113-1, 113-2〕
- **增強 NMBD**：吸入麻醉劑、**aminoglycosides**、Mg²⁺、低體溫、酸中毒、低血鉀、局麻藥 〔111-1〕

#### 重症肌無力（MG）

| | Succinylcholine | 非去極化 NMBD |
|---|---|---|
| **MG** | **抗性 → 需增加劑量** | **極敏感 → 減量、TOF 監測** |
| Lambert-Eaton | 敏感 | 敏感 |

〔114-2〕

- 術前評估 pyridostigmine 劑量；術後呼吸衰竭風險高

### 3.6 局部麻醉劑

- 機轉：**阻斷電位門控型 Na⁺ 通道**（非離子型穿膜 → 離子型由內側結合）；Na⁺ 通道三態：resting、activated（open）、inactivated（**use-dependent block**） 〔110-1, 111-1〕
- 理化性質

| 性質 | 影響 |
|---|---|
| **脂溶性** | **效力（potency）**、作用時間 〔110-1〕 |
| **pKa** | **Onset**（越接近 pH 越快）；**鹼化（NaHCO₃）→ onset 加快** 〔113-2〕 |
| **蛋白結合** | **Duration** |

- 神經敏感度：小直徑、有髓較敏感（B > Aδ、C > Aβ > Aα）→ 先失去痛溫覺、交感，後運動 〔110-1〕
- **Epinephrine → 血管收縮** → 延長作用、減少全身吸收、test dose 〔111-1〕
- **全身吸收（高 → 低）**：IV > **intercostal** > caudal > epidural > brachial plexus > sciatic/femoral > 皮下 〔112-2〕

| | Ester | Amide |
|---|---|---|
| 例 | Procaine、chloroprocaine、tetracaine、**cocaine** | **Lidocaine、bupivacaine、ropivacaine**（名稱兩個 i） |
| 代謝 | **Plasma pseudocholinesterase** | **肝 CYP450** 〔112-2, 115-2〕 |
| 過敏 | PABA → 較多 | 罕見 |

- **Bupivacaine：心毒性最強**（緩慢解離 Na⁺ 通道）；ropivacaine 較少
- **Cocaine：ester**、唯一阻斷 NE 再回收 → 血管收縮 〔115-2〕

#### 局部麻醉劑全身毒性（LAST）

- **中樞（先出現）**：**口周麻、舌麻、金屬味、耳鳴、頭暈** → 視覺障礙、抽搐 → **癲癇** → 昏迷、呼吸停止（**幻覺不是典型**）〔110-2, 111-1〕
- **心血管**：心律不整（VT/VF）、心肌抑制、心跳停止（bupivacaine 可先出現）

!!! danger "LAST 處置"
    **停止注射** → 呼救 → **呼吸道、100% O₂**（避免缺氧/酸中毒）→ **benzodiazepine 止抽** → **20% lipid emulsion 1.5 mL/kg bolus + 0.25 mL/kg/min** → ACLS 調整：**epinephrine ≤ 1 μg/kg**；**避免 vasopressin、CCB、β-blocker、lidocaine（其他局麻藥）** → 必要時 ECMO。〔110-1〕

## 四、區域麻醉

### 4.1 神經軸解剖

- 正中穿刺層次：皮膚 → 皮下 → **棘上韌帶 → 棘間韌帶 → 黃韌帶** → **硬膜外腔（loss of resistance）** 〔110-2〕 → 硬脊膜 → **蜘蛛網膜** → **蜘蛛網膜下腔（CSF）** 〔113-2〕 → 軟膜
- 成人脊髓止於 **L1–2** → 脊麻於 **L3–4 / L4–5**（Tuffier line ≈ L4）
- **Caudal block**：經 sacral hiatus（sacrococcygeal ligament）→ **薦部硬膜外腔**；兒童下腹/會陰 〔115-1〕

### 4.2 脊椎麻醉 vs 硬膜外麻醉

| | Spinal | Epidural |
|---|---|---|
| 位置 | 蜘蛛網膜下腔 | 硬膜外腔 |
| 劑量 | 小 | 大（10 倍） |
| Onset | **快、密實** | 慢、可分段（導管） |
| 阻斷高度決定 | **比重 + 姿勢**、劑量、**CSF 容積（肥胖、懷孕 → 較高）** 〔112-1〕 | **容積** |
| 時效 | 單次 | 可延長（導管） |

- **影響脊麻高度最小**：**注射速度**、針孔方向、性別 〔114-1〕
- 藥物：**bupivacaine 長效**、lidocaine 短效（TNS）；**intrathecal morphine（親水）作用 12–24 h、延遲性呼吸抑制**、fentanyl 親脂短效 〔113-1〕

#### 併發症

| 併發症 | 重點 |
|---|---|
| **低血壓（最常見）** | 交感阻斷 → 輸液、phenylephrine/ephedrine 〔113-1〕 |
| 心搏過緩 | T1–4 cardioaccelerator 阻斷、Bezold-Jarisch |
| **尿滯留** | 尤其 intrathecal opioid 〔113-1〕 |
| **PDPH** | **姿勢性頭痛**（坐立加重、平躺緩解）、額枕、頸僵、耳鳴；24–48 h；年輕女性、孕婦、大口徑/切割針 → 補液、咖啡因 → **epidural blood patch** 〔115-1〕 |
| High/total spinal | 呼吸困難、低血壓、意識喪失 |
| 硬膜外血腫/膿瘍 | 背痛 + 神經缺損 → 緊急 MRI、減壓 |

#### 禁忌

- **絕對**：病人拒絕、**穿刺部位感染**、**凝血異常/抗凝**（血小板一般 < 70–80k）、未矯正低血容、**ICP↑（腦瘤 → 腦疝）** 〔115-1〕
- **相對**：**嚴重 AS/固定心輸出**（急速 SVR↓）、全身感染、既有神經病變
- 血小板 100k 可安全施打 〔115-1〕

### 4.3 周邊神經阻斷

| 阻斷 | 範圍 | 重點 |
|---|---|---|
| **Interscalene** | **肩、上臂** | 漏 C8–T1（尺側）；**100% 同側膈神經麻痺** |
| **Supraclavicular** | 上肢全部（spinal of the arm） | 氣胸 |
| Infraclavicular / **Axillary** | **肘以下、手腕** 〔113-2〕 | — |
| **Femoral / Adductor canal** | **膝前方** → TKA；**adductor canal 保留股四頭肌力** 〔110-1〕 | — |
| Sciatic | 膝後方、小腿足部 | TKA 單用效果差 〔110-1〕 |
| **Paravertebral / thoracic epidural** | 開胸術 〔110-2〕 | — |
| Bier block | 前臂/手（IV regional） | 止血帶失效 → LAST |

## 五、特殊族群與手術情境

### 5.1 孕婦生理

| 系統 | 變化 | 麻醉意義 |
|---|---|---|
| 心血管 | **CO↑ 40–50%（SV、HR 皆↑）、SVR↓** | **Aortocaval compression → 左傾（LUD）** |
| 呼吸 | **MV↑（呼吸性鹼中毒）、FRC↓ 20%**、耗氧↑ | **快速缺氧**、困難插管（水腫）→ **小號 ETT** 〔110-2〕 |
| 氧解離 | **母體曲線右移**（2,3-DPG↑）→ 利胎盤釋氧；胎兒 HbF 左移 | 〔114-2〕 |
| 消化 | **LES 張力↓、胃壓↑**、產程胃排空延遲 | **一律視為 full stomach** → nonparticulate antacid、RSI 〔113-1〕 |
| 其他 | **MAC↓**、局麻藥需求↓、高凝 | — |

### 5.2 產科麻醉

- **Labor epidural**：產婦要求即可（**不需等子宮頸開 3 cm**、不增加剖腹產率）〔112-2〕
    - 疼痛：第一產程 **T10–L1（內臟）**；第二產程 **S2–S4（陰部神經）**
    - **低濃度 bupivacaine + fentanyl** → 運動阻滯少（walking epidural）〔114-1〕
    - **Test dose**（lidocaine + epinephrine）排除血管內/蜘蛛網膜下腔
    - 可能延長第二產程
- **剖腹產全身麻醉**：**RSI 首選 succinylcholine**（高度離子化，**幾乎不過胎盤**）；娩出後才給 opioid；**吸入麻醉劑降至 ~0.5 MAC**（避免子宮弛緩出血）+ oxytocin 〔113-1〕
- **孕期非產科手術**（如腹腔鏡闌尾切除）：**維持母體正常 PaCO₂**（**避免 permissive hypercapnia → 胎兒酸中毒**）、避免低血壓/缺氧、左傾、低氣腹壓、可存活週數監測 FHR 〔112-2〕
- **孕婦 CPR**：小號 ETT、去顫劑量不變、**手動推子宮向左**、**4 分鐘無 ROSC → perimortem cesarean** 〔110-2〕

### 5.3 手術姿勢

| 姿勢 | 用途 | 生理/風險 |
|---|---|---|
| **Trendelenburg（頭低）** | **下腹/骨盆手術**（上腹用 reverse） | **ICP、IOP、CVP↑**、FRC↓、喉/臉水腫、ETT 移入支氣管 〔110-1〕 |
| Reverse Trendelenburg | 上腹部、腹腔鏡膽囊 | 靜脈回流↓ |
| **Prone（趴臥）** | 脊椎、後側手術 | **V/Q 可改善**；**POVL（posterior ischemic optic neuropathy；非單純眼球受壓）**、上臂外展 < 90°、腹部懸空 〔113-1〕 |
| Lateral | 開胸、腎 | V/Q mismatch、腋下 roll |
| Lithotomy | 會陰 | **腓總神經**、腔室症候群 |

### 5.4 神經外科麻醉

- **CPP = MAP − ICP**（目標 60–70；< 60 → 繼發性腦損傷）〔110-2〕
- 誘導：**propofol/thiopental**（↓ CMRO₂、CBF、ICP）；**ketamine 傳統避免**；避免高劑量吸入麻醉劑（> 1 MAC 腦血管擴張）〔110-2〕
- 維持正常 CO₂（過度換氣僅救急）、避免低血壓、低血氧、高血糖、高體溫；頭抬高 30°
- 術後帶管 → opioid-based + NMBD

## 六、術後照護與疼痛處置

### 6.1 恢復室（PACU）

- 監測：**呼吸、循環、體溫、意識**
- 常見問題：**PONV**、低血氧、**低血壓**（低容積、出血）與高血壓（疼痛、膀胱脹、低體溫）、寒顫、譫妄、**殘留肌鬆**（aminoglycosides 增強）〔111-1〕
- **Modified Aldrete score**（各 0–2，**≥ 9 轉出**）：**activity、respiration、circulation、consciousness、O₂ saturation**；**不含疼痛**（PADSS 才有）〔114-1〕

### 6.2 術後噁心嘔吐（PONV）

- **Apfel 危險因子**：**女性、不抽菸、PONV/暈車史、術後 opioid**（0–4 個 → 10/20/40/60/80%）
- 其他：吸入麻醉劑、N₂O、長手術、腹腔鏡、婦科、斜視手術
- 預防：**dexamethasone（誘導時）**、**ondansetron（結束時）**、droperidol、scopolamine、aprepitant；**propofol TIVA** 〔111-1〕

### 6.3 急性術後疼痛

- **多模式止痛（ERAS）**：acetaminophen + NSAID（**腎功能損害**）+ **區域阻斷/局部浸潤** + 必要時 opioid；**ERAS 鼓勵使用周邊神經阻斷**、不常規放鼻胃管 〔112-1〕
- **Epidural analgesia 優點**：**減少 opioid、腸胃道/肺部併發症↓、壓力反應↓（阻斷交感，非增加）**、血栓↓ 〔111-1〕
- **開胸術 → thoracic epidural / paravertebral** 〔110-2〕
- **TKA → adductor canal / femoral block**（sciatic 效果最差）〔110-1〕
- **IV PCA**：提高滿意度、減少總 opioid、副作用↓；**並非絕對安全**（PCA by proxy、basal infusion、OSA、設定錯誤）→ 仍需監測 〔112-1, 115-2〕

### 6.4 疼痛名詞

| 名詞 | 定義 |
|---|---|
| **Allodynia** | **非傷害性刺激引起疼痛** |
| **Hyperalgesia** | **傷害性刺激反應加劇** |
| **Analgesia** | **對疼痛刺激無痛覺**（對所有知覺無反應 = anesthesia） |
| Paresthesia | 自發或誘發的異常感覺（不一定不愉快） |
| Dysesthesia | 不愉快的異常感覺 |

〔113-2〕

### 6.5 慢性與癌症疼痛

- **三叉神經痛**：**carbamazepine 首選**、oxcarbazepine → MVD、gamma knife 〔113-1〕
- **Epidural steroid injection**：神經根痛；**影像（fluoroscopy）導引**；類固醇 + 局麻優於單用局麻；**頸椎也可做**（多 interlaminar）〔111-2〕
- **癌症疼痛**：WHO 階梯、**口服優先、定時 + 突發痛劑量**；不能口服 → **貼片**、**皮下**（消瘦者貼片吸收不穩，皮下仍有效）；**化療神經病變屬癌症疼痛**；骨轉移 → NSAID、**類固醇**、放療、bisphosphonate 〔112-2, 114-1〕
- **避免 meperidine** 長期使用 〔112-2〕

| 神經叢阻斷 | 適應症 |
|---|---|
| **Celiac plexus** | **上腹內臟（胰臟癌）**；副作用：姿勢性低血壓、腹瀉 〔114-2〕 |
| Superior hypogastric | 骨盆內臟 |
| Ganglion impar | 會陰 |

## 七、重症醫學

### 7.1 敗血症

- **Sepsis-3**：感染 + **SOFA ≥ 2**；**septic shock = 充分輸液後仍需升壓劑維持 MAP ≥ 65 + lactate > 2 mmol/L**（SIRS/severe sepsis 已不使用）〔112-1〕
- **Surviving Sepsis 處置** 〔110-1, 113-2〕

| 項目 | 建議 |
|---|---|
| 抗生素 | **1 小時內**（先抽血液培養） |
| 輸液 | **30 mL/kg crystalloid（3 h 內）**（balanced 優於 NS） |
| 升壓劑 | **Norepinephrine 第一線** → 加 vasopressin → epinephrine；心功能差 → dobutamine |
| MAP 目標 | **≥ 65 mmHg**（非 90） |
| 類固醇 | **低劑量 hydrocortisone 200 mg/d**（需持續升壓劑時） |
| 血糖 | **> 180 開始胰島素、目標 ≤ 180**（避免嚴格控制） |
| 無效 | **EGDT 未優於常規**、**renal-dose dopamine 無效**、高劑量類固醇 |

- **多器官併發症**：**壓力性高血糖**（insulin resistance；非低血糖）、**血小板低下（早期）**、**DIC**、**壓力性潰瘍**、ARDS、AKI 〔111-2〕

### 7.2 ARDS

- **Berlin definition** 〔112-2, 114-1〕
    - **1 週內**發生/惡化
    - **雙側浸潤**（非積液、塌陷、結節可解釋）
    - **非心因性**（不能完全以心衰竭/體液過多解釋）
    - **PEEP ≥ 5 下 P/F**：**mild 200–300、moderate 100–200、severe ≤ 100**
- 治療（有實證）：**低潮氣量 6 mL/kg PBW、plateau ≤ 30 cmH₂O**、適當 PEEP、**prone（P/F < 150，≥ 12–16 h/day）**、保守輸液、± 早期 NMBD、ECMO
- **Inhaled NO**：**選擇性擴張通氣良好區域的肺血管**（改善 V/Q）、進血液即被 Hb 失活；**改善氧合但不降死亡率** 〔113-1〕

### 7.3 正壓通氣生理

- 胸內壓↑ → **靜脈回流↓、LV 前負荷↓、CO↓**；肺泡過度擴張 → **PVR↑、RV 後負荷↑**、**死腔↑**（West zone 1）
- **Barotrauma：plateau > 30–35 cmH₂O**（PEEP 10 為常用範圍）〔111-1〕

### 7.4 營養與代謝

- **優先腸道營養（24–48 h 內）**；EN 併發腹瀉、逆流；PPN → 靜脈炎；**PN 或 EN 中斷而胰島素未調整 → 低血糖**；敗血症 → 想導管感染；**refeeding syndrome（低磷）** 〔110-2〕
- **術後壓力性高血糖**：交感亢奮、cortisol/glucagon/GH↑、分解代謝↑、感染加重 → 高血糖 → 感染、傷口癒合差 〔114-2〕

### 7.5 一氧化碳中毒與吸入性傷害

- **CO**：對 Hb 親和力 ~250 倍、曲線左移、抑制 cytochrome oxidase；**一般 SpO₂ 假性正常 → co-oximetry** 〔115-2〕
- COHb 正常 < 3%（吸菸者 < 10%）；症狀：頭痛、噁心、意識混亂、休克
- 治療：**100% O₂（COHb 半衰期 ~90 min；室內空氣 ~300 min）**；**HBO（~30 min）**：意識改變、COHb > 25%（孕婦 > 15%）、心肌缺血
- **吸入性傷害**（密閉空間、臉燒傷、**碳渣、鼻毛焦、聲啞、喘鳴**）→ **早期插管**、100% O₂、查 **COHb、cyanide（lactate↑ → hydroxocobalamin）**；**無皮膚燒傷不需大量輸液**（Parkland 依 TBSA） 〔115-1〕
